## 摘要
交互式文本到SQL智能体通过多轮交互解决数据库任务，涉及模式探索、查询执行、反馈解释和决策修正。长期记忆有助于智能体重用过往经验，但现有检索方法仍存在局限。静态方法依赖固定相似度启发式规则，不优化下游效用；动态方法通常从稀疏的最终结果中学习，并在单一决策维度上检索记忆。当记忆有用性随交互阶段变化时，这并不足够，因为对初始规划有用的记忆可能与局部、状态条件执行所需的记忆不同。我们提出MERIT，一种动态多维度记忆检索框架。MERIT维护回合级记忆用于全局策略指导，以及轮次级记忆用于局部决策支持。两个层级均使用通过强化学习优化的学习型检索策略。为了在有限的中间监督下训练轮次级检索，MERIT使用轻量级过程奖励模型为局部记忆选择提供密集代理奖励。在BIRD-Interact上的实验表明，MERIT在成功率上优于无记忆、静态检索和动态检索基线，同时减少了平均交互轮次。在Spider2-Snow上的迁移结果进一步展示了无需针对特定基准调优的跨基准正向迁移。这些结果表明，多维度检索能提升交互式文本到SQL智能体的经验复用能力。

## Abstract
Interactive text-to-SQL agents solve database tasks through multi-turn interactions involving schema exploration, query execution, feedback interpretation, and decision revision. Long-term memory helps agents reuse past experiences, but existing retrieval methods remain limited. Static methods rely on fixed similarity heuristics that do not optimize downstream utility, while dynamic methods often learn from sparse final outcomes and retrieve memories at a single decision horizon. This is insufficient when memory usefulness changes across interaction stages, since memories useful for initial planning may differ from those needed for local, state-conditioned execution. We propose MERIT, a dynamic multi-horizon memory retrieval framework. MERIT maintains episode-level memory for global strategic guidance and turn-level memory for local decision support. Both levels use learned retrieval policies optimized with reinforcement learning. To train turn-level retrieval despite limited intermediate supervision, MERIT uses a lightweight Process Reward Model to provide dense proxy rewards for local memory selection. Experiments on BIRD-Interact show that MERIT outperforms no-memory, static-retrieval, and dynamic-retrieval baselines in success rate while reducing average interaction turns. Transfer results on Spider2-Snow further show positive cross-benchmark transfer without benchmark-specific tuning. These results suggest that multi-horizon retrieval improves experience reuse in interactive text-to-SQL agents.

### 1. 论文的核心问题与整体含义（研究动机和背景）
交互式文本到SQL（Text-to-SQL）智能体需要通过多轮交互（模式探索、SQL执行、反馈解释、方案修订）来完成复杂数据库任务。长期记忆可以帮助智能体重用过往经验，避免重复探索并提升决策质量。然而，现有记忆检索方法存在两个主要局限：
- **静态方法**（如BM25、余弦相似度）依赖固定相似度启发式，不直接优化下游任务效用；
- **动态方法**（如Memento、MemRL）学习记忆选择但仍主要基于最终结果（稀疏终端奖励），且仅在单一决策维度（回合级）进行检索，忽略了交互过程中不同阶段对记忆类型的不同需求（例如初始规划与局部调试所需记忆不同）。

为此，论文提出**MERIT**（Multi-horizon mEmory Retrieval using Intermediate and Terminal rewards），一个动态多维度记忆检索框架，旨在通过分离全局策略与局部支持、并使用强化学习优化检索策略，提升经验复用的有效性和交互效率。

### 2. 论文提出的方法论：核心思想、关键技术细节
**核心思想**：将记忆检索对齐决策维度，维护两层级记忆：
- **Episode-level（回合级）记忆**：记录完整交互轨迹、任务成果、提炼的策略洞察，在交互开始前检索，提供全局策略指导。
- **Turn-level（轮次级）记忆**：记录紧凑的状态-动作-观察片段（含状态签名、抽象动作、执行状态标签），在每次行动前检索，提供状态条件化的局部提示。

**关键技术细节**：
1. **两阶段检索管道**：
   - 第一阶段：基于嵌入的候选检索（余弦相似度）。
   - 第二阶段：学习型选择器（LoRA微调的Qwen3-4B）从候选中选出要注入的记忆，两者均用PPO优化。
2. **强化学习训练**：
   - Episode-level选择器：使用终端任务奖励（最终SQL执行正确性）。
   - Turn-level选择器：由于中间轮次缺乏直接可靠奖励，引入**Process Reward Model (PRM)** 提供密集代理奖励。
3. **PRM设计**：
   - PRM初始化为DeepSeek-R1-Distill-Qwen-7B，输入当前状态与候选记忆，输出结构化评分（沿7个维度：状态匹配、可行动性、模式泛化性、结果可靠性、对智能体清晰度、评估置信度、总体效用），并含二进制注入决策。

- **MERIT在BIRD-Interact上实现最高成功率**（Phase1 33.01%，Phase2 22.17%），同时将平均交互轮数降至7.84（比无记忆基线减少1.09轮）。

### 7. 优点：方法或实验设计上的亮点
- **双层级记忆设计**：首次将记忆检索与决策维度对齐，分离全局策略与局部状态条件支持，直观且有效。
- **RL优化检索策略**：不再依赖固定相似度，而是通过下游任务效用学习记忆选择，适应动态交互状态。
- **引入PRM提供密集奖励**：以结构化评估替代稀疏终端奖励，缓解轮次级信用分配难题，设计精巧（七维评分+二进制决策+文本反馈）。
- **数据增强与多轮轨迹生成**：SQL-first扰动策略保证可执行性，支持大规模训练。
- **实验设计严谨**：控制所有基线共享相同智能体、模拟器和预算；包含Leaderboard结果（使用更强模型取得SOTA）；跨基准迁移验证泛化性。

### 8. 不足与局限
- **PRM监督质量依赖教师模型**：PRM训练基于GPT-5生成的标注，而非真实因果标签，可能引入教师偏差。
- **仅测试强模型（GPT-5）作为主代理**：未验证在开源模型（如LLaMA、DeepSeek）或弱推理模型上的效果，通用性有待进一步探索。
- **记忆存储成本未分析**：虽然检索计算轻量，但长期运行会不断积累记忆，存储与更新开销未在文中讨论。
- **跨基准迁移增益较小**：在Spider2-Snow上增长率仅为3.29%（相对无记忆），可能受限于基准差异。
- **数据增强依赖LLM**：生成查询的逻辑一致性依赖LLM能力，存在质量波动风险。
- **实验未覆盖不同PRM架构**：仅使用单一PRM初始化和训练方案，未探讨规模或设计选择的影响。
