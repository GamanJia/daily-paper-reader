## 摘要
对话式AI智能体需要既具有可扩展性又在长时间交互中保持语义一致性的记忆系统。现有方法主要依赖基于大语言模型（LLM）的写入时摘要，这引入了非确定性、不断增加的token成本以及剪枝决策的不透明性。我们提出确定性记忆框架（DMF），这是一种以CPU优先的方法，用完全确定性的流水线替代生成式记忆压缩，该流水线基于经典自然语言处理分析、向量几何和数学评分。DMF为每次对话交互分配一个生存分数$Ω$，该分数由确定性内容信号、对话线索和结构化来源通过逻辑投影计算得出。一个交互计数衰减律，表示为$Ω_{\mathrm{eff}}(Δn)$，控制着当新回合到来时相关性的演变，其中$Δn$是更新的交互数量而非实际时间，从而保持完全确定性。我们展示了DMF的数学公式、其结构化召回流水线、剪枝决策过程以及评估协议。实验在使用LoCoMo和LongMemEval数据集专门构建的基准上进行。我们将DMF与Mem0（一种流行的AI智能体记忆层）进行比较。DMF在准备记忆上下文时使用零token，且在整个对话过程中使用的token数减少5倍至242倍，同时实现了相当的准确率。这些结果表明，可以从记忆管理循环中消除LLM调用，将token成本降至接近零，并为对话式AI智能体实现确定性记忆系统。

## Abstract
Conversational AI agents require memory systems that are both scalable and semantically coherent across long interaction horizons. Existing approaches rely predominantly on large language model (LLM)-based summarisation at write time, which introduces non-determinism, escalating token costs, and opacity in pruning decisions. We present the Deterministic Memory Framework (DMF), a CPU-first approach that replaces generative memory compression with a fully deterministic pipeline grounded in classical NLP analysis, vector geometry, and mathematical scoring. DMF assigns each conversational interaction a Survival Score $Ω$ computed from deterministic content signals, conversational cues, and structured provenance, combined through a logistic projection. An interaction-count decay law, denoted as $Ω_{\mathrm{eff}}(Δn)$, governs how relevance evolves as new turns arrive, where $Δn$ is the number of newer interactions rather than wall-clock time, preserving full determinism. We present the mathematical formulation of DMF, its structured recall pipeline, the pruning decision procedure, and the evaluation protocol. Experiments are conducted on a purpose-built benchmark using the LoCoMo and LongMemEval datasets. We compare DMF against Mem0, a popular memory layer for AI agents. DMF achieves comparable accuracy while using zero tokens to prepare the memory context and 5x to 242x fewer tokens over the entire conversation. These results show that it is possible to eliminate LLM calls from the memory-management loop, reducing token costs to nearly zero and enabling deterministic memory systems for conversational AI agents.

## 1. 核心问题与整体含义（研究动机与背景）
- **问题**：现有对话式AI智能体的记忆系统普遍采用基于大语言模型（LLM）的生成式压缩（如MemGPT、Mem0等），即在写入时由LLM对历史对话进行摘要。这带来三大关键缺陷：
  - **非确定性**：同一历史多次调用LLM可能产生不同摘要，导致记忆状态不可复现，难以调试和审计。
  - **高Token成本**：每次摘要消耗大量输入/输出token，在长对话场景中远超任务本身开销。
  - **不透明性**：无法检查某个事实为何被保留或丢弃，剪枝决策被封装在黑盒生成过程中。
- **整体含义**：提出一种完全摆脱LLM调用的确定性记忆框架DMF，使记忆管理可复现、低成本、可审计，为对话AI提供可靠的长期记忆基础。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：用CPU-first的全确定性流水线替代LLM驱动的生成式记忆压缩。整个记忆生命周期（评分、剪枝、归档、检索、重排序、证据组装）均不调用任何LLM。
- **关键技术细节**：
  - **NLP特征提取**：使用spaCy（词性标注、命名实体识别）和VADER（情感分析）提取三个标量信号：
    - 信息密度ID：语义性token占比（名词、动词、形容词、专有名词）。
    - 情感幅度|S|：VADER复合分数的绝对值。
    - 命名实体计数E（经饱和归一化，cap=5）。
    - 语义散度D：当前嵌入与滑动窗口中心点的余弦距离（惩罚离题内容）。
  - **对话与实用信号**：通过语言规则提取约束、偏好、当前状态、过去状态、更正、替换、询问、确认等布尔信号，以及可能的主题-值对（保守投影）。
  - **生存分数Ω**（静态）：
    - 三通道线性聚合：内容通道（α·ID+β·|S|+γ·Enorm+δ·D，δ<0）、操作通道（约束/偏好等布尔信号的加权和）、来源通道（用户更正、偏好更新等结构化元数据的加权和）。
    - 总预激活z_total，经逻辑斯蒂函数投影至(0,1)：Ω = σ(z_total - x0)，默认x0=1.5。
    - 示例：技术事实约0.86，平均对话约0.44，情感离题约0.08。
  - **时序衰减**（动态Ω_eff）：
    - 衰减轴：使用交互计数差Δn（更新的交互数），而非真实时间，保证确定性。
    - 指数衰减：Ω_eff(Δn) = Ω·exp(-λ·(1-ηΩ)·Δn)，其中λ=0.035，η=0.5。
    - 分数依赖性惯性：高Ω条目有效衰减率更低，半衰期更长（Ω=0.87时半衰期约35轮，Ω=0.18时约22轮）。
  - **记忆层级分类**：根据Ω_eff划分HEALTHY(>0.75)、UNSTABLE(0.3~0.75)、CRITICAL(≤0.3)。
  - **剪枝机制**：
    - 硬杀：定期扫描移除Ω_eff < 0.05的条目。
    - 预算压力剪枝：当active队列token超限（默认4096），在CRITICAL/UNSTABLE范围内根据复合剪枝分数S_prune = Ω_eff + 保留奖金 - 主题过时效罚分，逐条移除。
  - **长期记忆(LTM)**：仅存储原始文本和来源，不存分数/嵌入等派生信息，保证引擎升级后稳定。可选生成确定性卡片（MemoryCard）辅助检索。
  - **结构化检索流水线**：
    - 查询理解：解析为QueryFrame（实体、焦点、答案类型等）。
    - 证据底物构建：合并LTM原始记录、active可见记录、卡片。
    - 多通道候选生成：语义+词汇向量搜索（raw记录和卡片），硬过滤重复/失效条目。
    - 可回答性重排序：基于确定性特征（语义相似度、实体重叠、主题匹配、时效性、活跃性等）计算分数A(e,Q)。
    - 证据组装：展开卡片到原始支持轮次，返回RetrievedEvidence对象。
    - 上下文渲染：按固定模板将证据拼接至prompt。

## 3. 实验设计
- **数据集**：
  - **LoCoMo**：多会话对话数据集，包含1540个问题，分为multi-hop（282）、temporal（321）、open-domain（96）、single-hop（841）四类。
  - **LongMemEval-10**：从LongMemEval的6个类别（knowledge-update、multi-session、single-session-assistant、single-session-preference、single-session-user、temporal-reasoning）各随机采样10个问题，共60个。
- **基准方法**：**Mem0**（生产级记忆层，基于LLM提取结构化事实并存储）。
- **评价指标**：
  - Avg. Judge Score（LLM作为裁判的准确率，二值正确/错误）。
  - Exact Match（精确答案匹配归一化均值）。
  - Token F1（词法重叠F1）。
  - Token消耗统计：E2E Input、Prompt、Mem. Prompt、Mem. Compl、Mem. Total、Rec. E2E。
- **实现细节**：ChromaDB作为向量数据库，BAAI/bge-small-en-v1.5作为嵌入模型，gpt-4.1-mini生成对话，GPT-5-mini作为裁判LLM。DMF配置使用默认参数。

## 6. 主要结论与发现
- **LoCoMo结果**：DMF在所有指标上超过Mem0：平均Judge Score 0.7753 vs 0.6883（+12.6%），Exact Match 0.1039 vs 0.0747（+39%），Token F1 0.3720 vs 0.3142（+18%）。尤其在时序推理上DMF达0.7072，远超Mem0的0.1526（4倍以上）。
- **Token效率**：在LoCoMo上，DMF记忆准备零token，总token消耗（Rec. E2E）约1,059万 vs Mem0的5,665万（减少约5.4倍）；在LongMemEval-10上，DMF总token消耗约5.7万 vs Mem0的1.39亿（减少约242倍）。DMF的提示词较长（因不含摘要），但总token仍显著更低。
- **LongMemEval-10结果**：DMF平均Judge Score 0.717，Mem0 0.767（低约7%）。但在single-session-assistant类别上DMF（0.900）优于Mem0（0.600），归因于DMF保留了原始文本，能准确检索数字、列表等细节。
- **核心结论**：可以完全消除LLM在记忆管理循环中的调用，以确定性方法达到相近甚至更优的记忆召回精度，同时将token成本降低数个数量级。

## 7. 优点
- **完全确定性**：记忆状态由算法和配置唯一确定，不依赖LLM采样随机性，便于调试、审计和参数扫描。
- **接近零LLM调用成本**：记忆管理零token，仅最后的回答生成需要LLM。
- **认知启发**：采用Ebbinghaus遗忘曲线、ACT-R激活理论，将指数衰减与分数依赖性惯性结合，符合直觉。
- **源规范存储**：长期记忆仅存原始文本，派生信息在查询时重新计算，支持引擎升级。
- **结构化检索流水线**：多通道候选+可回答性重排序+证据组装，提升召回质量。
- **CPU-first**：降低对GPU依赖，适合大规模部署。

  - 缺失消融实验：嵌入模型选择、参数灵敏度、剪枝策略等均未验证。
