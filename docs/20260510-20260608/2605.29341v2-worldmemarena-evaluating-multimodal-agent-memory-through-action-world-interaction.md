## 摘要
多模态大语言模型越来越多地被部署为长周期智能体，其记忆不仅需要回忆，还必须追踪不断变化的世界、修正过时的信息，并在决策时刻提供正确的证据。现有基准测试在静态对话上衡量回忆能力，将记忆压缩为单一的任务结束准确率，并将视觉观察简化为标题，导致我们无法将失败定位到写入、维护、检索或使用环节。能够自主管理记忆的智能体框架的出现进一步加剧了这一差距，因为我们没有原则性的方法来比较手工设计的流水线与自我管理的替代方案。为了弥补这些差距，我们将多模态智能体记忆形式化为一个具有可观察四阶段生命周期的动作-世界交互循环，并在WorldMemArena中实例化：包含跨越终身演化（不断演化的个人和任务状态）和智能体执行（来自真实观察、动作和反馈的记忆）的400个多会话多模态任务，并标注了金牌记忆点、更新、干扰项和用于阶段级诊断的证据链。这使得首次能够进行长上下文、手工设计（RAG和外部记忆系统）和基于框架的记忆智能体之间的直接比较。结果表明：（1）更好的记忆写入和存储并不能保证更好的性能；（2）多模态记忆仍然难以充分利用视觉证据；（3）系统在不同领域间不稳定，且在现实智能体轨迹上性能下降；（4）框架记忆更灵活，但成本更高且可靠性较低。

## Abstract
Multimodal large language models are increasingly deployed as long-horizon agents, where memory must do more than recall: it must track an evolving world, revise what has gone stale, and surface the right evidence at decision time. Existing benchmarks measure recall over static dialogue, collapse memory into a single end-of-task accuracy, and reduce visual observations to captions, leaving us unable to localize failures to writing, maintenance, retrieval, or use. The rise of agent harnesses that author their own memory sharpens this gap, since we have no principled way to compare hand-designed pipelines with self-managing alternatives. To close these gaps, we formulate multimodal agent memory as an Action-World Interaction Loop with an observable four-stage lifecycle, and instantiate it in WorldMemArena: 400 multi-session multimodal tasks spanning Lifelong Evolution (evolving personal and task states) and Agentic Execution (memory from real observations, actions, and feedback), annotated with gold memory points, updates, distractors, and evidence chains for stage-level diagnosis. This enables the first head-to-head comparison of long-context, manually designed (RAG and external memory systems), and harness-based memory agents. Results show that: (1) better memory writing and storage do not guarantee better performance; (2) multimodal memory still struggles to fully use visual evidence; (3) systems are unstable across domains and degrade on realistic agentic trajectories; and (4) harness memory is more flexible but remains costly and less reliable.

## 1. 论文的核心问题与整体含义（研究动机和背景）

当前多模态大语言模型正从问答系统转向在动态环境中长期行动的智能体，其记忆机制不再仅是过去文本的缓存，而需要跟踪演化中的世界、修正过时信息，并在决策时刻提供正确证据。然而，现有基准存在三个关键缺陷：
- **仅测试静态对话召回**，而非动态使用经验指导未来行为。
- **报告单一最终准确率**，无法定位记忆失败发生在写入、维护、检索还是使用阶段。
- **文本中心**，常将图像转化为标题，缺乏真实交互压力和多模态证据的使用。

同时，智能体框架（如OpenClaw、Codex）允许智能体自主管理记忆，模糊了记忆模块与策略的界限。因此，论文提出一个问题：**当智能体能在真实环境中持续行动并管理自身经验时，应如何评估其记忆？** 为此，论文将多模态智能体记忆形式化为一个动作-世界交互循环，并构建了WorldMemArena基准，以支持阶段级诊断。

## 2. 论文提出的方法论

### 核心思想：记忆作为动作-世界交互循环
将智能体与环境交互建模为：在每个时间步，智能体从部分可见的世界状态`z_t`获得观察`o_t`，基于当前记忆`m_t`选择动作`a_t`，环境更新状态并返回反馈`f_t`。整个过程可表示为：

- `o_t = Ω(z_t)`, `a_t = π(o_t, m_t)`, `(z_{t+1}, f_t) = E(z_t, a_t)`

完整轨迹`τ = (x; η_1, ..., η_T)`，其中每个事件`η_t = (o_t, a_t, f_t)`。轨迹划分成多个会话`τ^{(1)} ◦ τ^{(2)} ◦ ... ◦ τ^{(S)}`。

### 四阶段记忆生命周期
1. **观察写入（Observe to Write）**：判断当会话中哪些信息对未来有​​用，产生记忆增量`Δ_s`。
2. **更新与巩固（Update and Consolidate）**：将新写入信息集成到现有记忆，支持修订和合并。
3. **检索决策（Retrieve for Decision）**：当未来查询到来时，获取正确的证据。
4. **使用行动（Use and Act）**：从检索到的证据生成最终响应或动作。

### 数据构建管线
采用统一自动化构造流程：1) 将原始数据分割为多会话实例；2) 从每个会话窗口提取金牌记忆点（事实、更新、未来问题所需证据）；3) 跨会话合并、修订、去重；4) 从精化后的记忆点构建问题-答案对。所有数据经2-3名人工审核确保质量。

## 6. 论文的主要结论与发现

1. **高存储质量不保证高QA性能**：许多系统记忆召回率高但证据检索和最终回答质量低，关键在于是否能在回答时正确使用。
2. **多模态记忆仍然是主要瓶颈**：文本为主的系统（如MemGPT）反而稳定，多模态系统（如ViLoMem）视觉信息转化为可用记忆效果差。
3. **跨域不稳定，智能体执行任务性能下降**：在终身演化场景优于智能体执行场景；具身任务（如导航）最具挑战。
4. **框架记忆灵活但成本高可靠性低**：OpenClaw/Codex超越多数手工系统，但计算开销大，框架依赖性导致不稳定。
5. **记忆维护以仅追加为主，很少主动修订**：系统更倾向于累积而非更新/删除旧信息，导致干扰和冲突。
6. **检索是最终性能的关键瓶颈**：检索时引入冗余或过时证据反而降低质量；检索仍依赖文本代理，视觉信息丢失。

- **数据集丰富**：覆盖终身演化和智能体执行两种互补场景，含大量图片和细粒度标注（记忆点、更新、干扰、证据链），规模远超现有基准。

## 8. 不足与局限

- **数据规模与多样性**：仅461个任务，覆盖6个领域+具身动作，但领域数量有限，可能无法代表所有真实应用。
- **LLM-as-Judge偏差**：所有记忆点和答案由GPT-5.4-mini评判，可能对某些类型（如多模态、推理）存在系统性偏好，且未提供人工验证的校准结果。
- **消融实验不足**：未对手工系统的各组件（如不同检索策略、摘要模式、更新规则）进行孤立消融，无法归因具体模块优劣。
- **框架记忆分析简化**：框架记忆的内部过程不可分解，仅作端到端评价，缺少阶段级诊断，结论停留于表面。
- **计算成本与可扩展性**：未讨论框架智能体在更大规模任务上的耗时和资源需求；手工系统中SimpleMem等耗时近800秒/任务，实用性存疑。
- **语言和环境局限**：所有任务为英文，场景未覆盖多语言、异构环境或更复杂的长期协作。
- **评估目标**：当前仍以问答准确率为核心，无法直接衡量记忆对未来行为改善的贡献。作者已指出需推进“从经验中学习”的评估，但本基准本身未实现这一点。
