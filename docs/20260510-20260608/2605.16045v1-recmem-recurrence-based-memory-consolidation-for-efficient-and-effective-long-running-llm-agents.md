## 摘要
记忆系统通常将用户-代理交互组织为可检索的外部记忆，对于长运行代理而言至关重要，因为它能克服LLM有限的上下文窗口。然而，现有记忆系统会调用LLM处理每个传入交互以提取记忆，这种急切的记忆巩固方案导致了大量的令牌消耗。为解决此问题，我们提出RecMem，重新思考何时应进行记忆巩固。RecMem将传入交互存储在潜意识记忆层中，并使用轻量级嵌入模型进行编码以便检索。仅当观测到语义相似的交互持续递归时，才调用LLM提取情景记忆和语义记忆。这种基于递归的巩固之所以有效，是因为这些交互对应一个信息丰富的语义聚类，因此值得提取和总结。为了提高准确性，RecMem还包含一个语义细化机制，用于恢复记忆提取遗漏的细粒度事实。实验表明，RecMem将三种最先进记忆系统的记忆构建令牌成本降低了高达87%，同时超过了它们的准确性。

## Abstract
Memory systems often organize user-agent interactions as retrievable external memory and are crucial for long-running agents by overcoming the limited context windows of LLMs. However, existing memory systems invoke LLMs to process every incoming interaction for memory extraction, and such an eager memory consolidation scheme leads to substantial token consumption. To tackle this problem, we propose RecMem by rethinking when memory consolidation should be conducted. RecMem stores incoming interactions in a subconscious memory layer and encode them using lightweight embedding models for retrieval. LLMs are only invoked to extract episodic and semantic memory when sustained recurrence are observed for semantically similar interactions. Such recurrence-based consolidation works because these interactions correspond to a semantic cluster with rich information and thus are worth extraction and summarization. To improve accuracy, RecMem also incorporates a semantic refinement mechanism that recovers the fine-grained facts omitted by memory extraction. Experiments show that RecMem reduces the memory construction token cost of three SOTA memory systems by up to 87% while exceeding their accuracy.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有基于外部记忆的LLM代理系统（如Zep、Mem0、A-Mem等）在处理每个用户-代理交互时，都会立即调用LLM进行记忆提取和合并（称为“急切记忆巩固”），导致巨大的令牌（token）消耗，使得这些系统在实际部署中成本高昂。
- **整体含义**：并非所有交互都值得立即进行LLM级别的处理——有些交互信息量少或包含噪声，有些交互与现有记忆无关，可被直接查询。论文借鉴认知科学中的“多存储器理论”和“互补学习系统框架”，提出仅在观察到语义相似的交互持续重复（即“递归”）时才触发LLM巩固，从而大幅降低记忆构建成本，同时保持甚至提升任务准确性。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **整体架构**：RecMem是一个三层次记忆系统，包括：
  - **潜意识记忆（Subconscious Memory）**：轻量级存储层，使用嵌入模型（如text-embedding-3-small）对每个完整的用户-助手交互单元（一个回合）进行向量化，并直接存入向量数据库，不调用LLM。所有未触发巩固的原始交互都保留在此层，可通过语义检索访问。
  - **情景记忆（Episodic Memory）**：存储按时间组织的叙事性摘要，描述一个主题如何在多个交互回合中演变。采用“先合并再处理”策略：新交互到来时，先检查是否能合并到已有情景记忆中（若语义相似度≥阈值）；若不能合并，则等待递归触发。
  - **语义记忆（Semantic Memory）**：存储原子事实（如用户偏好、实体关系等），通过“语义细化”机制从情景记忆及其对应的原始交互中提取，专门恢复情景摘要遗漏的细粒度细节。

- **递归式巩固机制**：
  - 当新交互单元 `s_i` 到来时，系统从潜意识存储中检索 `top-k` 个与其余弦相似度最高的单元，筛选出相似度 ≥ `θ_sim` 的交互集 `R_i`。
  - 若 `|R_i| ≥ θ_count`（递归计数阈值），则触发巩固：将该聚类 `C_i = R_i ∪ {s_i}` 交给LLM生成情景记忆，并基于这些交互和已有语义记忆执行语义细化。
  - 否则，交互仅留在潜意识层。

- **关键公式与流程**（文字说明）：
  - 交互单元定义：`u_i = (user_message, assistant_message, timestamp)`
  - 潜意识存储：`s_i = (v_i, u_i)`, 其中 `v_i = Φ(u_i)` 为嵌入向量。
  - 情景记忆合并条件：`cos(v_i, v_{E*}) ≥ θ_sim` 时，调用LLM将 `u_i` 合并到最近的情景记忆 `E*` 中。
  - 语义细化：对于每个新产生的情景记忆 `E`，检索相关旧语义事实 `V`，然后让LLM基于原始交互 `U_C`、情景摘要 `E` 和旧事实 `V` 提取新的事实 `M_sem`。

- **查询回答**：将用户查询编码为向量，从三个记忆层分别检索固定预算的项目（`k_sub=10`, `k_epi=5`, `k_sem=10`），合并后交给LLM生成答案。

- **效率提升巨大**：RecMem在LoCoMo上将记忆构建令牌消耗降低高达87.3%（与Mem0相比），在LongMemEval-S上降低77.5%，同时保持或提升总体准确率。

- **三层记忆互补**：潜意识层提供原始事实保障，情景层提供跨回合链接，语义层提供细粒度细节。移除任何一个模块都会导致性能下降（图2），其中潜意识层最为关键。
- **语义细化有效恢复遗漏细节**：直接提取语义事实（无情景参考）的效果低于基于情景摘要的语义细化，表明情景记忆提供了关键上下文信号。

## 7. 优点

- **实用性**：大幅降低token消耗，使长期运行代理更加经济可行，且查询阶段成本与基线相当，因此在流式部署中累积节省巨大。
