## 摘要
长期智能体记忆日益多模态化，然而现有评估很少测试智能体是否保留后续推理所需的视觉证据。在先前工作中，许多基于视觉的问题仅凭字幕或文本痕迹即可回答，从而无需保存细粒度视觉证据即可推断答案。同时，需要推理随时间变化的视觉状态的更困难案例则基本缺失。因此，我们引入了MemEye，该框架从两个维度评估记忆能力：一个维度衡量决定性视觉证据的粒度（从场景级到像素级证据），另一个维度衡量检索到的证据必须如何使用（从单一证据到进化综合）。在此框架下，我们构建了涵盖8个生活场景任务的新基准，并设置了基于消融的验证门，用于评估可回答性、捷径抵抗性、视觉必需性以及推理结构。通过评估4个VLM主干上的13种记忆方法，我们展示了当前架构在保留细粒度视觉细节和推理随时间变化的状态方面仍然存在困难。我们的发现表明，长期多模态记忆依赖于证据路由、时间跟踪和细节提取。

## Abstract
Long-term agent memory is increasingly multimodal, yet existing evaluations rarely test whether agents preserve the visual evidence needed for later reasoning. In prior work, many visually grounded questions can be answered using only captions or textual traces, allowing answers to be inferred without preserving the fine-grained visual evidence. Meanwhile, harder cases that require reasoning over changing visual states are largely absent. Therefore, we introduce MemEye, a framework that evaluates memory capabilities from two dimensions: one measures the granularity of decisive visual evidence (from scene-level to pixel-level evidence), and the other measures how retrieved evidence must be used (from single evidence to evolutionary synthesis). Under this framework, we construct a new benchmark across 8 life-scenario tasks, with ablation-driven validation gates for assessing answerability, shortcut resistance, visual necessity, and reasoning structure. By evaluating 13 memory methods across 4 VLM backbones, we show that current architectures still struggle to preserve fine-grained visual details and reason about state changes over time. Our findings show that long-term multimodal memory depends on evidence routing, temporal tracking, and detail extraction.

## 6. 主要结论与发现
- **当前系统远未饱和**：最佳方法SRAG(V)在开放题上LLM-as-a-Judge仅0.4937（满分1），在多选题上EM为0.6177。
- **三个关键失败模式**：
  1. **细粒度视觉证据丢失**：文本型记忆在低X（场景/区域级）表现接近图像型，但在高X（实例/像素级）显著落后。Caption-Proof增益在高X区域最大（SRAG(V)在X3、X4的增益达+0.19~+0.29）。
  2. **过时证据选择**：Y3（进化综合）问题中，检索方法常“检索到相关但过时的证据”。即使检索到最新线索，语义相似度也不能保证时间有效性（Stale-Dominance高达0.767）。
  3. **无法综合当前状态**：当视觉状态被更新时（如物体移动、标签替换），记忆系统难以优先选择最新有效状态。提供最新状态（latest-only oracle）比完整线索链略低，但仍远高于所有记忆系统。
- **权衡**：文本记忆有利于跟踪状态更新但丢失视觉细节；图像记忆保留细节但难以确定时间有效性。
- **跨主题扩展**：全历史方法（FC(V)）随无关历史增加而下降，检索型方法（SRAG(V)）更稳定。

## 7. 优点
1. **创新的二维评估框架**：系统化分离“视觉证据粒度”和“记忆推理深度”，使得失败原因可定位。
2. **严格的基准质量控制**：通过多重验证门（可回答性、捷径抵抗、视觉必需性、推理结构审计）确保问题具有诊断价值。
3. **丰富的诊断实验**：包括Caption替换、Oracle证据、检索召回、时序重排序、跨主题缩放等，深入揭示失败本质。
4. **覆盖多种真实场景**：8个生活任务涉及休闲、家庭、专业、个人等，图像来源多样化（照片、截图、漫画、生成图像）。
5. **公开可用**：提供了项目页面、代码和数据集。

## 8. 不足与局限
1. **基准规模有限**：共371个问题，每个（X,Y）格子样本量较小（如Y3×X4仅30个问题），可能导致统计波动。
2. **方法比较非严格公平**：各方法使用官方推荐嵌入和检索设置，而非统一编码器，因此结论应视为系统级趋势，而非方法间的精确排名。
3. **人类基线仅有小规模示例**：在附录B.3中仅对部分问题做了人类验证，未提供完整的人类上限参考。
4. **未涉及隐私与安全考虑**：论文指出更强视觉记忆可能带来隐私风险，但未给出解决方案。
5. **仅诊断性而非全面部署**：作者声明MemEye是诊断性基准，不能完全替代真实部署测试。未来工作需扩展到更大规模对话和更多样化架构。
6. **Y3问题的细节**：进化综合问题中，部分只需要确定最新状态，少数需要对比前后变化。研究主要聚焦“最新状态识别”，对“变化本身推理”的覆盖有待加强。
