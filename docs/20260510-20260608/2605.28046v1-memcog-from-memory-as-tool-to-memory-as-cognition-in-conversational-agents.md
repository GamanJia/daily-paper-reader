## 摘要
现有智能体记忆系统普遍遵循我们所谓的“记忆即工具”范式，其中单一查询触发平面段落列表的一次性检索，存在被动调用、推理-检索解耦以及检索片段与智能体导航需求之间的结构不匹配等问题。我们提出MemCog，一种“记忆即认知”系统，使记忆访问成为推理过程不可或缺的一部分。MemCog将用户知识组织为具有关联链接图的可导航记忆存储，提供跨维度导航接口以实现多步推理驱动遍历，并采用主动推理协议，驱动智能体从对话上下文自发启动记忆探索。此外，我们构建了ProactiveMemBench，这是首个评估主动记忆触发的基准测试。实验表明，MemCog在被动问答基准测试上达到了最先进水平（LoCoMo上92.98，LongMemEval上95.8），同时在ProactiveMemBench上显著优于基线，证明了“记忆即认知”的优势。

## Abstract
Existing agent memory systems universally follow what we term a Memory-as-Tool paradigm where a single query triggers one-shot retrieval of flat passage lists, suffering from passive invocation, reasoning-retrieval decoupling, and structural mismatch between retrieved fragments and the agent's navigational needs. We propose MemCog, a Memory-as-Cognition system that makes memory access an integral part of the reasoning process. MemCog organizes user knowledge as Navigable Memory Store with associative link graphs, exposes Cross-Dimensional Navigation Interface for multi-step reasoning-driven traversal, and employs Proactive Reasoning Protocol that drives agents to spontaneously initiate memory exploration from conversational context. We additionally construct ProactiveMemBench, the first benchmark for evaluating proactive memory triggering. Experiments show that MemCog achieves state-of-the-art on passive QA benchmarks (92.98 on LoCoMo, 95.8 on LongMemEval) while substantially outperforming baselines on ProactiveMemBench, demonstrating the advantage of Memory-as-Cognition.

## 1. 核心问题与研究动机（背景与整体含义）

- **现有范式的问题**：当前对话智能体记忆系统普遍遵循 **Memory-as-Tool** 范式，即单一查询触发一次性的平面段落列表检索。该范式存在三大根本性限制：
  - **调用瓶颈（Invocation Bottleneck）**：记忆系统仅在智能体显式发起工具调用时才被激活，缺乏主动触发能力；现有基准仅评估事实性问题，忽视日常对话中的主动记忆触发模式。
  - **推理-检索解耦（Reasoning-Retrieval Decoupling）**：一次性检索无法让智能体在结果不足时动态规划进一步探索，推理能力无法介入检索流程。
  - **结构不匹配（Structural Mismatch）**：返回的 top-k 片段缺乏结构导航信息，无法引导智能体进行定向迭代检索。

- **论文整体含义**：提出 **Memory-as-Cognition** 范式，将记忆访问从被动预处理步骤转变为智能体推理过程的核心组成部分。通过结构化导航、多步推理驱动遍历和主动触发协议，实现记忆与推理的紧密耦合。

## 2. 方法论：核心思想与技术细节

### 2.1 核心思想
- 设计三个紧密集成的组件：**Navigable Memory Store**（可导航记忆存储）、**Cross-Dimensional Navigation Interface**（跨维度导航接口）、**Proactive Reasoning Protocol**（主动推理协议）。三者协同实现从“记忆即工具”到“记忆即认知”的转变。

### 2.2 关键技术细节

#### (a) Navigable Memory Store
- **层次化组织**：三级粒度——**维度**（顶层类别，如个人偏好、工作）、**页面**（每个维度内的独立知识单元）、**章节**（页面内的细粒度信息块，包含标题、摘要、结构化事实、关联页面、时间戳和置信度）。
- **跨维度关联链接**：定义四种链接类型支持不同推理模式：
  - `related_to`：语义关联（跨维度）
  - `temporal_next`：时间先后顺序
  - `caused_by`：因果关系
  - `contrasts_with`：对比关系
- **构建与演化**：初始通过LLM从对话历史提取事实、聚类生成页面和链接；增量更新时匹配新信息到现有页面或创建新页面，并进行矛盾检测和置信度更新。

#### (b) Cross-Dimensional Navigation Interface
- 提供四种多粒度导航行动，取代单一搜索工具：
  - `list_dimensions()`：返回所有维度及描述
  - `browse_dimension(dim)`：返回指定维度内的页面标题和摘要
  - `read_page(page_id)`：返回页面全部内容及关联链接
  - `follow_link(link)`：沿超链接导航到目标页面
- 每个行动不仅返回内容，还返回结构上下文（可用链接、兄弟页面、位置），以支持后续导航决策。

#### (c) Proactive Reasoning Protocol
- 通过系统提示实现，规定两种记忆参与模式：
  - **主动关联**：当对话上下文提及人物、地点、主题等可能链接到存储知识时，智能体自发启动记忆导航。
  - **反应式响应**：当用户明确询问过去信息时，智能体导航记忆。
- **选择性呈现**：智能体在呈现前评估信息的四维（相关性、时效性、敏感性、冗余性），由LLM在思考阶段自主完成，无需额外门控模块。

### 2.3 算法流程（文字说明）
1. 系统初始化：构建Navigable Memory Store（根据对话历史生成页面和链接）。
2. 对话过程中：
   - 智能体接收用户输入，进入ReAct循环（Think → Act → Observe）。
   - 若上下文触发主动关联条件，智能体自主调用导航工具（如 `browse_dimension`、`read_page`）进行多步探索。
   - 每一步返回的结构上下文（可见链接、层次位置）引导下一步行动。
   - 推理完成后，智能体选择性呈现相关信息，并生成回复。
3. 更新：每轮对话后增量更新记忆存储。

## 6. 主要结论与发现

1. **内存即认知范式有效**：MemCog在LoCoMo上达到92.98（GPT-4.1-mini）、LongMemEval上95.8，均为SOTA，证明多步推理与结构化导航不牺牲被动QA性能。
2. **主动触发能力显著提升**：在ProactiveMemBench上，MemCog的Recall@5为59.51，LLM精密度87.58，人工精密度91.02，大幅超越所有基线。
3. **组件互补协同**：

4. **记忆访问是一个谱系**：从无记忆→单次搜索→多步导航→自发回忆，MemCog沿谱系前进，但未达到理论端点。

## 8. 不足与局限

- **计算开销**：多步导航增加token消耗和延迟，尽管论文声称通常只需2-3步，但在成本敏感场景下仍可能不可忽视。
