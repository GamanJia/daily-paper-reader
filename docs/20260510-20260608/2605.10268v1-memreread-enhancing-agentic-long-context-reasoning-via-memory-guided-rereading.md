## 摘要
为了在不采用标准注意力机制的二次复杂度的情况下处理长上下文推理任务，基于智能体记忆的方法应运而生，这些方法通常在逐块线性处理文档时维护一个动态更新的记忆。为了减轻这种边读边记忆范式中潜在证据丢失的问题，近期的工作集成了检索模块，允许智能体回忆先前在记忆覆盖过程中丢弃的信息。然而，基于检索的回忆既遭受记忆形成过程中的证据丢失，又受到无效查询引起的干扰。为了克服这些限制，我们提出了MemReread。基于流式阅读，MemReread绕过了中间检索。当最终记忆不足时，它会触发问题分解和重读，从而能够恢复过早丢弃的间接事实。这种设计支持非线性推理，同时保留了文档理解的内在逻辑流程。为了进一步提升实用性，我们引入了一个强化学习框架，该框架增强了长度外推能力，同时根据任务复杂度动态确定重读次数，从而灵活控制计算开销。大量实验表明，MemReread在长上下文推理任务上持续优于基线框架，同时保持相对于上下文长度的线性时间复杂度。

## Abstract
To tackle long-context reasoning tasks without the quadratic complexity of standard attention mechanisms, approaches based on agent memory have emerged, which typically maintain a dynamically updated memory when linearly processing document chunks. To mitigate the potential loss of latent evidence in this memorize-while-reading paradigm, recent works have integrated retrieval modules that allow agents to recall information previously discarded during memory overwriting. However, retrieval-based recall suffers from both evidence loss during memory formation and interference induced by invalid queries. To overcome these limitations, we propose MemReread. Built upon streaming reading, MemReread circumvents intermediate retrieval. It triggers question decomposition and rereading when the final memory is insufficient, enabling the recovery of indirect facts that were prematurely discarded. This design supports non-linear reasoning while preserving the inherent logical flow of document comprehension. To further enhance practicality, we introduce a reinforcement learning framework that enhances length extrapolation capability while dynamically determining the number of rereading passes based on task complexity, thereby flexibly controlling computational overhead. Extensive experiments demonstrate that MemReread consistently outperforms baseline frameworks on long-context reasoning tasks, while maintaining linear time complexity with respect to context length.

## 1. 核心问题与整体含义（研究动机和背景）
**核心问题**：长上下文推理任务中，基于代理记忆（agent memory）的方法采用“边读边记”范式，会在内存更新时丢失潜在证据（latent evidence）；现有检索增强方案虽然可以回溯历史记忆，但面临**永久性证据丢失**（早期间接事实从未被存储到任何历史记忆中）和**无效查询干扰**（无法区分已覆盖和未读内容，检索到噪声污染记忆）两大局限。

**整体含义**：针对上述缺陷，本文提出 **MemReread**——一种记忆引导的重读机制，在不引入检索模块的前提下，通过问题分解和定向重读来恢复被丢弃的间接事实，从而实现非线性推理，同时保留文档阅读的逻辑连贯性。

## 2. 方法论
### 核心思想
将“阅读”与“推理”解耦：阅读阶段只负责信息采集，推理阶段在每次阅读完成后才被触发，用于判断信息是否充足并决定是否需要重读。通过记忆引导的子问题分解与重读，动态恢复缺失证据。

### 关键技术细节
- **四个阶段**：
  1. **Read**：采用流式阅读（MemAgent范式），顺序处理文档块，维护固定大小的记忆缓冲。
  2. **Decompose**：基于最终记忆判断是否足够回答问题；若不足，生成最优先的子问题（sub-question），要求子问题可独立回答且不重复历史查询。
  3. **Integrate**：针对子问题执行重读，得到子答案，然后将子问题-答案对整合到根记忆（root memory）中，直接丢弃中间子记忆。
  4. **Answer**：当记忆充足时，直接基于根记忆生成最终答案。
- **强化学习训练**：提出 **Rereading-Adaptive GRPO (ReA-GRPO)**，结合过程奖励（状态级）和结果奖励（自适应性）。
  - **过程优势**：沿用 ReMemR1 的状态奖励，衡量每步记忆的信息量增益。
  - **结果优势**：根据同一组 rollout 的正确性和重读次数动态调整：全对时鼓励少重读，全错时鼓励多重读，部分正确时按重读次数归一化正/负优势。
  - 最终优势：$\hat{A}^{(g)}_{p,t} = \alpha \hat{A}^{(g)}_{out} + (1-\alpha)\hat{A}^{(g)}_{state,p,t}$。
- **算法流程**（伪代码）：在完成一轮全阅读后，循环进行“分解 → 重读 → 整合”，直到记忆充分或达到最大重读次数 $p_c$。

## 6. 主要结论与发现
- **性能提升**：MemReread 在几乎所有任务上超越 MemAgent 和 ReMemR1，尤其在 OOD 的 2WikiMultiHopQA 上最高提升 12.1%（4B 规模）。
- **自适应重读**：ReA-GRPO 能根据任务难度动态调整重读次数，在简单任务（如 RULER-QA 线性推理）几乎不重读，在复杂任务则适当重读，优于标准 GRPO。
- **线性复杂度**：时间 $O(p_c n)$，空间 $O(1)$（不存储历史记忆），而 ReMemR1 空间随上下文线性增长。
- **可迁移性强**：即使使用其他框架（MemAgent/ReMemR1）的训练权重，MemReread 也能获得显著增益，表明重读机制是流式代理的通用增强手段。

## 7. 优点
1. **创新机制**：将重读与记忆引导结合，避免检索干扰，同时恢复关键间接证据。
2. **训练策略**：ReA-GRPO 自适应控制计算开销，实现性能-效率平衡。
3. **工程友好**：时间复杂度线性、空间常数，适合资源受限场景。
4. **实验全面**：涵盖多个尺度、架构、任务类型、零样本和迁移场景，结果具有说服力。
5. **可解释性**：通过子问题生成和重读过程提供了透明的推理步骤。

## 8. 不足与局限
1. **任务泛化有限**：仅评估了长上下文多跳问答，未涉及代码理解、文本摘要、长文本生成等其他长上下文任务。
2. **推理延迟**：相比纯流式阅读（MemAgent），重读带来 3~4 倍的时间开销，对实时性要求高的场景不够理想。
3. **依赖模型固有推理能力**：失败案例表明，即使信息充分，模型仍可能因实体绑定错误、冲突解决失败（integration 阶段）而答错，说明方法受限于骨干模型本身。
4. **最大重读次数上限**：$p_c=3$ 在实际中已足够，但 $p_c=4$ 仍能继续提升，理论上有进一步优化空间（但推理成本也更高）。
5. **训练复杂度**：强化学习训练需多轮 rollout，对算力需求较高，可能限制在更大模型上的直接应用。
