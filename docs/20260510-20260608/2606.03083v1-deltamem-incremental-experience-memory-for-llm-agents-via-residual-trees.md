## 摘要
基于大语言模型（LLM）的智能体在持续交互中越来越依赖记忆来从经验中学习。然而，将经验存储为独立的、扁平的单元会导致大量冗余和检索冲突，因为相似的情节重复出现重叠内容，而细微的场景变化又使检索到的记忆提供矛盾的指导。为解决此问题，我们引入残差经验概念，认为新获得的经验通常是已有知识的增量变化。我们提出DeltaMem框架，将经验记忆组织为两个独立的残差树：一个存储以目标为导向的任务经验作为可复用技能，另一个存储场景级的环境知识。每棵树使用根节点表示泛化的基础经验，增量节点表示后续变化，使相关经验共享共同基础而无需重复存储。检索时，采用失败惩罚的相似度扫描定位最佳匹配，并通过根到匹配节点的链组合重建完整经验。一种自主整合机制将高频路径提炼为新的根节点，使树能从通用启发式自组织为专门化的变体。在多种交互环境中的实验表明，DeltaMem始终优于现有基线。为促进未来研究，我们在 https://github.com/import-myself/DeltaMem 发布代码。

## Abstract
Large Language Model (LLM)-based agents increasingly rely on memory to learn from experiences over continual interactions. However, storing experiences as independent, flat units leads to substantial redundancy and retrieval conflicts, as similar episodes repeat overlapping content and subtle scene variations cause retrieved memories to offer contradictory guidance. To address this, we introduce residual experience, positing that newly acquired experience is often an incremental variation of existing knowledge. We propose DeltaMem, a framework that organizes experience memory into two independent residual trees, one storing goal-conditioned task experience as reusable skills and another for scene-level environment knowledge. Each tree uses a root node for generalized base experiences and incremental delta nodes for subsequent variations, allowing related experiences to share a common foundation without duplication. For retrieval, a failure-penalized similarity scan locates the best match, reconstructing the full experience via root-to-match chain composition. An autonomous consolidation mechanism distills high-frequency paths into new root nodes, enabling the trees to self-organize from general heuristics to specialized variants. Experiments across diverse interactive environments show that DeltaMem consistently outperforms existing baselines. To facilitate future research, we release the code at https://github.com/import-myself/DeltaMem.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想：残差经验 + 结构解耦
- **残差经验（Residual Experience）**：新经验往往是已有知识的增量变化，只存储与最相似已有经验的差异部分（delta），避免重复存储。
- **结构解耦**：将经验分为两个正交维度——任务策略（Task Policy）和环境知识（Environment Knowledge），分别由两个独立的残差树管理。

### 关键技术细节
- **双树记忆架构**：
  - **Task-Tree**：存储以目标为导向的动作策略，每个技能节点包含 `⟨α, π, ω⟩`（激活条件、执行步骤、终止条件）。
  - **Env-Tree**：存储场景级声明性知识，每个知识节点包含 `⟨α, κ⟩`（场景触发条件、环境事实）。
- **残差树结构**：
  - 根节点（ROOT）：保存完整的、泛化的基础经验。
  - 残差节点（RESIDUAL）：仅保存相对于父链的增量修改（ΔP），不重复共享内容。
  - 节点还包含标签（成功/失败）、深度、成功命中计数、嵌入向量等。
- **写入决策**（公式4）：
  - 冷启动（相似度 < τ_base）：插入根节点。
  - 热启动（相似度 ≥ τ_base）：在最佳匹配节点下附加增量节点。若深度已达最大值 D_max，则作为兄弟节点附加。
- **检索与链重建**：
  - 全局平坦扫描所有节点，计算相似度并减去失败惩罚项 ε（默认0.05），选择得分最高的节点作为匹配点。
  - 重建：沿根→匹配路径拼接所有节点内容（根基础 + 各delta），形成完整、无冲突的记忆上下文。
- **经验提取协议**：每次交互后，用LLM从原始轨迹中提取结构化节点（如Root-Success提取完整技能，Residual-Success提取最小delta）。
- **自主记忆整合（Consolidation）**：
  - 跟踪非根节点的成功命中计数 c(v)，当 c(v) ≥ K_cons 时，将整条路径通过LLM蒸馏为一个新的根节点，并标记原节点为已整合。
  - 使高频路径升级为根节点，记忆层次从通用启发式自组织为专门化变体。

## 6. 论文的主要结论与发现

- DeltaMem通过残差树结构有效消除了记忆冗余和检索冲突，在ALFWorld、ScienceWorld、WebShop上均显著优于或持平现有基线。

- 自主记忆整合机制（K_cons < ∞）具有正则化效果，使系统对参数选择更鲁棒，并促进记忆层次自组织。
- 离线预构建的DeltaMem记忆库可直接迁移至新任务，冻结或继续更新均表现良好，优于扁平存储方法（AWM、ReasoningBank）。

## 8. 不足与局限

- **提取质量敏感**：节点提取质量受底层LLM能力影响，低质量提取可能向记忆树引入噪声。
- **参数需人工调优**：τ_base和K_cons需在基准小样本上选择，未实现自动跨域泛化。
