## 摘要
记忆是LLM智能体在长视界任务中运行的核心能力。现有的记忆基准主要评估在多轮对话场景中对个性化信息的保持，忽略了智能体长时间执行过程中发生的动态记忆形成。因此，它们产生的记忆系统在真实的智能体环境（如编码和网页导航）中迁移性差。我们提出了MemGym，一个用于智能体记忆的基准，它将现有的智能体gym和内部的基于记忆的流水线统一在一个记忆推理接口之后。MemGym跨越五个评估轨道，分为四个智能体领域：工具使用对话（tau2-bench）、多轮深度研究搜索（MEMGYM-DR）、编码（SWE-Gym和MEMGYM-CODEQA）以及计算机使用（WebArena-Infinity）。MemGym报告记忆隔离得分，将记忆性能与推理、检索和工具使用能力解耦，从而可以在没有这些干扰因素的情况下对记忆策略进行排名。我们为MEMGYM-CODEQA和MEMGYM-DR设计的合成流水线长度可控，每个阶段都经过消融验证，并与下游场景紧密对齐。为了使编码环境中的评估在学术上易于处理，我们训练了MemRM，一个轻量级奖励模型（使用QLoRA微调的Qwen3-1.7B），它通过快速标量读取来评分压缩质量，取代了完整的Docker部署。

## Abstract
Memory is a central capability for LLM agents operating across long-horizon tasks. Existing memory benchmarks predominantly evaluate retention of personalized information in multi-turn chat scenarios, overlooking the dynamic memory formation that occurs during extended agent execution. Consequently, the memory systems they produce transfer poorly to realistic agentic environments, such as coding and web navigation. We present MemGym, a benchmark for agentic memory that unifies existing agent gyms and in-house memory-grounded pipelines behind one memory-reasoning interface. MemGym spans five evaluation tracks grouped into four agentic regimes: tool-use dialogue (tau2-bench), multi-turn deep-research search (MEMGYM-DR), coding (SWE-Gym and MEMGYM-CODEQA), and computer use (WebArena-Infinity). MemGym reports memory-isolated scores that decouple memory performance from reasoning, retrieval, and tool-use ability, so memory strategies can be ranked without those confounders. Our synthetic pipelines for MEMGYM-CODEQA and MEMGYM-DR are length-controllable, ablation-verified at every stage, and tightly aligned with downstream scenarios. To make evaluation on coding environments academically tractable, we train MemRM, a lightweight reward model (Qwen3-1.7B fine-tuned with QLoRA) that scores compression quality as a fast scalar read in place of full Docker rollouts.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有LLM智能体记忆基准多聚焦于多轮对话中的个性化信息保留（静态回忆），忽略了智能体在执行长视界任务（如编码、网页导航、多轮搜索）时与工具交互、推理、行动交织的动态记忆形成过程。这导致现有记忆系统在真实场景中迁移性差。
- **背景与动机**：长时任务中，智能体必须持续决定保留、总结或丢弃哪些信息（记忆形成）。然而，现有基准存在三大障碍：
  - **度量纠缠**：端任务成功率混淆了记忆失败与推理、检索、工具使用错误。
  - **虚假记忆压力**：许多看似记忆密集的任务，实际上无需显式记忆管理（事实可从仓库或预训练中恢复）。
  - **评估成本高**：单次SWE-Gym部署需Docker基础设施和数十步执行，阻碍学术研究进行系统性的记忆策略迭代。
- **整体含义**：需要将智能体记忆作为独立的一类评估目标，而非混入任务准确率中。MemGym旨在提供统一、记忆隔离、低成本的评估框架，使记忆策略可被公平比较和优化。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将记忆模块与推理模型显式分离：定义一个统一每步接口（manage_context），记忆模块在提示词送入策略LLM前对其进行包装（压缩、总结、检索），使同一记忆策略可跨环境运行。
- **记忆隔离评分**：报告成对基线vs带记忆部署间的差异Δ（记忆增益），固定推理模型，解耦记忆与推理/检索/工具使用。
- **轻量评估信号**：训练MemRM奖励模型预测“压缩后行为是否改变”，取代完整Docker部署。

### 关键技术细节
1. **统一记忆基础设施**：
   - 五个环境（τ2-bench、SWE-Gym、WebArena-Infinity、MEMGYM-DR、MEMGYM-CODEQA）共享BaseMemoryManager、BaseAgent、BaseRunner等公共基类。
   - 每步循环：`env.reset() → memory_manager.manage_context → agent.act → env.step`。
   - 支持四种记忆操作族：直通（passthrough）、LLM总结、结构化总结（按环境定制）、检索式记忆。
   - 提供`repair_tool_call_pairs`原语，防止压缩导致工具调用-结果配对失效。

2. **MemRM轻量奖励模型**：
   - 任务：给定（压缩前上下文、压缩后上下文、候选动作）三元组，预测P(行为不变|压缩)，输出SAFE/HARMFUL标签。
   - 训练数据：18.6K条SWE-Gym压缩事件标签，通过三类来源生成（轨迹级任务解决、反事实重放、LLM作为裁判）。
   - 模型：基于Qwen3-1.7B-Base，QLoRA微调（NF4 4-bit, rank=16, α=32, 目标{q,k,v,o}投影），使用类平衡交叉熵损失。
   - 推断时通过阈值t*分类（约束：HARMFUL-F1≥0.90, SAFE精确率≥0.80）。
   - 效果：在SWE-Gym IID上AUROC 0.985，ECE 0.009；在分布外场景部分泛化（策略OOD AUROC 0.71, 场景OOD AUROC 0.75）。

3. **合成管道（MEMGYM-CODEQA和MEMGYM-DR）**：
   - **共同模板**：从来源（SWE-smith bug / 学术搜索）提取事实，分类为“仅记忆”或“可发现”，注入分心物，扩展至目标长度，通过多标准验证器认证。
   - **MEMGYM-CODEQA**：源于SWE-smith，提取行为事实，要求至少两个关键记忆独有事实；分心物来自跨实例报告、同仓库文档、对抗近匹配、同函数矛盾；验证器进行三项检查（可解性、分心混淆、问题泄露）。
   - **MEMGYM-DR**：通过迭代搜索构建有序桥梁事实链（retention_span）；注入四级分心物（自然/近匹配/对抗矛盾/批量填充）；关键步骤**虚构化**：用LLM提取实体并替换为虚构内容，防止模型从预训练中直接回答。
   - **验证条件**：要求`score_all_memory ≥ score_long_context`（多跳笔记优于长上下文转储），且无记忆基线接近零。

## 6. 论文的主要结论与发现

1. **记忆的收益是领域依赖的**：
   - 编码（SWE-Gym）：记忆对解决率中性（Δ≈0），但提供约1.3-1.5×上下文压缩，使轨迹保持在有效窗口内。
   - 对话和网页：记忆有清晰正收益（Tau2 +8.7pp, WebArena +4.3pp），原因是隐藏状态难以重新推导。
2. **合成基准下压力越大，记忆策略差距越明显**：
   - MEMGYM-CODEQA：A-Mem在500k token预算下达到0.75（无记忆仅0.20），且所有记忆策略随预算波动不大，表明策略质量比窗口大小更重要。
   - MEMGYM-DR：A-Mem在5/6跳时领先（0.518 vs BM25 0.425），因笔记进化链接了查询相关性低的桥梁段落；无记忆接近随机（0.009）。
3. **MemRM作为轻量评估信号有效**：
   - IID AUROC 0.985，ECE 0.009，可在子秒内完成压缩分类。
   - 在分布外子集（策略OOD、场景OOD）上部分泛化（AUROC 0.71-0.75），但覆盖有限。
4. **A-Mem是压力最大点上的最强策略**，在两个不相关领域表现一致，表明其稳健性不是数据特有。

## 7. 优点：方法或实验设计上的亮点

- **统一记忆接口**：五个环境共享一个每步契约，可实现跨域比较和快速移植新记忆策略。
- **记忆隔离评分**：通过成对基线Δ直接归因于记忆，避免推理、检索等混淆因素。
- **可控制、可验证的合成管道**：虚构化、分心物层级、多标准验证器确保实例测试真实记忆而非参数泄露；长度和噪声解耦，可独立缩放。
- **MemRM降低计算门控**：将分钟级Docker部署转化为亚秒级调用，使学术研究能系统迭代记忆策略（如作为强化学习奖励信号）。
- **开源成果**：释放五轨道包装器、合成管道、MemRM权重、标注轨迹语料库，促进社区研究。
- **实验细节详尽**：附录包含每环境超参数、压缩比公式、数据增强分类、OOD选择性分类定义等，增强可重复性。

## 8. 不足与局限

- **数据规模有限**：每轨道的pilot大小和MemRM训练集（18.6K）尚不足以覆盖所有策略×推理者×轨道网格的全部统计效力，部分子集（如SWE-Gym超参数扫描仅n=20）可能不够稳定。
- **成本仍较高**：尽管MemRM降低了编码评估成本，但主要实验（成对基线）仍依赖商业LLM API（主要用于Sonnet/Haiku），可能限制复制和扩展。
- **记忆增益的通用性需进一步验证**：SWE-Gym上记忆中性可能受限于任务特性（文件系统保存状态）；编码QA和搜索轨道设计可能会偏向特定策略。
- **MemRM的泛化局限**：
  - 仅在SWE-Gym上训练；OOD子集覆盖低（20-27%），且部分队列AUROC近随机或极性翻转；部署时需选择性分类规则。
  - 未包含Tau2-bench的OOD评估（因运行时数据不可重构输入三元组）。
- **虚构化依赖LLM判断**：虚构化步骤中实体提取和替换的准确性可能影响实例质量，且本文提供虚构化后无记忆基线接近0，但未进一步分析虚构化对记忆策略排名的干扰。
- **缺乏多轮干预实验**：文中主要比较单次记忆事件，未深入验证记忆策略在连续交互中如何随时间积累或错误传播。
- **潜在偏差风险**：训练MemRM的标签来自三种来源（任务解决、反事实重放、LLM裁判），LLM裁判可能引入系统性偏差；类平衡训练但SAFE比例仅12.2%，可能导致门控过于保守。
