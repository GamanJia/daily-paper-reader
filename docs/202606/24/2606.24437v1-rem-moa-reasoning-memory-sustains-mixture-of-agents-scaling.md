## 摘要
混合智能体（MoA）架构通过将多个LLM智能体组织成分层推理流程来改进推理时的缩放。然而，现有的MoA变体在深度增加时无法维持收益，表现出退化、早期平台期或饱和。我们提出ReM-MoA，一种记忆增强的MoA框架，通过两种机制维持缩放：（1）排位推理记忆，使用比较型评审智能体持续存储并排序来自所有层的推理轨迹；（2）策划多样化记忆路由方案，将不同智能体暴露于成功和失败轨迹的不同组合，在传播高质量推理的同时保持探索多样性。我们进一步引入可选的多域评审者蒸馏流程，通过前沿模型监督提高排序质量。在涵盖数学、形式逻辑、代码、知识和常识的五个推理基准上，ReM-MoA在深度和宽度缩放方面均持续优于先前的MoA变体，并且其优势随深度增加而扩大，确立了结构化跨层推理记忆作为可扩展多智能体推理的关键缺失机制。

## Abstract
Mixture-of-Agents (MoA) architectures improve inference-time scaling by organizing multiple LLM agents into layered reasoning pipelines. However, existing MoA variants fail to sustain gains as depth increases, exhibiting degradation, early plateauing, or saturation. We propose ReM-MoA, a memory-augmented MoA framework that sustains scaling through two mechanisms: (1) a Ranked Reasoning Memory that persistently stores and ranks reasoning traces from all layers using a comparative Reviewer Agent, and (2) a Curated Diversified Memory Routing scheme that exposes different agents to distinct combinations of successful and failed traces, preserving exploration diversity while propagating high-quality reasoning. We further introduce an optional multi-domain Reviewer distillation pipeline that improves ranking quality through frontier-model supervision. Across five reasoning benchmarks spanning math, formal logic, code, knowledge, and commonsense, ReM-MoA consistently outperforms prior MoA variants across both depth and width scaling, and its advantage widens with depth, establishing structured cross-layer reasoning memory as a key missing mechanism for scalable multi-agent inference.

# 论文总结：ReM-MoA: Reasoning Memory Sustains Mixture-of-Agents Scaling

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：现有的 Mixture-of-Agents (MoA) 架构通过将多个 LLM 智能体组织成分层流水线来提升推理时计算规模，但随深度增加，性能出现**退化**（如标准 MoA）、**早期平台期**（如 RMoA）或**饱和**（如 AttentionMoA）。已有变体无法维持缩放增益。
- **根源三个机制**：① 原始跨层拼接会传播错误；② 仅局部层间通信无法保留早期高质量推理；③ 智能体输入趋同导致探索多样性崩溃。
- **核心洞察**：可持续的 MoA 缩放需要同时保持**质量**和**多样性**，而现有方法都破坏了这一平衡。论文提出结构化跨层推理记忆作为关键缺失机制。

## 2. 方法论：核心思想、关键技术细节
### 核心思想
- 提出 **ReM-MoA**：通过一个**排位推理记忆（Ranked Reasoning Memory）** 持久化存储并排序所有层的推理轨迹（含评审分数和理由），并利用**策划多样化记忆路由（Curated Diversified Memory Routing）** 向同一层内不同智能体分发不同组合的高/低分轨迹，从而同时实现质量传播和多样性维持。

### 关键技术细节
- **记忆子系统**：每层提案者生成 N 条轨迹后，评审智能体（Reviewer Agent）一次性比较所有轨迹，输出每个轨迹的整数分数（1-10）和针对性理由。记忆条目为 (轨迹, 分数, 理由) 三元组，累积所有层（M≤l = ∪_{k=1}^l M_k），支持跨层读取。
- **路由机制**：从层 2 开始，每个提案者接收从记忆中选择的参考集。路由分为三类：**对比型**（Top_a ∪ Bot_b）、**正强化型**（Top_a）、**失败模式聚焦型**（Bot_a）。同一层的 N 条路由分布不同（如 N=3 时分别为 Con_2、Top_2、Bot_2），确保探索多样性。
- **可选评审蒸馏**：使用前沿模型（GPT-5.5）作为教师，在 ReM-MoA 自身产生的轨迹上监督微调小型评审者（Qwen2.5-7B，LoRA 参数仅 0.18%）。多域训练（MATH、ARC-Challenge、MedQA、MBPP、HellaSwag）使评审者泛化到未见领域。

### 算法流程（文字说明）
1. 输入问题 x，初始化空记忆 M。
2. 对于每层 l=1..L：
   - 层 1：提案者直接根据 x 生成 N 条轨迹。
   - 层 l≥2：每个提案者根据路由获取记忆中的参考集（包含轨迹、分数、理由），结合 x 生成新轨迹。
   - 评审者对所有 N 条轨迹打分并给出理由，存入记忆 M。
3. 最终聚合器从记忆中选取参考集，综合生成最终答案。
