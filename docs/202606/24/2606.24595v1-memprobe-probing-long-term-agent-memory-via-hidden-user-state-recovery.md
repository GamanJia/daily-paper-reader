## 摘要
长期记忆有望使LLM智能体在多次交互中变得更加胜任，保持对用户准确且不断更新的理解。然而在实践中，这种记忆主要通过下游行为来评估，例如后续的回答、个性化质量或任务成功率，这些评估仅间接测试理解能力，而记忆工件本身在很大程度上未经审计。我们认为，长期记忆应作为可审计的交互后工件进行评估：在普通辅助之后，从智能体留下的记忆中能重建出什么样的结构化用户状态？我们将这一观点实例化为MEMPROBE基准测试，在该基准中，配备记忆的智能体辅助模拟用户，每个用户携带一个隐藏的、基于分类法的用户状态库，经历一系列泄漏控制的任务轨迹，之后从智能体产生的记忆中，分别在完整存储和top-k访问下重建该状态库。MEMPROBE基于合成真实数据进行高效、可扩展的测量，涵盖50个模拟用户，每个用户有31个隐藏维度（共1550个恢复目标），并测试5种代表性记忆系统。测试最先进的记忆智能体时，我们发现成功辅助和可恢复记忆表现为不同的能力。即使在无记忆基线中，任务完成率也几乎饱和，而类别平衡的恢复率仅为中等（约0.6），且在top-k检索下进一步下降。MEMPROBE是首个直接研究记忆恢复的基准测试，重建系统保留的用户状态，并对照真实数据进行评分。我们将恢复视为未来记忆智能体需要优化的具体目标，并将MEMPROBE视为迈向一种环境的一步，在该环境中，智能体被训练来记住其用户，且相处越久越忠实。

## Abstract
Long-term memory promises LLM agents that grow more capable across sessions, maintaining an accurate, evolving understanding of the user that interaction forms. In practice, however, this memory is evaluated mostly through downstream behavior, such as later answers, personalization quality, or task success, which tests that understanding only indirectly and leaves the memory artifact itself largely unaudited. We argue that long-term memory should instead be evaluated as an auditable post-interaction artifact: after ordinary assistance, what structured user state can be reconstructed from the memory the agent leaves behind? We instantiate this view in MEMPROBE, a benchmark in which a memory-equipped agent assists simulated users, each carrying a hidden, taxonomy-anchored user-state bank, across a trajectory of leak-controlled tasks, after which that bank is reconstructed from the agent's resulting memory under both full-store and top-k access. Built on synthetic ground truth for efficient, scalable measurement, MEMPROBE spans 50 simulated users with 31 hidden dimensions each (1,550 recovery targets) and tests 5 representative memory systems. Testing state-of-the-art memory agents, we find that successful assistance and recoverable memory behave as distinct capabilities. Task completion nearly saturates, even for a memoryless baseline, while category-balanced recovery stays moderate (about 0.6) and drops further under top-k retrieval. MEMPROBE is the first benchmark to study memory recovery directly, reconstructing the user state a system retains and scoring it against ground truth. We see recovery as a concrete objective for future memory agents to optimize, and MEMPROBE as a step toward an environment where agents are trained to remember their users, growing more faithful the longer they know them.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有长期记忆评估主要通过**下游行为**（任务成功率、回答质量、个性化程度等）间接测试记忆效果。这种评估方式无法直接衡量记忆工件本身的质量——高任务成功率可能源于上下文猜测或无记忆基线，并不代表系统真正形成了对用户的忠实模型。
- **研究动机**：任务成功与记忆保真度是**两种不同的能力**；需要一个能直接审计记忆内容的评估指标。
- **整体含义**：提出将长期记忆视为**交互后可审计的工件**，通过从中能否重构出隐藏的用户状态（技能、知识、偏好、经历等）来评估记忆质量，从而推动智能体系统真正学会“记住用户”。

## 2. 论文提出的方法论

### 2.1 核心思想
- **记忆恢复（Recovery）**：智能体与用户交互后，从其留下的持久记忆工件中，尽可能多地重构出用户隐藏状态，并与真实标签对比打分。
- **三个关键步骤**：
  1. **暴露（Expose）**：模拟用户通过泄漏控制的对话自然展现隐藏状态证据，但不直接点名。
  2. **收集（Collect）**：智能体依据自身记忆策略（写、合并、更新等）将对话证据写入持久存储。
  3. **恢复（Recover）**：通过两种读取模式（完整存储转储 `dump_all` 和系统自身 `top-k` 检索 `retrieve`）从记忆中提取信息，由插槽填充器（slot-filler）预测每个隐藏维度，再由LLM法官对照真值评分（五级0~1）。
- **两种读取模式分离了“是否写入”与“是否可检索”**，便于定位失败原因。

### 2.2 关键技术细节
- **合成用户构建**：每个用户包含一个基于分类法的隐藏状态库，共31个维度，分为5类：
  - 技能记忆（Skill Memory）
  - 知识记忆（Knowledge Memory）
  - 情景记忆（Episodic Memory）
  - 自我模型（Self Model）
  - 辅助偏好（Assistance Preference）
- **泄漏控制任务**：每个隐藏维度对应一个普通辅助任务，要求不直接提及目标值，通过反钓鱼审查机制确保任务本身不会泄露答案。
- **失败归因（Failure Attribution）**：对恢复分数低于0.75的维度进行三级诊断，区分：
  - 任务设计失败（task_design_failure）
  - 真正记忆失败（memory_failure）
  - 智能体引导失败（agent_elicitation_failure）
  - 模拟用户未足够披露（simulator_too_strict）

### 2.3 核心评分指标
- **类别平衡恢复分数 B**：先按5个类别内平均，再对5个类别均值取平均，避免大类别主导。
- 分数范围[0,1]，越高越好。

## 3. 实验设计

### 3.1 数据集/场景
- **50个合成模拟用户**，每个用户31个隐藏维度，共计**1550个恢复目标**。
- 每个用户有31个泄漏控制任务（每个维度一个），交互上限25轮。
- 用户原型使用DeepPersona生成，真实标签基于O*NET、HEXACO、Conway自传记忆等已有分类法。

### 3.2 Benchmark 对比方法
- **nomem**：无记忆基线。
- **longctx_full**：存储原始对话全文，使用句子Transformer余弦检索（retrieve模式）。
- **amem**（A-Mem）：Zettelkasten式笔记组织，带演化链接。
- **mem0**（Mem0）：提取并整合对话事实，基于存储检索。
- **memt**（Mem-T）：使用Mem-T-4B作为训练过的记忆操作策略，分层数据库。

此外，对比了两种读取模式：`dump_all`（完整存储）与`retrieve`（top-5检索）。

### 3.3 主要实验结果
- 任务完成率（A）几乎饱和（>99.9%），偏好分数（D）>4.58/5，平均轮次2.4~2.5。
- 无记忆基线nomem同样接近完美任务完成，但记忆恢复为零。
- 记忆系统的类别平衡恢复分数 B 在 `dump_all` 模式约0.61~0.62，`retrieve` 模式降至0.47~0.54。
- 情景记忆（Episodic Memory）最难恢复（retrieve模式下仅0.23~0.35），辅助偏好（Assistance Preference）最好（retrieve模式下约0.72）。
- 系统排名在两种读取模式下不一致：`dump_all` 下longctx_full略优，`retrieve` 下amem最优。
- 失败归因显示，真正记忆失败占大多数，任务设计、引导失败等占少数。

## 6. 论文的主要结论与发现

1. **任务成功 ≠ 良好用户状态存储**：所有系统任务完成率接近完美（含无记忆基线），但恢复分数仅中等（~0.6）。辅助成功与用户模型形成是分离的能力。
2. **存储不等于可检索**：`dump_all` 恢复高于 `retrieve`（相差约0.07~0.14），表明证据虽已存储但仍可能无法通过常规检索接口获取。记忆需要检索感知的整合（retrieval-aware consolidation）。
3. **写策略瓶颈在于抽象化**：系统倾向保存原始交互，很少将其凝练成紧凑的用户状态声明，导致检索时机难以匹配。
4. **情景记忆最难恢复**：单次、时间锚定的事件（如“某次顿悟”）比稳定的偏好更难恢复，原因是需要绑定事件、上下文与后果，而不仅仅是记录表面事实。

## 7. 优点

- **创新评估范式**：首次将长期记忆作为可审计的后交互工件直接评估，摆脱了对下游行为的间接依赖。
- **分离写入与检索**：通过`dump_all`和`retrieve`两种模式，可诊断失败发生在存储侧还是检索侧。
- **精细的失败归因机制**：三级归因管道（任务设计→证据披露→引导失败）帮助区分真正的记忆失败与其他原因。
- **可控且可扩展的合成环境**：基于分类法的隐藏状态库和泄漏控制任务，使地面真值已知，支持大规模、低成本、可复现的评估。
- **覆盖代表性记忆系统**：5种不同设计（无记忆、原始存储、笔记式提取、事实整合、学习策略）提供了清晰的对照图谱。
- **开放资源**：全部代码、数据、评估轨迹、法官输出、归因标记均已开源。

## 8. 不足与局限

- **合成用户与脚手架局限性**：所有用户基于美国背景的DeepPersona，缺乏多语言、跨文化、高度隐私保护或快速变化的真实用户行为。模拟器未能完全代表开放域人机交互。
- **评分与归因依赖LLM评判**：虽然质量经过人工抽样验证，但LLM作为法官仍可能受表面形式影响（如方向性标签的极性歧义），且未采用双盲设计。分数应谨慎解读。
- **任务难度较低**：日常辅助任务，任务完成率饱和，未能测试更复杂任务下内存与任务的交互。
- **未直接评估用户条件化辅助技能**：某些失败源于智能体未能引导用户披露，这本身是一种记忆缺失（知道“如何问这个用户”），但基准未直接测量此类记忆。

- **GPT-5.4-mini为最新模型**，但对于未来模型可能过时，法官阈值需重新校准。
