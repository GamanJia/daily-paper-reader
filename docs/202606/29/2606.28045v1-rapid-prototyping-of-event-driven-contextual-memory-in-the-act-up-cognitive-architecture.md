## 摘要
本文描述了在ACT-Up认知架构中实现上下文记忆和基本事件处理的方法，该方法在保持其可扩展性和适合快速原型设计的同时，增加了关键功能并降低了新用户的使用门槛。这包括描述工作记忆和激活扩散的理论中立实现，以及基本的联想学习机制。使用Klein、Addis和Kahana（2005）描述的序列记忆任务，展示了算法开发的快速原型设计示例。该研究描述了在三种序列和自由回忆条件下，连续列表呈现过程中邻近效应的变化。我们进一步描述了如何使用生成式AI和事件处理器直接从研究论文的方法部分自动创建认知实验。

## Abstract
The present paper describes an implementation of contextual memory and a basic event-handler for the ACT-Up cognitive architecture which maintains its scalability and appropriateness for rapid-prototyping while adding essential features and lowering the barrier to entry for new users. This includes describing a theory-neutral implementation of working memory and spreading activation, in addition to a basic associative learning mechanism. An example of rapid prototyping for algorithm development is presented using the serial memory task described in Klein, Addis, and Kahana (2005). This study describes how contiguity effects change across sequential list presentations across three serial and free recall conditions. We further describe how to use generative AI and the event handler to automatically create cognitive experiments directly from the Methods section of research papers.

# 2. 论文提出的方法论

- **核心思想**：在 ACT-Up 核心框架上增量式添加两个模块——上下文记忆模块和事件处理模块，全部采用“理论中立”设计，用户可自定义核心函数（如工作记忆衰减、联想学习）以适应不同理论。
- **关键技术细节**：
  - **工作记忆 API**：提供 `init-context-module()`、`add-element()`、`remove-element()`、`update-context()` 等函数。`update-context` 使用用户提供的更新函数（默认使用 ACT-R 的激活衰减公式）。
  - **联想学习 API**：基于哈希表存储有向关联，支持常数时间访问。主要函数包括 `add-association()`、`update-association()`、`update-from-context()` 和 `spreading()`。`spreading` 根据工作记忆中所有源项的残余激活和关联强度计算目标项的总激活扩散。
  - **原型联想扩散函数**：
    - `capped-spread(freq, max=1, b=0.5)`：使用 `max * tanh(b * freq)` 将强度缩放到 [0, max]。
    - `actr-decay-activation(current-time, add-time, decay=0.35)`：简化 ACT-R 的基水平衰减，公式：`1 - decay * log(1 + (t - t0))`。
    - `adaptive-decay-activation(current-time, add-time, w)`：根据工作记忆中的元素数量自适应增加衰减率。
    - `use-based-decay(value, interference, time)`：对关联强度按百分比衰减（默认 1%）。
  - **事件处理模块**：
    - 提供 `queue-item()`（按时间戳排队添加/移除刺激）、`show-item()`（即时显示）、`purge-item()`、`advance-event-clock()`（推进时钟并处理所有到期事件）、`event-log()`（记录事件历史）。

# 3. 实验设计

- **使用场景**：Klein et al. (2005) 的多试次序列记忆任务。
  - 刺激：19 个不重复单词，每 1500 ms 呈现一个，列表重复呈现 5 次。
  - 三种条件：
    - **serial-constant**：固定顺序，要求按序回忆。
    - **free-constant**：固定顺序，允许自由回忆。
    - **free-varied**：每次呈现顺序随机，允许自由回忆。
- **基准（Benchmark）**：人类被试的总体正确率、序列位置曲线、条件响应概率（CRP，即邻近性效应）。论文没有进行跨模型对比（如 TCM、SEM、SIMPLE 等），而是定性讨论模型与这些理论的关联。
