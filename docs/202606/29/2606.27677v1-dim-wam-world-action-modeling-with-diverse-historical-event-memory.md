## 摘要
世界-动作模型通过联合预测未来的视觉状态和动作，在机器人操作中展现出令人期待的性能。然而，现有方法主要依赖短期历史和短视的未来预测，这对于长期任务来说是不足的，因为长期任务的成功执行依赖于早期的观察和任务进展。这类时间依赖型任务需要有效利用互补的时间信息，包括近期局部上下文、跨阶段历史事件、即时未来动态以及全局任务进展。为了解决长期遗忘和对全局任务状态感知不足的问题，我们提出了DiM-WAM，一种记忆增强的世界-动作模型，它集成了多尺度历史上下文、局部未来动态和全局任务进展。该记忆从真实观测中提取紧凑的视觉事件信息，通过独立的基于相似性的合并更新多个记忆库，然后读取带有库标识和时间嵌入的长期上下文，以条件化视频和动作去噪。一个进度监督目标进一步促使记忆标记不仅编码已完成的历史事件，还编码当前任务阶段及其对剩余任务的影响。在RMBench上，DiM-WAM将平均成功率从LingBot-VA的28.4%提高到69.8%，超过了显式记忆的Mem-0基线（42.0%）。在四个真实世界的Franka任务上，它将平均阶段成功率从70.7%提高到91.5%，完整任务成功率从52.5%提高到80.0%。项目页面：https://wangkai-casia.github.io/dim-wam/

## Abstract
World-action models have shown promising robot-manipulation performance by jointly predicting future visual states and actions. However, existing methods mainly rely on short-term history and short-horizon future prediction, which is insufficient for long-horizon tasks whose correct execution depends on earlier observations and task progress. Such temporally dependent tasks require effective use of complementary temporal information, including recent local context, cross-stage historical events, immediate future dynamics, and global task progress. To address long-term forgetting and poor awareness of the global task state, we introduce DiM-WAM, a memory-augmented world-action model that integrates multi-scale historical context, local future dynamics, and global task progress. The memory extracts compact visual event information from real observations, updates multiple memory banks through independent similarity-based merging, and then reads the bank-identity- and time-embedded long-term context to condition video and action denoising. A progress-supervision objective further encourages memory tokens to encode not only completed historical events but also the current task stage and its implications for the remaining task. On RMBench, DiM-WAM raises average success from 28.4% with LingBot-VA to 69.8%, exceeding the explicit-memory Mem-0 baseline at 42.0%. On four real-world Franka tasks, it improves average stage success from 70.7% to 91.5% and full-task success from 52.5% to 80.0%. - **研究动机**：现有世界-动作模型（WAM）主要依赖短期历史（滑动窗口）和短视的未来预测，在长时域机器人操作任务中表现不佳。长时域任务的成功执行依赖早期的观测和任务进度，具有强非马尔可夫性，需要四类互补的时间信息：① 长期历史（已完成的子任务与早期状态）；② 短期历史（近期局部变化）；③ 短期未来（即时视觉演化与动作后果）；④ 全局任务进展（当前状态在目标中的时间位置）。
- **整体含义**：现有方法（如LingBot-VA、GR-2等）即使扩展上下文窗口，也会因注意力竞争导致早期关键状态被遗忘，并且中间预测误差会污染长期上下文。记忆增强的VLA方法主要针对动作预测，而WAM的记忆还需直接参与未来视觉状态的生成和更新。因此需要专门为WAM设计一种可压缩、可检索、并由真实观测校正的长期记忆机制。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
显式地将长时域决策所需的信息分解为局部历史、跨阶段历史、即时未来动态和全局任务进展，并通过**多库记忆结构**组织长期历史，配合**任务进度监督**，使记忆不仅编码过去事件，还编码当前阶段及剩余任务含义。

### 关键技术细节
- **多类型历史事件记忆（Multi-Type Historical Event Memory）**：
  - **压缩视觉事件提取**：从每个真实观测中提取紧凑的视觉事件token `˜ui`（通过压缩模块gϕ）。
  - **多银行记忆更新**：使用K个并行记忆库，每个库固定N个事件槽。通过独立相似性合并策略更新：定义合并优先级 `ρ(u,v)=((1+cos(m_u,m_v))/2)*exp(-|t_u-t_v|/τ)`，当库满时，若新候选与最新事件冗余度高于最冗余的历史相邻对，则跳过写入；否则合并最冗余对并写入新事件（合并采用质量加权平均）。初始状态锚点固定在槽1，最新事件受保护。
  - **独立有界压缩**：每个库独立维护事件序列，避免不同类型历史在单一容量下直接竞争。
- **协同记忆读取（Cooperative Memory Reading）**：
  - 读取时对所有有效记忆token附加银行身份嵌入bk，按时间顺序展平，并添加RoPE时间嵌入，形成条件序列Ri。
  - 记忆同时条件化视频去噪和动作去噪，使未来视觉状态和动作基于相同的长期任务状态。推理时记忆仅为临时注意力条件，不清除KV缓存；预测完成后清除临时K/V，仅在收到真实环境反馈后更新持久记忆。
- **任务进度感知记忆学习（Task-Progress-Aware Memory Learning）**：
  - 从聚合的长程记忆预测离散的任务进度分布 `pi = Softmax(h_prog(Pool(Ri)))`，采用交叉熵损失 `L_prog`。
  - 提供全局目标相对时间信号，但不显式预测未来观测或动作，而是连接已完成事件与剩余任务的含义。
- **多样性约束**：对不同银行聚类的平均特征施加正交性损失 `L_div`，防止银行坍缩到相同表示。
- **最终训练目标**：`L = L_video + λ_a L_action + λ_div L_div + λ_prog L_prog`。

### 算法流程（文字说明）
1. **读取**：从记忆库读取银行身份+时间嵌入的记忆条件，结合局部上下文（滑动窗口KV缓存）和语言指令，进入视频-动作联合去噪生成未来视觉潜变量和动作块。
2. **预测**：模型预测未来H步的视觉潜变量和动作序列。
3. **交互**：执行动作，获得真实观测。
4. **更新**：将真实观测压缩为事件token，按独立相似性合并策略更新K个记忆库。
