## 摘要
大语言模型（LLM）代理在长时间、多会话的交互中运行，其中事实会发生变化：用户搬家、价格更新、计划修订。正确执行需要使用事实的当前值并丢弃已被取代的值。我们在真实对话数据上分离出这种能力，并表明它是一个独特的、尚未解决的失败。在LongMemEval的知识更新子集上，将代理的完整上下文替换为有边界、自维护的记忆后，即使在前沿模型（gpt-5.4）上，准确率也从92%下降到77%，这一差距具有统计显著性（配对McNemar p<0.005），并且随着模型规模的扩大而持续存在，而完整上下文准确率稳定在92%附近。因此瓶颈在于记忆维护而非理解，且无法通过更强模型解决。接着我们探究这是否仅仅是记忆大小不足，结果发现并非如此：随着对话长度增长24倍，准确率进一步下降（从68%到28%），并且给予代理成比例更多的记忆并未带来可检测的恢复（28%对28%，n=25）。失败随对话长度而非压缩比扩展。我们发布Supersede，一个开放的强化学习环境（基于verifiers/prime-rl栈），将这一测量转化为训练信号：代理根据当前值作答获得奖励，依据过时值作答受到惩罚。最后，我们形成闭环并表明这一差距是可训练的：在此环境上对小型开源模型（Qwen2.5-3B）进行GRPO微调，使其在真实未见对话上的保留替代准确率几乎翻倍（单次运行从9.0%到16.7%），且单调的检查点曲线表明学习到的策略而非训练框架带来了提升。据我们所知，这是首个奖励目标为时间事实时效性的可训练环境，也是首个证据表明替代鸿沟不仅可测量也可通过训练缩小。

## Abstract
Large language model (LLM) agents operate over long, multi-session interactions in which facts change: a user moves, a price updates, a plan is revised. Acting correctly requires using the current value of a fact and discarding values that have been superseded. We isolate this ability on real conversational data and show that it is a distinct, unsolved failure. On the knowledge-update subset of LongMemEval, replacing an agent's full context with a bounded, self-maintained memory drops accuracy from 92% to 77% even on a frontier model (gpt-5.4), a gap that is statistically significant (paired McNemar p<0.005) and persists across model scale while full-context accuracy saturates near 92%. The bottleneck is therefore memory maintenance, not comprehension, and is not closed by a stronger model. We then ask whether this is merely an undersized memory, and find it is not: as the conversation grows 24x, accuracy falls further (from 68% to 28%), and granting the agent proportionally more memory yields no detectable recovery (28% to 28%, n=25). The failure scales with the length of the conversation, not the compression ratio. We release Supersede, an open reinforcement-learning environment (on the verifiers / prime-rl stack) that turns this measurement into a training signal: agents are rewarded for answering from the current value and penalized for stale ones. Finally, we close the loop and show the gap is trainable: GRPO fine-tuning a small open model (Qwen2.5-3B) on this environment nearly doubles its held-out supersession accuracy on real, unseen conversations (9.0% to 16.7%, a single run), along a monotonic checkpoint curve indicating the learned policy, not the harness, carries the gain. To our knowledge this is the first trainable environment whose reward targets temporal fact-currency, and the first evidence the supersession gap can be trained down, not only measured.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型（LLM）代理在长期、多会话交互中需要处理事实的动态变化（如用户搬家、价格更新、计划修订）。正确行为要求使用事实的**当前值**，并丢弃已被**取代**（superseded）的旧值。然而，现有代理在自我维护的有界记忆下，难以正确保持事实的时效性，导致回答依赖过时信息。作者将这种特定能力的失败称为**替代鸿沟（supersession gap）**。
- **动机**：尽管已有长时记忆基准（如LongMemEval）和遗忘感知指标（FAMA），但**没有**将该失败转化为可训练的信号。同时，RL for memory的工作关注最终答案正确性或相关性，而非事实的**时间时效性**。本文填补这一空白。
- **整体含义**：替代鸿沟不是理解问题，而是一个记忆维护策略问题，且**不能通过扩大模型或扩大记忆自动解决**，但可以通过针对性的RL训练来缩小。

## 2. 方法论

### 核心思想
- 构建一个**开放RL环境** `Supersede`，奖励信号直接基于**事实的当前值**，而非最终答案正确性或其他代理指标。环境强制代理在有限笔记（bounded memory）中维护状态，且**不允许重新读取原始会话**。
- 使用**GRPO**算法微调开源小模型，验证该训练信号的有效性。

### 关键技术细节
- **任务定义**：多会话交互 + 关于变化事实的查询。代理逐会话处理，维护一个最大B字符的笔记，最后仅从笔记作答。
- **奖励函数**：
  - 主要奖励：`r_cur = 1[最终答案传递当前值]`，使用**程序化匹配器**（judge-free）评分。匹配器先归一化，然后检查当前值变体是否为子串，否则使用token重叠阈值。
  - 可选惩罚：当已知过时值时，`r_stale = -1[答案包含过时值]`。实验中仅优化`r_cur`（权重1.0）。
- **训练算法**：GRPO（Group Relative Policy Optimization），利用组内优势估计，无需值函数。
- **模型与适配器**：Qwen2.5-3B-Instruct，LoRA低秩适配（rank=32, alpha=64），target modules包括q,k,v,o,gate,up,down投影。
- **数据**：
  - **诊断**：LongMemEval知识更新子集（真实对话，分为oracle和s两种长度）。
  - **训练**：程序化生成模板化时间线（6-8个会话，一个事实被更新并埋于干扰会话中），共2000个episodes，与真实评价集**不重叠**。

## 6. 主要结论与发现

1. **替代鸿沟存在且显著**：即使前沿模型（gpt-5.4），从全上下文切换到有界记忆后，知识更新准确率从92%降至77%（p<0.005）。
2. **更大模型不能解决**：全上下文准确率随模型增大饱和（接近92%），但有界记忆准确率增长缓慢（63%→64%→77%），差距持续。
3. **更大记忆也不能解决**：对话长度增长24倍导致准确率从68%降至28%；即使记忆成比例扩大（7,150字符），准确率仍为28%（无净恢复）。
4. **可训练性**：在Supersede环境上的GRPO训练，使Qwen2.5-3B在真实、未见过的LongMemEval oracle集上准确率**从9.0%提升至16.7%**（86%相对提升），且单调上升（证明学习而非偶然）。
5. **记忆维护是瓶颈**：失败源于代理不能正确覆盖/保留当前事实，而非阅读理解不足。

## 7. 优点

- **开源完整资源**：代码、环境、训练模型、数据集均公开。

- **排除了两种常见简单解法**：明确证明更大模型和更大记忆都无效，强化了需要训练策略的主张。
- **使用真实对话数据**：避免模板化数据饱和问题，结果更具现实意义。
