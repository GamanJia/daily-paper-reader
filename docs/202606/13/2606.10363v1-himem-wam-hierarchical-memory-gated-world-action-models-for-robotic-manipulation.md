## 摘要
世界动作模型（WAMs）已成为具身智能的一种新的强大范式，学习与动作相关的视觉动态，显著增强了泛化性和鲁棒性。然而，现有的WAMs在长期机器人操作中仍然难以处理任务相关记忆。为了解决这个问题，我们提出了HiMem-WAM，一种层次记忆门控WAM，它集成了以运动为中心的潜在动作、高级技能潜在变量和边界触发的记忆更新。具体来说，我们开发了一个层次潜在动作框架，联合学习低级运动和高级技能潜在变量，提供结构化的时间抽象。同时，边界感知记忆门在预测的技能转换处写入紧凑的任务状态，无需在测试时生成未来视频或光流估计即可实现因果推理。在LIBERO、LIBERO-PLUS、RMBench和真实世界任务上进行评估，HiMem-WAM显示出层次潜在变量提高了部署扰动下的鲁棒性，记忆模块显著有益于依赖记忆的长期操作。

## Abstract
World Action Models (WAMs) have emerged as a new powerful paradigm for embodied intelligence, learning action-relevant visual dynamics that significantly enhance generalization and robustness. However, existing WAMs still struggle with task-relevant memory in long-horizon robotic manipulation. To address this, we present HiMem-WAM, a Hierarchical Memory-Gated WAM that integrates motion-centric latent actions, high-level skill latents, and boundary-triggered memory updates. Specifically, we develop a hierarchical latent action framework that jointly learns low-level motion and high-level skill latents, providing structured temporal abstraction. Meanwhile, a boundary-aware memory gate writes compact task states at predicted skill transitions, enabling causal inference without test-time generation of future video or optical flow estimation. Evaluated on LIBERO, LIBERO-PLUS, RMBench and real-world tasks, HiMem-WAM shows that hierarchical latents improve robustness under deployment perturbations, and the memory module substantially benefits memory-dependent long-horizon manipulation.

### 2. 方法论：核心思想、关键技术细节、流程

- **核心思想**：将机器人操纵策略分解为**高层技能隐变量**和**低层运动隐变量**两个层次，并通过**边界感知的门控记忆模块**在技能切换点写入紧凑的任务状态，从而在保持因果推理（无需测试时生成未来视频或光流）的同时实现长期记忆。
- **关键技术细节**：
  1. **分层隐变量动作框架**：
     - **低层运动隐变量**（low-level latent actions）：使用多视角光流（DPFlow）和变分分词器，将短时上下文（相邻帧、光流、指令、本体感受）编码为连续隐变量，并通过重构光流和弱监督对齐实际动作来训练。训练后冻结，离线提取所有轨迹的低层隐变量序列 $Z^l$。
     - **高层技能隐变量**（high-level skill latents）：对低层序列进行动态分块：边界预测器在每个层级计算相邻令牌的相似度得分，标记新段落的起始点；通过注意力池化将变长段落聚合为下一层级的令牌。经过 $H$ 个层级后得到最终技能序列 $Z^h$。边界标签和每步技能目标通过索引映射展开回原始时间步。
  2. **门控记忆模块**：
     - 将当前观测、指令、本体感受编码为状态 $x_t$，从外部记忆库 $M_t$ 中检索上下文 $c_m^t$，并通过**读门** $\alpha_r^t$ 将其注入状态得到 $\tilde{x}_t$。
     - 使用 Qwen3-VL-4B-Instruct 作为规划器，从 $\tilde{x}_t$ 预测当前技能 $\hat{z}^h_t$ 和边界分数 $\hat{b}_t$。
     - 执行器将 $\hat{z}^h_t$ 展开为低层动作块 $\hat{Z}^l_{t:t+K-1}$，再通过动作解码器得到最终控制命令。
     - **写门** $\alpha_w^t$ 由当前状态、预测技能和边界分数共同决定，当 $\alpha_w^t > \eta$ 时，将候选记忆令牌 $\gamma_t$ 写入记忆库（否则保持）。写门通过 BCE 损失监督为边界标签，同时 $L_1$ 正则化鼓励稀疏读写。
  3. **三阶段训练流程**：
     - **Stage I**：训练低层隐变量分词器（利用光流和可选动作标注），冻结后离线提取所有轨迹的低层序列。
     - **Stage II**：冻结分词器，基于低层序列发现技能边界，无记忆预训练规划器和执行器（损失包括技能 MSE、隐动作块 MSE、边界 BCE）。
     - **Stage III**：激活记忆模块，在有动作标注的演示数据上微调完整策略（损失包括动作损失、分层隐变量损失、边界损失、门控损失）。可选的教师强制热身阶段用真实边界初始化记忆更新。
- **推理流程**：仅接收当前观测、本体感受、指令和记忆库，读门检索记忆，规划器预测技能和边界，执行器产生动作块，写门决定是否存储新记忆。整个过程因果、无未来预测。

### 6. 主要结论与发现

- **层次隐变量提升鲁棒性**：Stage II 预训练在标准 LIBERO 上提升 +1.1%，在部署扰动更大的 LIBERO-PLUS 上提升 +3.8%（零样本），证明隐变量捕获了任务完成的运动模式而非过拟合视觉外观。
- **门控记忆改善长时记忆依赖**：在 RMBench 上 HiMem-WAM 达到 26.3% 平均成功率（M(1) 31.6%，M(n) 19.8%），显著优于无记忆的基线（如 π0.5 10.8%），表明稀疏、边界触发的记忆写入有效保留了任务状态。
- **真实世界泛化表现突出**：在硬任务（长时双臂操纵）上，HiMem-WAM 比 π0.5 提升 +25.0%（ST）和 +20.0%（GE）；在中级任务上也有显著提升。
- **层次预训练在不同动作空间均有效**：关节位置和末端执行器位姿两种表示下，Stage II 都能带来增益，且在末端执行器位姿上增益更大（因其细节更少，更依赖运动先验）。
- **推理完全因果、无需未来生成**：HiMem-WAM 维持了标准动作分块策略的因果接口，测试时不需光流或视频生成，保证了实时性。

### 7. 优点

- **创新性**：首次将层次隐变量（技能+运动）与边界触发的稀疏记忆结合，克服了 WAM 在长时域任务中的记忆瓶颈，同时保持了因果推理效率。
- **实用性**：三阶段训练可充分利用无动作标签的视频数据进行运动先验学习，降低对有标注示范的依赖；记忆模块仅写入紧凑状态，不会导致存储爆炸。
- **实验严谨**：仿真和真实世界均包含标准、扰动、记忆多难度设置，消融实验完整，对比基线覆盖主流方法，结果有统计学意义（多次试验）。
- **泛化能力**：零样本迁移至 LIBERO-PLUS 的多种扰动场景表现优异，真实世界 GE 设置下仍能保持高成功率，说明模型学到了更本质的运动动态而非表面关联。
- **可复现性**：论文提供了详细的实现细节（附录 A-B），包括边界评分、池化、损失函数、教师强制热身等，便于复现。

### 8. 不足与局限

- **计算开销大**：训练管道涉及光流提取、隐变量学习、技能发现、记忆策略训练等多个阶段，虽然推理高效，但训练需要“considerable computation”（论文原文）。未提供具体算力数据，难以评估资源需求。
- **工程复杂度高**：多阶段设计使得调优和部署复杂度增加，且最终性能依赖于每个阶段的质量（如隐变量分词器、边界预测器、记忆更新策略），存在级联误差风险。
- **记忆规划能力仍有限**：在 RMBench 的 M(n) 任务（需要多步状态更新）上性能明显下降（19.8%），低于专用记忆方法 MEM-0（8B 规划器+更复杂的记忆推理），说明当前简单读写门控还不足以处理复杂的多轮状态更新，需要更强的记忆推理机制。

- **潜在偏差风险**：真实世界训练数据为每任务400演示，可能不足以覆盖所有变体；GE 设置的扰动虽多样但并未穷尽所有可能的部署变化，可能高估或低估某些扰动下的性能。
