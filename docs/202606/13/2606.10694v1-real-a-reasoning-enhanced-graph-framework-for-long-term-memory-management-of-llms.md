## 摘要
大语言模型（LLMs）越来越需要与用户进行长期交互。然而，由于其有限的上下文窗口，LLMs无法保留所有历史交互，因此长期记忆管理对于存储、更新和检索超出上下文限制的历史信息至关重要。尽管最近的记忆系统尝试通过外部存储历史信息来解决这一问题，但现有方法存在三个关键局限：基于平面文本的记忆组织无法捕捉记忆之间的显式关系，结构化记忆系统通常会破坏性地覆盖演变中的事实，而当前检索机制在证据不完整时仍然保持查询无关和被动。REAL将长期对话记忆构建为一个时间感知和置信度感知的有向属性图，其中每个原子事实用实体、关系、有效时间区间、置信度分数和探索意图标签表示。在记忆构建过程中，REAL采用非破坏性的时间更新策略，保留并行事实版本及其有效时间区间，从而忠实追踪事实的演变。在检索过程中，REAL锚定与查询相关的根实体，解耦其探索意图，并通过语义评估器引导的混合束搜索提取紧凑的记忆子图。它还进一步整合反事实推理来修复不可靠的检索状态，并通过隐式逻辑关系恢复缺失的记忆证据。综合实验表明，REAL在长期记忆性能上显著优于平面文本、基于图以及现有的记忆基线，平均提升22.72%。

## Abstract
Large Language Models (LLMs) are increasingly expected to interact with users over long time horizons. However, due to their finite context window, LLMs cannot retain all past interactions, making long-term memory management essential for storing, updating, and retrieving historical information beyond the context limit. Although recent memory systems attempt to address this issue by storing historical information externally, existing approaches suffer from three key limitations: flat text-based memory organizations fail to capture explicit relations among memories, structured memory systems often destructively overwrite evolving facts, and current retrieval mechanisms remain query-agnostic and passive when evidence is incomplete. REAL constructs long-term conversational memory as a temporal and confidence-aware directed property graph, where each atomic fact is represented with entities, relations, valid-time intervals, confidence scores, and exploration intent labels. During memory construction, REAL adopts a non-destructive temporal update strategy that preserves parallel fact versions and their validity intervals, enabling faithful tracking of fact evolution. During retrieval, REAL anchors query-relevant root entities, decouples their exploration intents, and performs semantic evaluator-guided hybrid beam search to extract compact memory subgraphs. It further incorporates counterfactual inference to repair unreliable retrieval states and recover missing memory evidence through implicit logical relations. Comprehensive experiments demonstrate that REAL substantially improves long-term memory performance over flat-text, graph-based, and existing memory baselines, achieving an average improvement of 22.72\%.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型（LLMs）在与用户长期交互时，由于有限的上下文窗口（8K–256K tokens）无法保留全部历史信息，需要外部长期记忆系统来存储、更新和检索超越上下文限制的历史信息。
- **现有方法的三大缺陷**：
  - **C1：平面文本组织**：将历史分割为独立文本块并向量化存储，缺乏实体间显式关系，无法支持多跳推理和路径级检索。
  - **C2：缺乏事实演化**：结构化记忆系统采用破坏性更新（新事实直接覆盖旧事实），丢失了用户偏好、计划随时间演变的轨迹。
  - **C3：检索低效与被动**：检索机制与查询无关（如固定步长随机游走或固定深度遍历），且当证据不足时仅返回“不知道”，无法通过隐式逻辑关系进行反事实推理以恢复缺失证据。
- **研究动机**：设计一个结构化的、时间感知的、推理增强的外部记忆框架，将LLM长期记忆问题视为数据管理问题，实现高效、忠实、可演化的事实追踪与动态检索。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
REAL 将长期对话记忆构建为**带时序、置信度和探索意图的有向属性图**，并在检索阶段通过**语义评估器引导的混合束搜索**和**反事实推理**提取紧凑的查询相关子图。

### 2.2 关键技术细节

#### （1）记忆构建（Memory Construction）
- **原子事实提取**：每一轮对话调用LLM提取六元组：`(h, r, t, [τₛ, τₑ], c, ι)`，其中：
  - `h, r, t`：头实体、关系、尾实体
  - `[τₛ, τₑ]`：有效时间区间
  - `c ∈ (0, 1]`：置信度（基于语言线索，如“可能”→低置信度）
  - `ι ∈ {FACT, CAUSAL, TEMPORAL, CONTRAST, EVOLUTION}`：探索意图标签
- **非破坏性时间更新**：
  - 根据关系的基数类型（单值/多值/未知）处理新事实：
    - 单值关系：若新事实与旧事实尾部不同且时间重叠，则关闭旧区间（设τₑ为新事实的τₛ），插入新事实，保留并行版本
    - 多值关系：直接添加新边，若相同三元组重叠则合并区间
    - 未知基数：默认多值处理
  - 从而忠实记录事实的演化历程（如“喜欢食物”从意大利→日本）
- **置信度分层与升级**：低置信度事实（<θₛₜₐᵦₗₑ，默认0.8）在常规检索中被排除，除非查询明确请求不确定信息；后续对话确认可升级置信度
- **探索意图标签**：引导检索阶段优先匹配与查询意图兼容的事实（如因果查询只扩展CAUSAL边）

#### （2）记忆检索（Memory Retrieval）
- **根实体锚定与意图解耦**：对查询q，LLM自动提取根实体集合`{(eᵢ, ιᵢ)}`，其中ιᵢ是查询意图（如因果、时序等）
- **语义评估器引导的混合束搜索**（Algorithm 1）：
  - 从每个根实体出发，维护k个束（beam），每个束记录遍历路径`Pᵢⱼ`（含实体和意图序列）
  - **候选节点扩展**：对当前尾实体获取直接邻居，依次应用：
    - 时间过滤：邻居有效区间须包含查询时间（默认当前时间）
    - 置信度阈值：仅保留c≥θₛₜₐᵦₗₑ
    - 意图兼容性：邻居的ι与当前束的意图匹配
  - 基于语义相似度（BGE-m3嵌入）选择top‑m候选邻居，形成扩展候选路径
  - **路径评分**：语义评估器对每条路径计算三个分数：
    - `S_QR`：查询相关性
    - `S_LC`：逻辑连贯性
    - `S_AS`：实体特定答案充分性（评估该路径是否满足针对该根实体的子问题）
  - **停止/扩展/反事实决策**：
    - 若当前路径的`S_AS` ≥ 所有扩展候选的`S_AS`，则选择Stop，将路径加入最终证据池
    - 否则，将`S_AS`更高的扩展候选加入候选池（Expand）
    - 若扩展不可靠（无候选、相似度过低、连贯性过低），触发Counterfactual_Infer
  - **反事实推理**：基于预定义规则（对称、上下位、时序、因果、共现）生成新的遍历假设，恢复可能存在的缺失证据。引入预算`B_cf = max(0, m - |N_rel|)`限制搜索范围
  - **全局束剪枝**：对每个根实体，合并正常候选和反事实候选，取top‑k路径进入下一步
- **答案生成**：将检索到的记忆子图序列化为紧凑上下文，包含实体、关系、时间戳、置信度，再输入LLM生成回答

### 2.3 算法流程（文字说明）
Algorithm 1 详细描述了混合束搜索的伪代码：输入包括用户查询q、记忆库M、束宽k、最大深度D_max等。从每个锚定根实体初始化束集，逐步扩展、评分、决策、反事实修复和束剪枝，直到所有束选择Stop或达到最大深度，最后聚合最终路径为M_q。

## 6. 主要结论与发现

1. **REAL在所有基准上显著优于所有基线**：平均提升22.72%（LJ分数），尤其是相比Full Context提升49.33%，相比平面文本提升23.85%，相比图基线提升12.71%。
