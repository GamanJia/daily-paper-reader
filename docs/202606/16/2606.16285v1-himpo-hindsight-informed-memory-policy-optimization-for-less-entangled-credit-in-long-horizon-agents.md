## 摘要
长时域智能体依赖记忆机制压缩交互历史，但优化记忆写入面临独特的信用分配挑战：一次记忆更新可能因下游工具故障、噪声观测或推理错误而受到奖励或惩罚，而非因其自身贡献。这种因果纠缠的信用会导致智能体丢弃有用证据或保留无关信息。我们提出HiMPO，一种后见明智记忆策略优化框架，用于在长时域智能体中为记忆写入动作分配低纠缠信用。HiMPO首先通过比较相同写入前状态下，从先前记忆和更新记忆中可恢复的任务相关信息来估计记忆更新的局部效用。然后，它使用后见相关性作为有界的回顾性滤波器，当局部效用未得到目标结果支持时衰减记忆信用。由此产生的记忆特定优势仅应用于记忆令牌，而轨迹级奖励优化智能体其余行为。在基于裁判的开放领域任务和客观压缩记忆问答中，HiMPO在保持压缩上下文效率的同时，优于基于强记忆和基于RL的基线。受控干预进一步表明，HiMPO减少了由工具引入错误引起的归因泄漏，并提高了记忆更新的归因保真度。

## Abstract
Long-horizon agents rely on memory mechanisms to compress interaction history, but optimizing memory writing faces a distinct credit assignment challenge: a memory update may be rewarded or penalized due to downstream tool failures, noisy observations, or reasoning errors rather than its own contribution. This causally entangled credit can lead agents to discard useful evidence or preserve irrelevant information. We propose HiMPO, a Hindsight-Informed Memory Policy Optimization framework for assigning less-entangled credit to memory-writing actions in long-horizon agents. HiMPO first estimates the local utility of a memory update by comparing the task-relevant information recoverable from the previous and updated memories under the same pre-write state. It then uses hindsight relevance as a bounded retrospective filter that attenuates memory credit when local utility is not supported by the target outcome. The resulting memory-specific advantage is applied only to memory tokens, while trajectory-level rewards optimize the rest of the agent behavior. Across judge-based open-domain tasks and objective compressive-memory QA, HiMPO improves over strong memory-based and RL-based baselines while preserving compressed-context efficiency. Controlled interventions further show that HiMPO reduces blame leakage from tool-induced errors and improves attribution fidelity of memory updates.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究问题**：长时域智能体（如多步推理、工具调用代理）依赖记忆机制压缩交互历史以应对长上下文。然而，记忆写入的优化面临**因果纠缠的信用分配问题**：一次记忆更新可能因下游工具故障、观测噪声或推理错误而受到奖励或惩罚，而非因其自身贡献。这导致智能体可能丢弃有用证据或保留无关信息。
- **背景**：现有方法（如 MemPO、SUPO）主要采用结果驱动的记忆奖惩，无法区分错误源自记忆、工具还是推理。例如：工具返回错误证据但记忆忠实地总结它，最终答案错误，但记忆不应被惩罚；反之工具正确但记忆遗漏关键事实，记忆应被惩罚。同一失败轨迹需要相反的信用。
- **动机**：需要一种更纯净的记忆信用分配方法，使得记忆更新的优化仅依赖于其自身对任务相关信息的贡献，并过滤掉非记忆组件（工具、推理、观测）带来的干扰。

## 2. 方法论

### 核心思想
HiMPO 将每次记忆更新视为一个策略控制的“写入动作”，通过两个互补信号构建记忆特定优势（advantage）：
1. **局部反事实效用**：在相同的写前状态下，比较更新后记忆与更新前记忆的任务相关信息可恢复性差异。
2. **后见相关性**：目标结果条件下该记忆写入相对于同级写入的后验概率比，用于有界回溯过滤。

通过**门控函数**（sigmoid of sign-consistent product）结合两者，仅当两种信号方向一致时才传递信用。最终的记忆优势仅施加给 <mem> token，其他 token 使用轨迹级优势。

### 关键技术细节
- **局部反事实效用**：定义答案打分函数 \(S(H_{i,t}, m, z_i^*)\) 为在给定写前状态和记忆候选 \(m\) 条件下目标结果 \(z_i^*\) 的平均对数似然。则 \(\Delta_{i,t} = S(H_{i,t}, m_{i,t}, z_i^*) - S(H_{i,t}, m_{i,t-1}, z_i^*)\)。标准化为 \(\hat{\Delta}_{i,t}\)。
- **后见相关性**：计算在给定后见（目标结果）条件下记忆 token 的条件平均对数似然，然后减去同一提示组同级轨迹的均值：\(\log \rho_{i,t} = \log h_{i,t} - \text{mean}_j \log h_{j,t}\)。
- **门控函数**：\(G(\hat{\Delta}_{i,t}, \log \rho_{i,t}) = \sigma(\beta_{\text{eff}} \cdot \text{sgn}(\hat{\Delta}_{i,t}) \log \rho_{i,t} - \tau_\rho)\)。再得到记忆优势 \(A_{i,t}^M = G \cdot \hat{\Delta}_{i,t}\)。
- **稳定化机制**：① 成功轨迹上负记忆优势置零（成功掩码）；② 可选指数平滑向后传播信用（延迟平滑）。最后，记忆 token 的优势为 \(A_{i,k} = A_i^T + \lambda_M \tilde{A}_{i,t(k)}^M\)（记忆 token），其他为 \(A_i^T\)。
- **优化目标**：标准的截断 PPO 目标，用上述 token 级优势。

### 算法流程（文字说明）
1. 采样 N 条带记忆的轨迹。
2. 计算轨迹奖励和轨迹优势。
3. 对每个记忆写入：计算局部效用并标准化；计算后见相关性；通过门控得到记忆优势；应用成功掩码和平滑。
4. 将记忆优势散布到 <mem> token；与其他 token 的轨迹优势结合。
5. 更新策略。

1. HiMPO 在 BCP 和 FRAMES 上达到最高 accuracy，在 BCP 全上下文下比 MemPO 提升 +2.53，SUPO 提升 +2.17；在压缩预算下也一致领先。

3. 消融表明：局部反事实效用信号本身已有贡献（+1.1~+2.2 pp）；回溯滤波进一步提升（+2.2~+3.3 pp）；稳定化机制主要在长时域设置显著。

5. 结论：有效的智能体记忆不仅需要压缩，还需要低纠缠的信用分配。
