## 摘要
长期记忆对于对话代理在长时间对话中保持连贯性、兑现多个会话前做出的承诺以及根据每个用户调整其行为至关重要。然而，当前基于大语言模型的长期对话记忆，在可达性上受限于查询与存储内容（包括词汇和稠密向量）之间的相似度。当查询和记忆共享表面特征（如措辞或命名实体，我们称之为描述性）时，这种方法是有效的。但它忽略了另一类同样有价值的情况，即查询和记忆不共享表面特征，仅通过潜在的语义弧（联想性）相连。在这种模式下，主流的长期记忆系统普遍失效。覆盖这另一半使得助手能够首次主动将过去的对话作为语义资产加以利用。在记忆方面，这是认知科学中所谓的“情景未来思维”的工程对应：排练过去的经验，以便在未来需要找到它的上下文中使用。我们将这些写入时的排练称为触发器。我们提出了T-Mem，这是首个同时涵盖描述性和联想性回忆的长期对话记忆架构。在两种证据粒度（单一事实和完整交流）上，T-Mem实例化了一个描述性触发器家族和一个联想性触发器家族，使得每个记忆都能从表面相似和相关性约束的查询中可达。作为实证验证，T-Mem在LoCoMo和LoCoMo-Plus上均达到了最先进水平。

## Abstract
Long-term memory is essential for conversational agents to remain coherent across extended dialogues, follow through on commitments made many sessions earlier, and adapt their behaviour to each user. Current LLM-backed long-term conversational memory, however, is reachability-bounded by the similarity between a query and stored content, both lexical and dense-vector. The approach is effective when query and memory share surface features such as wording or named entities (we call this descriptive). But it misses another, equally valuable class of cases, where query and memory do not share surface features and are tied only by a latent semantic arc (associative). On this regime prevailing long-term memory systems collectively fail. Covering this other half is what allows an assistant, for the first time, to actively draw on past dialogue as a semantic asset. On the memory side, this is the engineering counterpart of what cognitive science calls episodic future thinking: rehearsing past experience for the future contexts under which it will need to be found. We call these write-time rehearsals triggers. We propose T-Mem, the first long-term conversational memory architecture that covers both descriptive and associative recall. At each of two evidence granularities, single facts and full exchanges, T-Mem instantiates one descriptive trigger family and one associative trigger family, so that every memory remains reachable from both surface-similar and relevance-bound queries. As empirical validation, T-Mem reaches state-of-the-art on both LoCoMo and LoCoMo-Plus.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：现有的长期对话记忆系统（如Flat RAG、图结构记忆、智能体层次记忆、OS风格记忆内核等）均依赖**查询与存储内容之间的相似性**（词汇或稠密向量）进行检索。这种**描述性回忆**（descriptive recall）仅在查询与记忆共享表面特征（措辞、实体、时间地点）时有效，但忽略了另一类常见场景：查询与记忆仅通过**潜在语义弧**（如因果链、情境延续）关联，即**联想性回忆**（associative recall）。
- **含义**：用户长期对话中很少用完全相同的表达重提旧话题，更多通过间接线索（如新情境）触发旧信息。现有系统无法处理此类联想性检索，导致对话智能体无法主动利用过去对话作为语义资产。T-Mem借鉴认知科学中的**情景未来思考**（episodic future thinking），在写入记忆时预生成面向未来检索线索的“触发器”，使得记忆在将来即使未被相似查询直接命中，也能被关联查询找到。
- **整体贡献**：首次提出覆盖描述性与联想性两种回忆模式的长期对话记忆架构，填补了现有系统的结构性盲区。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **触发器（Trigger）机制**：在记忆写入阶段，由LLM为每条记忆自动生成一组“触发器”，这些触发器是未来查询可能使用的间接线索（如超级概念、情境投影、情感属性等）。检索时，查询不仅匹配原始记忆内容，也匹配触发器，实现联想性可达。
- **双粒度 × 双方向设计空间**：证据粒度分为**项目（item）**（单一原子事实）和**场景（scene）**（连贯对话片段）；回忆方向分为**描述性**（表面相似）和**联想性**（潜在关联）。共四个象限：Q I（item×描述性）、Q II（item×联想性）、Q III（scene×联想性）、Q IV（scene×描述性）。每个象限对应一个触发器家族：Entity（Q I）、Bridge（Q II）、Horizon（Q III）、Scene（Q IV）。其中Bridge和Horizon首次填补联想性盲区。

### 2.2 关键技术细节
- **记忆结构**：包含五类对象：场景（VS）、项目（VI）、主题标签（VT）、四种触发器（T^Ent, T^Brg, T^Scn, T^Hor）、说话者人格总结（Persona）。场景和项目作为答案时的证据；触发器仅参与检索，不传递给QA LLM；人格作为额外上下文。
- **记忆构建流水线**（四阶段）：
    1. **场景分割**：利用边界检测LLM将对话流分割为按事件闭合的场景。
    2. **主题分配**：每个新场景匹配已有主题标签，若无匹配则创建新标签；支持多标签。
    3. **项目提取**：每个主题下，LLM提取两类项目：原子项目（绑定单一场景）和连接项目（绑定多个相关场景），保留跨场景逻辑链。
    4. **触发器实例化**：
        - 项目级：Entity Trigger（命名项目的超级概念），Bridge Trigger（将项目投影到未来可能相关的情境，附一句理由）。
        - 场景级：Scene Trigger（四方面属性：情境、对象、事件、情感），Horizon Trigger（向前投影到未来可能触发的维度）。
- **索引**：支持两种索引：
    - **节点索引**：每个节点注册到BM25稠密表。
    - **触发器感知索引**：每个项目暴露三种视图（概念only、桥only、联合视图），场景级类似多视图方案。
- **检索流程**（Algorithm 1）：
    - 顶层主题预过滤（RRF融合BM25+稠密）→ 场景选择（相似度+触发器召回）→ 项目选择（场景绑定+硬余弦门限触发器召回）→ 加入Persona → 送入QA LLM。
    - 关键设计：通过触发器召回的节点不经过主题预过滤，避免重新陷入相似性检索陷阱。

## 3. 实验设计

### 3.1 数据集 / 场景
- **LoCoMo**：多会话对话数据集，跨越数周至数月，包含四类问题：单跳（Single-hop）、多跳（Multi-hop）、时间（Temporal）、开放域（Open-domain）。
- **LoCoMo-Plus**：在LoCoMo基础上增加了**认知子集**（Cognitive subset），专门探测联想性回忆——cue与答案仅通过叙事或因果线索关联，无词汇/语义接近性。该子集是论文的核心评测场景。

### 3.2 Benchmark与对比方法
- **主对比**（LoCoMo）：Mem0、Zep、Memobase、MemU、Supermemory、MIRIX、MemOS、HyperMem。
- **LoCoMo-Plus**：除了上述部分系统（Mem0、A-Mem、SeCom、MemOS、HyperMem），还包括闭源LLM基线（GPT-4o、Gemini-2.5-Pro）。
- **评估指标**：LLM-as-judge准确率（Overall及四类子类），token-level F1。

### 3.3 实验设置
- 稠密编码器：bge-m3；RRF平滑常数k0=60；构建记忆LLM：GPT-4.1-mini；答案生成与判断：LoCoMo用GPT-4o-mini，LoCoMo-Plus用GPT-4o生成、Gemini-2.5-Flash判断。

## 6. 主要结论与发现

- T-Mem在LoCoMo上达到80.26% Overall准确率，超过最强基线HyperMem 3.25个百分点。
- 在LoCoMo-Plus上达到74.81%，将跨基准差距从之前的28~50个百分点大幅缩小至**5.45个百分点**，证明了联想性回忆的有效性。
- 消融实验揭示：场景级触发器（Scene & Horizon）在LoCoMo上影响甚微，但在LoCoMo-Plus上至关重要（移除后下降达22个百分点），而项目级触发器（Entity+Bridge）在LoCoMo-Plus上效果不明显，因为该基准的cue偏向场景粒度。
- 验证了核心设计理念：现有系统优化的描述性回忆在联想性评测中完全失效，而T-Mem的写时触发器机制弥补了这一盲区。
