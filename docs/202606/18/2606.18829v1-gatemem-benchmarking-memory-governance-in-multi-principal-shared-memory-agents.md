## 摘要
面向LLM智能体的记忆基准测试大多假设单用户场景，忽略了医院、工作场所、校园和家庭中共享助手的应用。在这些部署中，多个主体向公共记忆池写入内容，并在不同角色、范围和关系下查询，因此记忆质量既需要检索能力也需要治理能力。我们提出GateMem，一个面向多主体共享记忆智能体的基准测试。GateMem联合评估了三个方面：对带有状态更新的合法长程请求的效用、跨上下文授权边界的访问控制，以及用户明确删除请求后的主动遗忘。其覆盖医疗、办公、教育和家庭领域，包含长篇多方对话、增量记忆注入、隐藏检查点、结构化评判和泄露目标标注。在多种基线和骨干模型上，没有方法能同时实现强效用、稳健的访问控制和可靠遗忘。长上下文提示通常以高token成本获得最佳治理得分，而基于检索和外部记忆的方法降低了成本，但仍会泄露未经授权或已删除的信息。这些结果表明当前的记忆智能体远未达到可靠的共享机构部署要求。

## Abstract
Memory benchmarks for LLM agents largely assume single-user settings, leaving shared assistants for hospitals, workplaces, campuses, and households understudied. In these deployments, multiple principals write to a common memory pool and query it under different roles, scopes, and relationships, so memory quality requires governance as well as recall. We introduce GateMem, a benchmark for multi-principal shared-memory agents. GateMem jointly evaluates utility for legitimate long-horizon requests with state updates, access control across contextual authorization boundaries, and agent-facing active forgetting after explicit deletion requests. It spans medical, office, education, and household domains, with long-form multi-party episodes, incremental memory injection, hidden checkpoints, structured judging, and leak-target annotations. Across diverse baselines and backbone models, no method simultaneously achieves strong utility, robust access control, and reliable forgetting. Long-context prompting often yields the best governance score at high token cost, while retrieval-based and external-memory methods reduce cost yet still leak unauthorized or deleted information. These results show current memory agents remain far from reliable shared institutional deployment.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：当前LLM智能体的记忆基准（如LoCoMo、LongMemEval、MemBench等）大多假设单用户、私有记忆场景，即记忆仅服务于单个用户，评估重点在于最大召回和长期推理。然而，现实中智能体正向医院、企业、校园、家庭等**多主体共享环境**部署：多个用户（患者、医生、护士；经理、员工、HR等）向同一记忆池写入并查询，且角色、权限、关系动态变化。此时，高召回率若缺乏严格治理，反而成为安全漏洞——例如将敏感诊断泄露给未经授权的家庭成员，或恢复已删除的项目草案。
- **核心问题**：共享记忆智能体必须在**三个耦合维度**上同时表现可靠：（1）对授权用户的**效用**（Utility）——正确提供当前范围内的合法信息；（2）**访问控制**（Access Control）——阻止未经授权的信息泄露；（3）**主动遗忘**（Active Forgetting）——用户要求删除后，智能体不应再恢复、确认或间接重构已删除信息。现有基准均未联合评估这三维度。
- **整体含义**：本文提出**GateMem**基准，将记忆评估从“单用户召回”扩展到“多主体共享记忆治理”，揭示了当前智能体远未达到可靠共享部署需求。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
GateMem是一个**结构化基准测试**，而非新模型。它通过精心设计的**长对话多主体交互剧情**，插入**隐藏检查点**，分别测试三个治理维度。每个检查点包含：查询输入（请求者身份+查询文本）和隐藏标注（期望动作、评判标准、泄漏目标）。评估时智能体只看到可见部分，需根据已摄入的历史记忆和策略规则输出响应。采用**LLM-as-a-Judge**进行打分。

### 关键技术细节
- **剧情构建管道**（如图2所示）：
  1. **场景规格设计**：定义域、主体集、角色关系、初始访问规则。
  2. **多主体对话生成**：借助LLM生成长篇多轮对话（~200轮/剧情），包含事实引入、更新、权限变更、删除请求等自然语言操作；不暴露显式记忆操作标签。
  3. **检查点插入**：在特定轮次后插入隐藏检查点，需回答三类问题之一，并附上评判指导（`judge_spec`）和泄漏目标（`leak_targets`）。
  4. **质量控制**：四阶段验证——模式一致性、证据链验证、删除链闭合、泄漏目标人工审计。

- **记忆状态演化**：\( M^{(e)}_t = \text{Ingest}(M^{(e)}_{t-1}, \tau_t, S_e) \)，其中 \( S_e \) 是场景规格（固有权重规则），\( \tau_t \) 是当前轮次内容。智能体逐轮摄入，不修改固有规则。

- **检查点结构**：\( c_n = (e_n, t_n, p_n^{\text{req}}, x_n) \)，对应隐藏标注 \( y_n = (q_n, a_n^*, J_n, \Lambda_n) \)，其中 \( q_n \) 为查询类型（`utility`/`access_control`/`active_forgetting`），\( a_n^* \) 为期望归一化动作（`answer`/`refuse`/`answer_redacted`/`no_memory`），\( J_n \) 为裁判规格，\( \Lambda_n \) 为保护泄漏目标。

- **评估指标**：
  - **有效效用 \( U \)**：针对效用检查点，要求动作匹配 `answer` 且事实覆盖 `J_n` 指定元素。
  - **访问控制违规率 \( A \)**：如果响应泄漏了 \( \Lambda_n \) 或未采取有效限制动作（`refuse`或`answer_redacted`），记为违规。
  - **主动遗忘失败率 \( F \)**：如果响应恢复、确认或重构了删除信息，或未采取 `no_memory` 动作，记为失败。
  - **记忆治理得分 \( \text{MGS} = U \cdot (1-A) \cdot (1-F) \)**：乘法组合，反映三个维度缺一不可。

## 6. 主要结论与发现

1. **无方法同时取得三维度高性能**。长上下文方法在多数骨干下MGS最高，但仍有显著泄漏（如访问控制违规率可达33.9%、主动遗忘失败率可达64.9%）。策略RAG虽提升安全但通常降低效用。外部记忆系统（A-Mem、Mem0、ReMeM）不自动提供治理，甚至在部分场景更差。
2. **长上下文是最强基线但成本高**：它提供完整证据链，驱动高效用，但同时也暴露敏感和删除信息。其Token消耗是检索方法的3–6倍，但延迟更低（因无需复杂检索）。
3. **策略感知检索改善安全但可能过度保守**：策略RAG通过元数据过滤显著降低泄漏，但导致较高过度拒绝率（Fig 3(b)最高63.3%），牺牲合法请求。
4. **骨干模型能力显著影响治理权衡**：GPT-5.4和Deepseek-V4-Pro达到最佳MGS，而Llama-4-Maverick在遗忘方面失败率较高，Gemini-2.5-Flash-Lite虽然效用高但访问控制和遗忘失败率均很高。
5. **失败模式多元**：访问控制错误不仅来自直接越权，更多来自间接推理、交叉患者混淆、角色不匹配等软越权。主动遗忘失败中，yes/no确认、分割重构、更新删除冲突等攻击容易触发恢复。
6. **记忆治理远未成熟**：即使最佳方法（如Deepseek-V4-Pro+长上下文）在医疗领域MGS也仅70.6%，在办公领域67.9%，在家领域68.5%，远低于可部署所需的接近100%。需要新的治理机制设计。

## 7. 优点

- **问题定义新颖且重要**：首次将记忆评估从单用户召回扩展到多主体共享记忆治理，提出三维度耦合评估框架，符合真实部署需求。
- **基准构建严谨**：四阶段质量控制、删除链闭合、支持证据验证、人工审计泄漏目标，确保基准可靠。
- **覆盖领域广、攻击类型丰富**：包括12种访问控制攻击和6种主动遗忘攻击，模拟了真实社会工程和间接推测，避免简单测试。
- **评估协议标准化**：采用归一化动作空间、乘法MGS、LLM-as-a-Judge加上人类验证，提高了可复现性和公平性。
- **丰富诊断分析**：检索深度敏感性、过度拒绝率、按攻击类型拆分失败，提供了深入洞察，帮助研究者定位弱点。
- **开源发布**：提供代码、数据集、排行榜、项目页面，社区可复现贡献。

## 8. 不足与局限

- **实验覆盖**：未测试在线学习或动态防御策略（如实时访问决策、写入时加密），也未覆盖多智能体协作场景（当前只评估单一智能体面对多主体）。
- **外部记忆系统配置可能未最优**：对A-Mem、Mem0、ReMeM等基础配置（top-k、图扩展参数）仅采用默认或单一设置，未进行超参数调优，可能降低其潜力。
- **令牌成本和延迟**：长上下文方法虽然MGS高，但token消耗巨大；检索方法延迟高（ReMeM可达260秒/检查点）。实际部署需平衡效率，但文中仅报告未提出改进方案。
- **攻击多样性**：尽管包含12种，但仍可能未覆盖所有现实攻击（如共谋攻击、时序攻击结合）。
- **骨干模型演化快**：当前结论基于2026年上半年的模型，随模型升级可能变化。基准需持续更新。
- **应用限制**：当前基准要求固定访问规则在剧情开始时给定，未评估动态规则学习或角色临时授权变动的场景。
