## 摘要
长期对话智能体需要记忆和查询跨会话、多类型、具有复杂关联的信息。现有的智能体记忆系统依赖异构向量和图形数据库，导致记忆信息碎片化并造成跨数据库I/O高延迟。在检索方面，常见的RAG风格方法容易引入噪声、遗漏相关线索且缺乏token预算控制，降低了LLM的准确性和效率。我们提出Mandol，一种聚合式记忆系统，将碎片化的记忆表示和存储整合为统一的记忆原生架构。其核心组件包括：(1) 分层记忆模型，将记忆组织为表示原始记忆信息的基本层和将基本记忆聚合为可追溯抽象记忆的高级抽象层，两者统一表示为结构化语义图；(2) 聚合语义数据结构，结合SemanticMap和SemanticGraph，原生融合键值、向量和图形结构，并提供统一的混合检索算子以消除跨数据库I/O；(3) 定量查询机制，具有查询自适应路由、定量去噪和冲突解决、以及token约束的上下文生成，在检索过程中无需LLM参与。在两个广泛使用的长期对话基准LoCoMo和LongMemEval上的实验表明，Mandol在代表性智能体记忆系统中取得了最佳整体准确率。在性能比较方面，Mandol在10 QPS并发负载下获得了5.4倍的检索加速和4.8倍的插入加速，同时在消费级硬件上仍保持低延迟。

## Abstract
Long-term conversational agents need to remember and query cross-session, multi-typed information with complex correlations. Existing agent memory systems rely on heterogeneous vector and graph databases, which fragment memory information and cause high cross-database I/O latency. For retrieval, common RAG-style methods tend to introduce noise, miss correlated clues, and lack token budget control, degrading LLM accuracy and efficiency.   We propose Mandol, an agglomerative memory system that consolidates fragmented memory representations and storage into a unified memory-native architecture. Its core components include: (1) a hierarchical memory model that organizes memory into a basic layer representing raw memory information and a high-level abstract layer that agglomerates basic memories into traceable abstract memories, both uniformly represented as structured semantic graphs; (2) an agglomerative semantic data structure combining SemanticMap and SemanticGraph, which natively fuses key-value, vector, and graph structures and provides unified hybrid retrieval operators to eliminate cross-database I/O; and (3) a quantitative query mechanism with query-adaptive routing, quantitative denoising and conflict resolution, and token-constrained context generation, all without involving LLMs during retrieval. Experiments on two widely used long-term conversation benchmarks, LoCoMo and LongMemEval, show that Mandol achieves the best overall accuracy among representative agent memory systems. For performance comparison, Mandol also obtains a 5.4x retrieval speedup and a 4.8x insertion speedup under 10 QPS concurrent load, while still maintaining low latency on consumer-grade hardware.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
Mandol 采用“聚合”（agglomerative）方式，将原始记忆（basic memory）通过 LLM 自动提取并聚合为高层次的抽象记忆（如事件链、实体图、用户偏好），所有记忆均用统一的结构化语义图表示。同时设计原生融合键值、向量和图形结构的内存数据结构，并提供无需 LLM 参与的定量检索机制。

### 关键技术细节

#### 2.1 层次化记忆模型（Hierarchical Memory Model）
- **基本记忆层**：由记忆单元（Memory Unit）、记忆空间（Memory Space）和显式/隐式关系构成。记忆单元包含原始信息、语义向量和元数据；记忆空间提供逻辑隔离（按会话、任务、主题等）；显式关系通过规则解析添加（如时序、实体引用），隐式关系（语义相似度）按需计算。
- **高层抽象记忆层**：LLM 自动将基本记忆聚合成三种抽象记忆：
  - **情景记忆（Episodic Memory）**：事件链（时序和因果边）
  - **语义记忆（Semantic Memory）**：实体图（引用和属性边）
  - **情感记忆（Emotional Memory）**：用户偏好演化链（状态更新边）
  每个抽象节点保留指向原始基本记忆的链接（`source_unit_uids`），确保证据可追溯。
- **会话级上下文增强**：对孤立话语添加会话元数据（时间戳、主题）以提升跨会话检索效果。

#### 2.2 聚合语义数据结构（Agglomerative Semantic Data Structure）
- **SemanticMap**：组合键值存储和向量结构，支持异构数据存储和语义查询。记忆单元 ID 为 key，value 包含原始信息和语义向量；提供倒排索引、稠密向量索引和稀疏向量索引。
- **SemanticGraph**：轻量邻接表存储显式结构边，隐式语义关系则从 SemanticMap 的索引按需获取。
- **统一标识**：SemanticMap 和 SemanticGraph 共享相同的内存单元 ID，使操作（查找、过滤、向量搜索、图遍历）返回一致标识，混合检索原子化，消除跨数据库 I/O。

#### 2.3 定量查询机制（Quantitative Query Mechanism）
- **阶段一：查询自适应路由（Query-Adaptive Routing）**
  - 轻量级意图分类器根据查询特征（如时间表达、实体提及）选择相关记忆源并分配候选预算。
  - 在每个激活源中并行执行 BM25 关键词检索、SPLADE 稀疏扩展、稠密向量搜索，通过 Reciprocal Rank Fusion 融合候选列表；然后对 top 候选进行子图扩展（选择性遍历 SemanticGraph），最后用轻量级交叉编码器（cross-encoder）重排序，得到候选 \(c_i\) 的相关性分数 \(S_{ce}(c_i)\)。

- **阶段二：定量去噪与冲突解决（Quantitative Denoising and Conflict Resolution）**
  - **源内去噪**：采用基于**中位数绝对偏差（MAD）**的动态阈值：
    \[
    \tau_{mad} = \text{median}(S_{ce}) - \kappa \cdot \text{MAD}(S_{ce})
    \]
    其中 \(\text{MAD}(S_{ce}) = \text{median}(|S_{ce}(c_i) - \text{median}(S_{ce})|)\)，低于阈值的候选被丢弃（论文中 \(\kappa = 2.5\)）。
  - **跨源冲突解决**：对涉及相同实体但描述不一致的候选，计算仲裁分数：
    \[
    S_{arb}(c_i) = w_{rel} \cdot S_{ce}(c_i) + w_{temp} \cdot f_{time}(c_i) + w_{source} \cdot f_{source}(c_i)
    \]
    其中 \(f_{time}\) 为指数时间衰减，\(f_{source}\) 根据来源置信度权重（基本记忆 1.0，情景记忆 0.8，语义记忆 0.6）。保留最高分记录，丢弃冗余或过时信息。

- **阶段三：Token 约束的高质量上下文生成（Token-Constrained Context Generation）**
  - 采用**最大边际相关性（MMR）**贪心选择算法：
    \[
    \text{MMR}(c_i | S) = \lambda \cdot \text{Rel}(c_i) - (1 - \lambda) \cdot \text{Red}(c_i, S)
    \]
    其中 \(\text{Rel}(c_i) = S_{ce}(c_i)\)，\(\text{Red}(c_i, S)\) 计算候选 \(c_i\) 与已选集 \(S\) 的最大冗余度（基于实体和记忆源重叠）。贪心添加候选直至 token 预算耗尽，优先保留高相关且多样化的证据。

## 7. 优点

1. **统一表示消除碎片化**：层次化记忆模型将所有记忆（基本和抽象）统一为结构化语义图，克服了向量与知识图的割裂。
2. **低延迟**：原生语义数据结构（SemanticMap + SemanticGraph）在单地址空间内融合多种存储模式，避免跨数据库序列化开销；进程内内存架构使得检索和插入延迟极低。
3. **检索质量高**：定量检索机制通过自适应路由、MAD 去噪、冲突仲裁和 MMR 上下文生成，有效减少噪声和冗余，尤其擅长多跳推理和时序查询。
4. **无需 LLM 参与检索**：所有去噪、冲突解决、上下文选择步骤均不调用 LLM，大幅降低推理成本。
5. **轻量级后端仍优于强基线**：使用 0.6B 嵌入模型和轻量重排序器，仍能超越使用 4B 嵌入模型的 EverMemOS，说明方法本身的有效性。
6. **资源友好**：在消费级 GPU（24 GB 显存）上可运行，RAM 占用适中。
