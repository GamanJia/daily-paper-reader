## 摘要
长时域具身操作要求代理记住持久对象、跟踪变化的场景状态，并复用先前的交互知识。然而，现有的代理记忆通常以非结构化历史或基于嵌入的记录形式存储，难以检索与操作相关的对象部件、物理状态、动作效果和可执行技能。我们提出了一种分析概念中心记忆框架，用于具身操作代理。我们的记忆围绕结构化分析概念组织经验，其中对象由语义部件、参数化模板、接地姿态、功能可供性和操作状态表示。它进一步将对象和场景记忆与用于动作引发状态变化的过渡记忆以及用于模板接地和政策接地执行的技能记忆相连接。在运行时，代理执行结构化的从粗到细检索，以识别相关对象、状态、过渡和技能，支持状态一致的推理和技能复用。在依赖记忆的操作、铰接对象泛化、真实世界记忆评估和消融实验上的实验表明，我们的方法在任务完成率、检索准确性、对象再识别和跨对象技能泛化方面优于非结构和基于嵌入的记忆基线。

## Abstract
Long-horizon embodied manipulation requires agents to remember persistent objects, track changing scene states, and reuse prior interaction knowledge. However, existing agent memories are often stored as unstructured histories or embedding-based records, making it difficult to retrieve manipulation-relevant object parts, physical states, action effects, and executable skills. We propose an analytic concept-centric memory framework for agentic embodied manipulation. Our memory organizes experience around structured analytic concepts, where objects are represented by semantic parts, parametric templates, grounded poses, affordances, and manipulation states. It further connects object and scene memories with transition memory for action-induced state changes and skill memory for template-grounded and policy-grounded execution. At runtime, the agent performs structured coarse-to-fine retrieval to identify relevant objects, states, transitions, and skills, supporting state-consistent reasoning and skill reuse. Experiments on memory-dependent manipulation, articulated-object generalization, real-world memory evaluation, and ablations show that our approach improves task completion, retrieval accuracy, object re-identification, and cross-object skill generalization over unstructured and embedding-based memory baselines.

- **研究动机**：现有具身代理在执行长时域复杂操作任务时，需要记忆持久对象、跟踪动态场景状态、重用先前的交互知识。但当前的记忆系统（如非结构化历史记录、嵌入向量式记忆）难以有效检索与操作直接相关的对象部件、物理状态、动作效果和可执行技能，导致重复发现对象、状态丢失、无法利用先验经验等问题。
- **背景**：长期操作任务依赖层次化执行，现有方法要么是端到端 VLA 策略（隐式推理），要么是 agentic 系统（显式规划但依赖手动技能）。两者都缺乏一个既语言可寻址、又对象结构化、接地执行的显式记忆接口。
- **整体含义**：提出一种以结构化分析概念为中心的显式记忆框架，使记忆成为连接感知、推理和执行的桥梁，提升技能复用和状态一致推理能力。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

- **核心思想**：将记忆围绕“分析概念”（Analytic Concept）组织。每个对象被分解为语义部件、参数化模板、几何属性、姿态、功能可供性（affordances）和操作模板。记忆分为**稳定先验知识**和**动态经验记忆**两部分：
  - **稳定先验知识**：语义库（Msem，存储模板的自然语言描述）和模板库（Mtemp，存储可重用分析模板及其参数空间和操作函数）。
  - **动态经验记忆**：对象记忆（Mobj，接地后的对象实例，持久化ID、部件、姿态等）、场景记忆（Mscene，图结构跟踪环境状态）、过渡记忆（Mtrans，动作引发的状态变化）、技能记忆（Mskill，可执行过程，包括模板接地技能和政策接地技能）。

- **关键技术细节**：
  - **记忆构建与更新**：在线接收指令和视觉观测后，通过 VLM 引导的物体/部件检测、SAM 分割、FoundationPose 姿态估计、Point-Transformer 参数回归等工具，将观测对象接地为分析概念，并解析物体身份（通过类别、部件、几何、姿态等多层次匹配），更新对象、场景、过渡和技能记忆。
  - **结构化记忆检索**：采用粗到细两阶段检索。粗阶段根据指令、观测和当前子任务识别候选类别、模板和操作上下文；细阶段应用硬过滤（类别、部件、affordance 一致性）和排序（几何、姿态、场景状态、过渡适用性、技能统计）。
  - **记忆接地推理与执行**：整合检索到的对象、场景、过渡和技能，检查技能前提条件（precondition）与当前场景状态是否一致，利用过渡记忆预测动作效果。选择模板接地技能（由操作模板实例化）或政策接地技能（调用预训练 VLA 策略），执行后验证结果并更新记忆。

- **算法流程**（Algorithm 1 文字说明）：
  1. 初始化稳定库和动态记忆。
  2. 接收任务指令 L 和当前观测 o_t。

- 分析概念中心记忆在记忆依赖操作任务上显著优于无记忆策略及嵌入/关键帧类记忆策略（总平均成功率 69%~70% vs. 基线最高 53%）。
