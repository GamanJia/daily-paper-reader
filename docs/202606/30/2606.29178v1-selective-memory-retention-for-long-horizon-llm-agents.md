## 摘要
对于增强记忆的LLM智能体，何时保留是重要的？我们通过TraceRetain对此进行研究，这是一个轻量级框架，用于冻结的LLM智能体中有限的外部记忆，它根据可解释特征（成功度、年龄、访问频率、冗余度、特异性、相似性、下游效用）对条目进行评分，并在容量满时驱逐得分最低的条目。在使用gpt-5-mini的干净ALFWorld上，外部记忆在两个随机种子下稳定地优于无记忆，但不同有限保留策略之间的差异落在威尔逊95%置信区间内：干净ALFWorld在T=100到T=200时并未自然表现出记忆污染——而保留正是为了解决这一问题。在受控的噪声写入压力（75%合成干扰项）下，无限制记忆和FIFO-K50在Precision@5上下降（20.2%至12.4%和15.8%至3.8%），而TraceRetain-CEM基本不变（16.9%至16.6%），并保持了97/100的任务成功率。其机制是：无限制记忆具有最高的平均相似度（0.87），但精度最低，表明嵌入空间中接近查询的失败干扰项。保真分布评估显示，增强记忆的策略在50个任务中解决了47到49个，而无记忆则为39/50。在饱和的干净基准上，有限保留以零任务成功代价换取了记忆和步骤效率，并且仅在流中包含噪声时才与缓存启发式方法区分开来。

## Abstract
When does retention matter for memory-augmented LLM agents? We study this with TraceRetain, a lightweight framework for bounded external memory in frozen LLM agents that scores entries by interpretable features (success, age, access frequency, redundancy, specificity, similarity, downstream utility) and evicts the lowest-scoring ones at capacity. On clean ALFWorld with gpt-5-mini, external memory robustly improves over no memory across two seeds, but differences among bounded retention policies fall within Wilson 95% CIs: clean ALFWorld at T=100 to T=200 does not naturally exhibit the memory pollution retention is designed to address. Under a controlled noisy-write stress (75% synthetic distractors), unbounded memory and FIFO-K50 degrade on Precision@5 (20.2% to 12.4% and 15.8% to 3.8%) while TraceRetain-CEM is essentially unchanged (16.9% to 16.6%) and preserves 97/100 task success. The mechanism: unbounded memory has the highest mean similarity (0.87) but lowest precision, indicating failed distractors close to the query in embedding space. Held-out in-distribution evaluation shows memory-augmented policies solving 47 to 49 of 50 tasks vs. 39/50 for no memory. Bounded retention buys memory and step efficiency on saturated clean benchmarks at no task-success cost, and only differentiates from cache heuristics when streams contain noise.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：在记忆增强的大型语言模型（LLM）智能体中，记忆保留策略（何时逐出、保留哪些记忆）在什么情况下真正对性能产生影响？
- **背景与动机**：
  - 现有LLM智能体（如Reflexion、Voyager、MemGPT）广泛使用外部记忆来支持长周期任务，但主要关注“写入”和“检索”，对容量限制下的“逐出”策略研究不足。
  - 随着记忆无限积累，可能发生“记忆污染”：相似但无用或失败的记忆挤占重要记忆，降低检索质量和任务成功率。
  - 该问题的回答直接影响可持续持续适应：若保留不重要，可简单采用缓存启发式方法降低成本；若重要，则需投入工程资源实现智能保留。

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：提出 **TraceRetain** 框架，在冻结的基础LLM上，对每条记忆条目计算基于可解释特征的综合评分，当记忆池超过容量`K`时逐出得分最低的条目。
- **关键技术细节**：
  - **特征向量**：每条记忆在时刻`t`提取11个特征，包括成功/失败、归一化年龄、最后访问间隔、访问频率对数值、特异性、冗余度、步骤效率、下游效用、效用置信度、最后检索相似度、平均检索相似度等。
  - **评分函数**：`s_i = wᵀ φ(m_i, t)`，其中`w`为可学习或固定的权重向量。
  - **两种变体**：

    - **TraceRetain-CEM**：使用交叉熵方法（CEM）搜索最优权重，在20个任务调优子集上根据组合目标（成功率、步骤效率、检索精度）优化。
  - **工作流程**：智能体每轮检索前5条最相关的记忆（基于嵌入相似度），与ReAct风格提示结合；任务结束后将轨迹摘要写入记忆池；若容量超限，触发保留策略逐出低分记忆。

## 6. 论文的主要结论与发现
1. **记忆增强普遍有效**：在所有场景中，有外部记忆的策略任务成功率显著优于无记忆（配对符号检验均显著，噪声场景下无限制和FIFO例外）。
2. **干净饱和基准下保留策略差异不显著**：干净T=100/200中，所有有界保留策略（包括FIFO）任务成功率波动在威尔逊CI内，无法区分优劣。有界保留的收益主要体现在**记忆效率**（半容量达到同等效果）和**步骤效率**（减少37%~55%环境步数）。
3. **噪声压力下保留策略区分明显**：当75%写入为失败干扰时，无限制记忆Precision@5从20.2%降至12.4%，FIFO从15.8%降至3.8%，而TraceRetain-CEM几乎不变（16.9%→16.6%），并保持97/100成功率。无限制和FIFO在配对符号检验中未显著优于无记忆。
4. **污染机制**：无限制记忆噪声干扰项嵌入相似度高（0.87）但精度最低，检索到大量相似但失败的条目；TraceRetain通过成功度和冗余度特征降低其分数，保持低相似度高精度。
5. **转移评估**：所有记忆策略在50个保留任务中解决47~49个，无记忆解决39个；有界保留步骤数更少（最少9.52步），无限制记忆精度最高（45.2%）但任务成功率最低，说明规则精度不能完全反映保留目标。
