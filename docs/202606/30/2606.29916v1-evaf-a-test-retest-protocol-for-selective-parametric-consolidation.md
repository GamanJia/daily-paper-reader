## 摘要
长期运行的语言智能体需要机制来决定在工作上下文消失后哪些经验应该保留。检索系统可以重新插入过去的文本，但它们本身并不能表明经验已被选择性地巩固到模型自身的行为中。我们引入了EVAF，一种用于门控LoRA巩固的回声-效价吸引场机制，以及一种用于在受控干扰下测量选择性参数巩固的测试-重测协议。在GPT-2和TinyLlama上，EVAF优先巩固高效价、高惊喜度的经验，同时通过互补的路由记忆路径保留可检索的事实记忆。测试-重测测量显示，与冻结、仅检索和无门控持续更新基线相比，干扰后的行为持久性更强，同时参数漂移和跨角色污染保持在较低水平。结果支持记忆访问与记忆深度之间的分离：检索事实与内化经验是不同的计算操作。

## Abstract
Long-running language agents need mechanisms for deciding which experiences should persist after the working context is gone. Retrieval systems can reinsert past text, but they do not by themselves show that an experience has been selectively consolidated into the model's own behavior. We introduce EVAF, an Echo-Valence Attractor Field mechanism for gated LoRA consolidation, and a test-retest protocol for measuring selective parametric consolidation under controlled interference. Across GPT-2 and TinyLlama, EVAF preferentially consolidates high-valence, high-surprise experiences while preserving retrieval-accessible factual memory through a complementary routed memory path. Test-retest measurements show stronger post-interference behavioral persistence than frozen, retrieval-only, and ungated continual-update baselines, while keeping parameter drift and cross-persona contamination low. The results support a separation between memory access and memory depth: retrieving a fact and internalizing an experience are distinct computational operations.

## 1. 核心问题与整体含义

大型语言模型作为长期运行的语言代理，会积累大量的交互历史。现有记忆系统（如 Mem0、Zep、Letta/MemGPT、HippoRAG、LIGHT）专注于**检索**——在查询时返回“用户之前说了什么”；但本文提出一个正交问题：**哪些经历应该被永久性地内化到模型的参数中**，从而改变模型本身的写作和回应方式，而不仅仅是作为可检索的事实。这本质上是 **选择性参数巩固**（selective parametric consolidation）问题——区分“事实查找”（检索）与“人格塑造”（内化）。EVAF 受互补学习系统（CLS）理论启发，但明确声明是一种**可证伪的机制性协议**，而非完整的认知身份形成理论。

## 2. 方法论

### 2.1 核心思想
- 双系统架构：**快速工作记忆**（前缀状态）与**慢速参数存储**（LoRA 权重）。
- 选择性门控：仅高效价（valence）×高惊讶（surprise）的事件被写入 LoRA。
- 使用**测试-重测协议**（Test-Retest Protocol）来检测参数写入是否真正发生并留存。

### 2.2 关键技术细节
- **快速系统（前缀动态）**：可训练前缀 \( s(t) \in \mathbb{R}^{P \times D} \) 被约束在高维球面流形 \( (S^{D-1}(\sqrt{D}))^P \) 上。更新方程：\( s(t+1) = \Pi_{\text{球面投影}}\big( s(t) + \alpha [ -\nabla_s S_t + \lambda_{\text{con}}(s(t)-s_{\text{EMA}}(t)) ] \big) \)，其中包含惊讶梯度下降和排斥性 EMA 惯性项（维持极限环）。
- **慢速系统（LoRA + 回放 + EWC）**：当门控触发时，对缓冲区 B（容量 4）和回放集 R（从过去流中均匀采样 4 个样本）执行 N_inner=5 步 AdamW 优化，损失为 \( \frac{1}{|B\cup R|}\sum \text{CE} + \lambda_{\text{reg}}\|\theta-\theta_0\|^2_2 \)。
- **双门控**：\( P_{\text{write}}(V_t, S_t) = \sigma(k_v(V_t-\tau_v)) \cdot \sigma(k(S_t-\tau_s)) \)，要求效价和惊讶同时超过阈值（>0.55）才写入缓冲区；缓冲满 4 个后触发一次巩固事件。
- **测试-重测协议**：每次巩固事件前后，测量四个信号：
  - \( \Delta S_{\text{buf}} \)：缓冲区惊讶变化（负值表示写入成功）。
  - \( \Delta S_{\text{rep}} \)：回放集惊讶变化（重复训练样本的反遗忘检查）。
  - \( \Delta S_{\text{global}} \)：流级别惊讶基线漂移。
  - **动态冻结 z 分数**：前后工作记忆轨迹步角度的变化（>3 表示冻结到定点）。

### 2.3 算法流程简述
1. 初始化前缀、LoRA、EMA。
2. 对每个流步骤：
   - 计算惊讶 \( S_t \)。
   - 更新前缀（梯度下降 + EMA 排斥）。
   - 计算效价 \( V_t \)。
   - 若双门控 > 0.55，将样本加入缓冲区。
   - 当缓冲区满（4 个），触发巩固：
     - 采样回放集。
     - 执行 N_inner 步 LoRA 更新（带 EWC 锚点）。
     - 记录测试-重测信号。
     - 清空缓冲区。

## 5. 主要结论与发现

1. **四个机制特征在所有模型上重现**：
   - 测试-重测参数写入信号（所有事件 ∆S_buf < 0）。
   - 操作动态冻结签名（后巩固步角显著下降，z > 3）。
   - 几何锁定（球面约束在机器精度内）。
   - 容量和成熟度感知的重新锚定规则（不同模型需要调整 τ_s、λ_reg、lr_LoRA）。

2. **选择性与稳定性而非深度**：V9 在每个事件 ∆S_buf 上与朴素 LoRA 基线重叠 1σ，但其优势在于保持健康的 ∆S_global、低触发计数方差、以及每种子均保持冻结特征——即“选择性 + 稳定性”前沿。

3. **下游任务信号**：V9 在角色事实识别 CE 上**每格均优于 Frozen**；在短流上优于 B1b（GPT-2 60 轮无重叠 1σ）；长流上 B1b 因过度学习而更优，但 V9 的参数漂移和优化步数低得多（20× 更小 LoRA L2 漂移，150× 更少更新步）。

4. **生成性人格印记**：短流上 V9 的命中率比 Frozen 放大约 54 倍（均值 54% vs 1%，但方差大）；长流上 V9 的特征是**方差降低**（3× 低于 B1b）而非更高均值。

5. **区分性 token 测试**：参数方法（V9、B1b）在 40 token 预算内**零区分性 token**，仅 B3b RAG 能生成；参数路径编码**类型学**（共享主题），检索路径编码**具体细节**——功能正交。

6. **评估时混合（V9 + RAG）**：证实正交性但拒绝简单拼接；识别 CE 未改善，区分性 token 仍≈0。

7. **缩放规则审计**：部分预测性（几何锁定、P-band 规则）、部分拟合（λ_reg 多因子）、部分猜想（lr_LoRA，仅 Mistral 单点支持）。
