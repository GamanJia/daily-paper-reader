## 摘要
动态环境中的终身具身导航要求机器人从零散观测中形成持久的场景理解，这对于依赖显式地图或场景图且难以泛化到结构化设置之外的现有方法仍然困难。我们提出AllDayNav，一种终身自我学习导航框架，通过强化学习将场景动态隐式编码到大模型的十亿级参数中，并由自演进多模态记忆驱动，该记忆维护并更新视觉关键帧、语义描述和时间上下文，同时自主生成开放词汇指令、图像目标和结构化奖励。在跨房间、跨集和跨任务场景的合成和真实环境实验表明，AllDayNav实现了接近100%的成功率，并在路径效率和鲁棒性上持续超越基于地图、VLM和RL的强基线，展示了隐式的、记忆驱动的强化学习作为显式建图的可扩展替代方案，用于可靠的终身导航。

## Abstract
Lifelong embodied navigation in dynamic environments requires robots to form persistent scene understanding from fragmentary observations, which remains difficult for existing methods that rely on explicit maps or scene graphs and struggle to generalize beyond structured settings. We propose AllDayNav, a lifelong self-learning navigation framework that implicitly encodes scene dynamics into the billion-scale parameters of a large model via reinforcement learning, powered by a self-evolving multimodal memory that maintains and updates visual keyframes, semantic descriptions, and temporal context while autonomously generating open-vocabulary instructions, image goals, and structured rewards. Experiments in both synthetic and real-world environments across cross-room, cross-episode, and cross-task scenarios show that AllDayNav achieves success rates approaching $100\%$ and consistently surpasses strong map-based, VLM, and RL baselines in path efficiency and robustness, demonstrating implicit, memory-driven reinforcement learning as a scalable alternative to explicit mapping for reliable lifelong navigation.

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- **记忆-策略协同进化**：通过自主探索逐步构建多模态记忆数据库，记忆同时服务于自我监督任务生成（指令-目标对）和策略训练；策略改进后又能更高效探索，进一步丰富记忆，形成闭环自我提升。
- **隐式表征**：以图像为中心表示导航目标（而非符号指令），记忆持续更新，模拟人类心理意象。

### 关键技术细节
1. **预训练VLA骨干**：
   - 双编码器：SigLIP（语义） + DINOv2（结构），特征融合后通过MLP投影到Qwen2-7B骨干的嵌入空间。
   - 历史压缩：对历史帧使用全局平均池化（GAP）压缩，并应用指数衰减注意力偏置（`α = exp(-λ·时间差)`），使模型在固定计算预算内关注更长历史。
   - 动作表示：预测8个连续局部航点（位置+朝向），利于平滑轨迹执行。
2. **自进化多模态记忆数据库**：
   - 条目结构：RGB关键帧、自然语言描述（由VLM生成）、时间戳、预计算视觉嵌入（LLaVE）。
   - 记忆更新与去重：新帧与当前关键帧的嵌入余弦相似度 >0.15 时视为候选；与已有记忆条目相似度 ≤0.7 时视为新颖，插入新条目；否则仅当新图像与已有描述的文本嵌入对齐更好时才替换。
3. **自指令生成与混合目标检索**：
   - 自指令：每10个周期或记忆增长20%时，将记忆中的描述汇总给Qwen3-VL-8B，生成50个多样化导航指令（涵盖物体、功能、空间、组合、时间等类型）。
   - 混合检索：给定指令，先用VLM从记忆中选最匹配场景（考虑时间戳）；若置信度<0.6或记忆稀疏时，则回退到互联网图像集（预先爬取的室内场景图片），保证训练信号持续可用。
4. **保守Q学习（CQL）策略优化**：
   - MDP形式化：状态=当前RGB + 目标图像 + 历史帧；动作=8个航点；奖励=终端成功奖励(+10) + 进展奖励(相似度过阈值+2) + 时间惩罚(-0.01) + 碰撞惩罚(-0.1)。
   - CQL损失：标准贝尔曼误差 + 保守正则化项（惩罚OOD动作的Q值），设α=5.0。
   - 策略损失：最大化Q值 + 行为克隆正则化（从成功轨迹中MSE监督），λ_bc=0.1。
   - 异步奖励计算：LLaVE嵌入推理在并行流中，不阻塞控制循环。
5. **预训练**：
   - 在Habitat模拟器中，使用HM3D/MP3D数据集，50,000条轨迹（5百万步），80%最短路径 + 20%探索轨迹。
   - 使用强数据增强（运动模糊、亮度/对比度/颜色抖动、高斯噪声、随机相机抖动、灯光变化、随机遮挡/区域移除）弥合Sim-to-Real差距。
   - 训练14K步，batch size 320，AdamW，lr 3.3e-5，余弦退火。
