## 摘要
大语言模型在融入新知识时面临遗忘或昂贵重训练的问题。我们提出DYNA，一种轻量级框架，通过时间知识图谱增强冻结的大语言模型，其中事件作为节点，时间关系作为带时间戳的有向边。该图作为外部可更新的记忆。查询时，DYNA通过随机游走和中心性度量检索相关节点，然后增强大语言模型的响应。在三个时间召回任务上评估，DYNA相比微调减少了约7%的灾难性遗忘，相比标准RAG在时间顺序上提升了约5%。更高的图聚类系数与更好的检索效果相关，表明图结构的重要性。贡献包括：(1) 将情景记忆作为时间知识图谱，(2) 无需重训练的大语言模型增强，(3) 图属性作为检索性能的预测因子。

## Abstract
Large Language Models (LLMs) struggle to incorporate new knowledge without forgetting or costly retraining. We propose DYNA, a lightweight framework that augments a frozen LLM with a temporal knowledge graph where events are nodes and temporal relations are directed, timestamped edges. The graph serves as an external, updatable memory. At query time, DYNA retrieves relevant nodes via random walks and centrality measures, then augments the LLM's response. Evaluated on three temporal recall tasks, DYNA reduces catastrophic forgetting by ~7% compared to fine-tuning and improves temporal ordering by ~5% over standard RAG. Higher graph clustering coefficients correlate with better retrieval, showing that graph structure matters. Contributions: (1) episodic memory as temporal KG, (2) retraining-free LLM augmentation, (3) graph properties as predictors of retrieval performance.

# 论文总结：DYNA: Dynamic Episodic Memory Networks for Augmenting Large Language Models with Temporal Knowledge Graphs in Continuous Learning

## 1. 核心问题与整体含义（研究动机和背景）

大语言模型（LLM）在训练后难以持续融入新知识。现有方法面临两难：重新训练所有数据计算成本高昂；仅在新增数据上微调则会导致**灾难性遗忘**——新学知识破坏已有知识。经典的检索增强生成（RAG）虽可引入外部文本，但难以捕获事件之间的**时间依赖关系**（如先后顺序）。为此，论文提出 **DYNA 框架**，将**时间知识图谱**作为 LLM 的外部情景记忆，使 LLM 在冻结状态下实现持续学习，同时保留时间推理能力。该工作结合了复杂网络科学、知识图谱、认知启发记忆与 LLM 四个领域。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 将每个**事件**表示为知识图谱中的一个**节点**，节点存储事件的文本描述。
- 将事件间的**时间关系**（before、after、co-occurs）表示为**有向、带时间戳的边**。
- 知识图谱作为**连续可更新的外部记忆**，LLM 本身保持冻结（不修改参数）。
- 查询时通过图探索与中心性度量检索相关事件子图，与 LLM 内部知识融合生成回答。

### 2.2 关键技术细节

#### 图构建
- 三种时间关系：before（有向）、after（反向推断）、co-occurs（双向，短时间窗口内）。
- 边权重使用**指数衰减函数**：  
  \( w(v_i, v_j) = \exp(-\lambda |t_i - t_j|) \)，\(\lambda\) 为衰减超参数，控制时间敏感性。

#### 图更新与剪枝
- 时间剪枝：移除早于阈值 \(T_{\text{max}}\) 的节点。
- 度剪枝：移除低连通性的节点，保持图规模可控。

#### 检索机制（三步）
1. **种子节点选择**：从查询中提取关键词/实体，匹配节点，取 top‑k 最相似节点。
2. **随机游走遍历**：从每个种子节点出发执行多次随机游走，沿权重边探索，捕获时间临近事件。
3. **中心性评分**：对访问过的节点，综合 **度中心性**、**接近中心性** 和 **访问频率** 进行排序：  
   \( \text{score}(v) = \alpha \cdot \text{degree}(v) + \beta \cdot \text{closeness}(v) + \gamma \cdot \text{visit\_freq}(v) \)。

#### 响应生成
- 构建增强提示：系统指令 + 检索到的事件（含时间戳）+ 原始查询 → 输入冻结的 LLM。
- 整个过程无需对 LLM 做任何参数更新。

## 6. 主要结论与发现

1. **性能提升**：DYNA 在 TOA 上达到 71.42%，优于最强基线 DynaGen（68.14%），提升约 3.28 个百分点。
2. **遗忘抑制显著**：经过 10 次更新后遗忘率仅 1.70%，远低于标准微调的 34.81%。
3. **检索瓶颈突出**：P@1 仅 21.28%——检索返回的第一个相关节点仅有约 1/5 概率正确，说明检索是主要短板。
4. **图拓扑影响检索**：聚类系数越高的图，检索效果越好；随机游走是性能最重要的贡献者（移除后 TOA 下降 7.59 个百分点），时间边贡献次之（下降 4.37 个百分点）。
5. **局限性确认**：对隐含推理任务（TimeQA Hard）优势缩小至 2.68pp；短序列（<5 事件）下不显著优于 RAG；前 300 事件稀疏图阶段表现弱于 LDCL。

## 7. 优点

- **轻量级**：无需修改 LLM 参数，计算成本低，适合持续部署。
- **结构化时间记忆**：显式编码事件间时间顺序，优于 RAG 的扁平文本。
- **可解释性**：图结构（聚类系数、度）可作为检索质量预测指标。
- **全面消融**：清晰分解了各模块（随机游走、时间边、权重、剪枝）的贡献。
- **开源可复现**：使用 LLaMA 3‑8B（开源），便于其他研究者验证。

## 8. 不足与局限

- **检索精度低**：P@1 仅 21.28%，即使加入时间信息仍难以精确定位单一相关事件，说明需要更先进的检索策略（如个性化 PageRank、基于注意力机制的遍历）。
- **隐含推理能力弱**：当时间关系需要隐性推断时，DYNA 优势很小。
- **冷启动问题**：稀疏图时期（前 300 个事件）表现不如基于预训练嵌入的 LDCL。
- **实时性不足**：10,000 节点时检索需 0.9 秒，可能无法用于亚秒级响应系统。
- **模型通用性未探**：仅测试了 LLaMA 3‑8B，未验证在其他 LLM（如 GPT‑4、Gemini）上的效果。
- **数据集简化**：虽然使用了多个标准基准，但真实世界流式数据可能更嘈杂、更复杂，实验结果可能无法直接迁移。
- **提升幅度适中**：TOA 仅提升 3.28pp，作者也承认这是渐进式改进，并非突破性进展。对于多数实际应用，标准 RAG 可能已足够。
