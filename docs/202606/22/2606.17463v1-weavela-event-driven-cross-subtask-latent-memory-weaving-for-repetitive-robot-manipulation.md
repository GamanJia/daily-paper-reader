## 摘要
视觉-语言-动作（VLA）策略在单步操作中表现出色，但在每个阶段依赖于前一步完成结果的情况下仍然脆弱。核心问题在于结构性的：短窗口VLA缺乏跨子任务边界路由信息的显式通道，而现有的记忆增强变体要么每帧写入、从演示时间阶段检索，要么在子目标事件触发时执行操作，但没有实现显式的子任务到子任务的交接传递给动作专家。我们识别出子目标完成事件作为跨子任务记忆交接的自然时间单元，并提出了WeaveLA（为视觉-语言-动作策略编织潜记忆），一种跨子任务记忆接口，在冻结的VLA骨干之上，通过查询驱动的注意力池化将每个完成的片段压缩为潜令牌，并将其直接路由到下一子任务的动作生成路径中。这种事件触发、动作侧的设计保留了基础策略的短窗口接口，同时增加了轻量级跨子任务通道。通过在RoboMME上使用$π_{0.5}$骨干进行分层评估，WeaveLA的增益恰好出现在需要该通道的地方：在最难的重复切片（SwingXtimes, $N{=}3$）上，成功率从$0\%$提升至$47.8\%$，而单次执行的情节保持不变。每情节配对分析确认增益仅限于那些因果结构需要跨子任务信息的任务。

## Abstract
Vision-Language-Action (VLA) policies have achieved remarkable single-step manipulation, yet they remain brittle precisely where each stage depends on what was just completed. The core issue is structural: short-window VLAs lack an explicit channel for rouxting information across sub-task boundaries, and existing memory-augmented variants either write at every frame, retrieve from demonstration-time stages, or fire at sub-goal events without performing an explicit sub-task-to-sub-task hand-off into the action expert. We identify the sub-goal completion event as the natural temporal unit for cross-subtask memory hand-off, and present WeaveLA (Weave Latent memory for Vision-Language-Action policies), a cross-subtask memory interface that, on top of a frozen VLA backbone, compresses each completed segment into latent tokens via query-driven attention pooling and routes them directly into the action-generation path of the next sub-task. This event-triggered, action-side design preserves the base policy's short-window interface while adding a lightweight cross-subtask channel. Through stratified evaluation on RoboMME with a $π_{0.5}$ backbone, WeaveLA's gains land exactly where the channel is needed: on the hardest repetition slice (SwingXtimes, $N{=}3$), success rises from $0\%$ to $47.8\%$, while single-execution episodes remain unchanged. Per-episode paired analysis confirms the gains are confined to tasks whose causal structure requires cross-subtask information.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有视觉-语言-动作（VLA）策略在单步操作中表现优异，但在重复性操作（如多次摆动、多次拾放）中频繁失败。因为这类任务依赖“前一个子任务刚刚完成”这一信息，而短窗口VLA没有显式通道在子任务边界之间传递信息。每帧写入、检索演示帧等方法要么成本高，要么无法在运行时捕捉子任务完成事件。
- **动机**：识别出子目标完成事件是跨子任务记忆传递的自然时间单元——当一个子任务结束时，下一个子任务恰好需要知道之前完成的情况。基于此，提出一个轻量级、事件驱动的跨子任务记忆接口，在不破坏原有VLA单步能力的前提下，精准解决重复操作中的信息瓶颈。

## 2. 方法论

- **核心思想**：在冻结的VLA骨干（如π₀.₅）上附加一个“潜记忆编织”模块（WeaveLA）。该模块仅在子目标完成事件触发时，将刚完成的子任务片段压缩成固定数量的潜令牌（8个，d=2048），并直接路由进下一子任务的动作生成路径（动作专家），而不是混入语言提示或视觉上下文。
- **关键技术细节**：
  - **触发器**：使用子目标完成事件（在仿真中由模拟器提供，在真实部署中可用模型内部潜变量偏移检测器替代）作为写入时机。
  - **记忆编织器**（Query-driven Memory Weaver）：对已完成子段的视觉、语言、状态特征拼接后，用8个可学习查询令牌通过单步注意力池化（attention pooling）压缩得到记忆潜向量。公式为：`A = softmax(Q K^T / √d_h), m_{k-1} = W_out(A V + Q)`，其中K=V=H。
  - **动作侧注入**：在π₀.₅的Gemma动作专家每一Transformer块中，在自注意力之后、前馈网络之前插入第三个记忆条件AdaRMS模块。记忆令牌先投影到动作专家宽度，然后通过交叉注意力（带RoPE和RMSNorm）产生上下文向量，再生成AdaRMS的缩放和平移参数，调整隐藏状态。这使得记忆调制轻量，且初始接近无调制。
  - **训练策略**：三阶段训练。阶段0：冻结视觉编码器，仅训练动作流匹配损失，建立短窗口策略。阶段1：引入Weaver和记忆通路，仅用动作损失训练，稳定记忆通路。阶段2：启用完整目标（动作损失+记忆‑文本对齐损失+对比损失），对齐损失权重0.05，对比损失0.02。这样做防止了记忆潜向量范数坍塌（见图7）。
  - **训练目标**：主要动作为流匹配损失；辅助损失在阶段2加入，仅用于训练时塑造潜空间，不改变推理输入接口。
- **计算开销**：训练参数量约46M（LoRA+Weaver+动作侧投影），约为冻结的3.4B基础策略的1.4%。由于仅在子目标边界触发写入，运行时开销远小于每帧写入机制。

- **Benchmark**：RoboMME官方基线以及多种记忆增强VLA变体（如MemER、SAM2Act+、FrameSamp、TTT、RMT等）。
- **对比方法**：
  - 无记忆的π₀.₅基线及带过去动作拼接的变体。
  - 符号记忆（基于子目标预测的GroundSG+Gemini/QwenVL）。
  - 循环记忆（TTT、RMT）。
  - 感知记忆（TokenDrop、FrameSamp的三种集成方式：Context/Expert/Modul）。
  - WeaveLA自身在两种训练规模（6任务和16任务）和两种触发器（oracle和潜变量偏移）下的结果。

## 6. 主要结论与发现

- **关键结果**：在RoboMME最难重复切片SwingXtimes (N=3)上，WeaveLA将成功率从0%提升至47.8%（6任务训练）；16任务训练下从4%升至30%。单次执行任务（N=1）成功率保持约100%，说明增益完全来自跨子任务通道。
- **其他发现**：StopCube作为计数关键任务，WeaveLA达到22%（6任务训练），优于无记忆基线（8%），但仍低于FrameSamp+Modul（42%），但分析表明两种方法是正交的，可联合。触发器来源分析：潜变量偏移检测器可恢复oracle触发器68%的增益，且无需外部监督。
- **机制定位**：所有分层和配对分析一致表明，增益集中在对跨子任务信息有因果依赖的任务上（重复Swing、依赖停止StopCube），而非其他任务。

## 7. 优点

- **设计巧妙**：事件驱动写入与动作侧注入，既轻量又精准，不改变基础VLA的单步接口，训练参数量仅1.4%。
- **实验严谨**：通过重复次数分层、困难分层、配对分析等多种统计手段，有力证明了增益的“机制定位”——只在需要的地方激活。
- **消融全面**：从“写什么”“何处写”“何时写”三个维度与SOTA基线对比，明确了各自贡献。
- **实用性强**：潜变量偏移触发器可实现在无外部子目标监督下的部署，且恢复了大部分增益；训练三阶段策略解决了潜表示崩塌问题。
- **开源友好**：提供了子目标边界标注工具和详细超参数。

## 8. 不足与局限

- **依赖子目标边界**：在仿真中使用oracle边界，虽然提出了潜变量偏移检测器作为替代，但在StopCube等纯计数任务上该检测器失效（仅2% vs oracle 12%），仍有待改进。
- **Q-Former提取器不稳定**：用多层解码器替代单步注意力池化后，训练不稳定且成功率骤降至3.5%，原因可能是推断成本高且训练轨迹不稳定，但作者未深入分析。
- **真实机器人验证规模小**：仅一个任务（PickXtimes N=3）20 episodes，缺乏多任务复杂场景的严格评估，结论外推需谨慎。
- **与FrameSamp+Modul的差距**：在StopCube上WeaveLA（22%）落后于FrameSamp+Modul（42%），虽然作者指出两者可组合，但未实验证明。
- **未与最新旗舰模型（如GR00T N1.6）对比**：仅使用π₀.₅骨干，可迁移性未验证。
- **未探讨更大瓶颈宽度的影响**：16令牌未带来提升，但更少令牌（4）则性能崩塌，说明存在最佳带宽但未进一步分析。
