## 摘要
记忆已成为自进化智能体的标准基础，但保留经验并不等同于学习如何通过经验进化。现有的记忆智能体可以存储轨迹、检索反思或积累技能，但往往缺乏选择有用经验、据此行动、编写可复用知识以及维护不断增长的存储库的整体能力。我们提出了OPD-Evolver，一个通过同策略自蒸馏培养此类智能体进化器的慢-快协同进化框架。在快速循环中，OPD-Evolver与四层记忆层级交互，以读取、使用、编写和维护经验，实现快速测试时进化。在慢速循环中，经结果校准的记忆归因和特权后见将这些能力蒸馏到可部署策略中。在跨领域基准测试中，OPD-Evolver比ReasoningBank等记忆系统高出高达11.5%，比Skill0等基于训练的方法高出约5.8%。进一步分析表明，OPD-Evolver内化了高价值经验和记忆管理，使OPD-Evolver-9B能够挑战Qwen3.5-397B-A17B和Step-3.5-Flash等大型对手，超越了记忆增强的智能体，迈向真正合格的智能体进化器。

## Abstract
Memory has become a standard substrate for self-evolving agents, yet retaining experience is not the same as learning how to evolve through it. Existing memory agents can store trajectories, retrieve reflections, or accumulate skills, but often lack the holistic competence to select useful experience, act on it, write reusable knowledge, and maintain a growing repository. We introduce OPD-Evolver, a slow-fast co-evolution framework that cultivates such an agent evolver through on-policy self-distillation. In the fast loop, OPD-Evolver interacts with a four-level memory hierarchy to read, use, write, and maintain experience for rapid test-time evolution. In the slow loop, outcome-calibrated memory attribution and privileged hindsight distill these four abilities into the deployable policy. Across multi-domain benchmarks, OPD-Evolver surpasses memory systems such as ReasoningBank by up to 11.5%, and training-based methods such as Skill0 by ~5.8%. Further analysis shows that OPD-Evolver internalizes high-value experience and memory management, enabling OPD-Evolver-9B to challenge giant counterparts such as Qwen3.5-397B-A17B and Step-3.5-Flash, pointing beyond memory-augmented agents toward genuinely qualified agent evolvers.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
提出**OPD-Evolver**：一个慢-快协同进化框架（slow-fast co-evolution framework），通过同策略（on-policy）自蒸馏将在线交互经验和事后特权信息转化为智能体的进化能力。

### 关键技术细节

#### 快循环（Fast Loop）——在线经验使用
- **四级记忆层次**：轨迹（trajectories）、技巧（tips）、技能（skills）、工具（tools）。每种类型的记忆具有不同复用粒度。
- **检索与选择**：用嵌入相似性从每层检索Top-K候选记忆，然后由智能体策略本身（选择器 Sel_θ）压缩为紧凑上下文。
- **经验指导的执行**：智能体以任务和选择后的记忆为条件进行多步交互。
- **经验编写**：同一策略在回合结束后决策写入哪些记忆到哪一层（可写多个层），并可动态决定写入数量。
- **记忆维护**：每Q=30个任务后，智能体执行多步维护工具调用（lookup, merge, delete），更新存储库。

#### 慢循环（Slow Loop）——同策略蒸馏
- **结果校准的记忆归因**：对于每个记忆m，仅在它被检索的任务组中比较被选入/未被选入时的回报差异，获得校准的记忆分数V(m)。公式：先定义Ω_g^-(m)和Ω_g^+(m)分别为m未被选/被选的任务组，用ρ_g(m)加权，再结合置信因子γ(m)和层先验α_ℓ。这样将延迟的环境反馈转化为每个记忆的密集标签。
- **统一后见蒸馏**：构建四个决策输入（选择、执行、编写、维护），每个决策学生只能看到公共输入zk，教师额外看到特权视野hk（如每个候选记忆的价值、成功轨迹、生产记忆的未来价值、存储库诊断等）。学生采样自己的输出并计算教师分布与学生分布的KL散度（逐token），最小化蒸馏损失L_slow。教师参数冻结（stop-gradient）。蒸馏后只有学生行为被部署到快循环。

#### 算法流程（文字描述）
1. 快循环：对每个任务xt，形成查询，检索各层的候选集，智能体选择子集，用选择后的记忆执行，获得轨迹和回报，然后编写更新记忆；每Q个任务执行维护。
2. 慢循环：对日志中的记忆估计V(m)；对每个决策k，构造(zk, hk)，学生采样输出，教师计算逐token KL散度，优化总损失。

- **偏差风险**：

  - 社会风险：改进记忆复用能力可能放大不安全行为或隐私泄露，需监控和审计。

- **未明确讨论**：
  - 训练总时间（GPU小时）、蒸馏的收敛性分析。
