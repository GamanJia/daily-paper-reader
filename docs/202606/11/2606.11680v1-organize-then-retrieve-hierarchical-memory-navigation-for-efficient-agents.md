## 摘要
大型语言模型（LLM）智能体由于其固有的无状态性，在处理长时程任务时面临困境，所有任务相关信息都需要编码在不断增长的输入上下文中。这导致推理质量下降、推理成本增加以及延迟升高，因此需要高效的工作记忆机制。然而，现有方法要么依赖有损压缩，要么依赖基于相似性的检索，这些方法通常难以捕捉多步智能体任务所需的时间结构和因果依赖关系。在本文中，我们提出了HORMA，一种层级组织与检索记忆智能体，它将经验组织成类似文件系统的层级结构，其中摘要化的实体与相应的原始轨迹相链接，从而在保留详细信息的同时实现高效访问。HORMA将工作记忆分解为两个阶段：结构化记忆构建和基于导航的检索。构建模块通过区分由信息缺失导致的失败和由误导或过载上下文导致的失败，迭代式地优化经验的组织方式。导航模块使用通过强化学习训练的轻量级智能体遍历层级结构，选择最小但充分的上下文，从而减少关键执行路径上的延迟。在ALFWorld、LoCoMo和LongMemEval上，HORMA在受限上下文预算下提高了任务性能，同时在长对话任务中最多仅使用基线token用量的22.17%。与现有方法相比，它始终能实现更好的效率-性能权衡，并有效泛化到未见任务。

## Abstract
Large language model (LLM) agents struggle with long-horizon tasks due to their inherent statelessness, requiring all task-relevant information to be encoded in growing input contexts. The resulting degraded reasoning quality, increased inference cost, and higher latency necessitate efficient working memory mechanisms. However, existing approaches either rely on lossy compression or similarity-based retrieval, which often fail to capture temporal structure and causal dependencies required for multi-step agentic tasks. In this work, we present HORMA, a Hierarchical Organize-and-Retrieve Memory Agent that organizes experience into a file-system-like hierarchical structure, where summarized entities are linked to the corresponding raw trajectories, enabling efficient access without losing detailed information. HORMA decomposes working memory into two stages: structured memory construction and navigation-based retrieval. The construction module iteratively refines how experiences are structured by distinguishing between failures caused by missing information and those caused by misleading or overloaded context. The navigation module retrieves task-relevant context by traversing the hierarchy using a lightweight agent trained with reinforcement learning to select minimal yet sufficient context, thereby reducing latency along the critical execution path. Across ALFWorld, LoCoMo, and LongMemEval, HORMA improves task performance under constrained context budgets while requiring at most 22.17% of the baseline token usage in long conversation tasks. Compared to existing methods, it consistently achieves better efficiency-performance trade-offs and generalizes effectively to unseen tasks.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）智能体在长时程任务中面临严重的上下文瓶颈——由于无状态性，所有任务相关信息必须编码在持续增长的输入上下文中，导致推理质量下降、推理成本增加和延迟升高。现有方法要么使用有损压缩（如摘要、上下文折叠）不可逆地丢弃细粒度信息，要么使用基于语义相似性的扁平检索，无法捕获长交互过程中积累的时间层次结构和因果依赖关系。
- **背景**：尽管已有外部记忆系统试图扩展存储容量，但它们通常将经验组织为独立条目的扁平集合，检索退化为浅层语义匹配，返回时间不一致或上下文无关的信息。现有系统将记忆构建和检索视为一个整体联合优化，导致严重的信用分配问题——当智能体失败时，难以区分是记忆组织、检索还是下游推理的故障。
- **整体含义**：需要一种将记忆构建与检索解耦、同时保留结构化组织和高效导航的工作记忆机制，以实现长时程任务下的效率-性能最佳权衡。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：提出HORMA（Hierarchical Organize-and-Retrieve Memory Agent），将工作记忆显式解耦为两个专业化模块，在共享的类文件系统层级工作空间中操作：
  1. **记忆管理模块（Memory Manager, M_m）**：负责将原始轨迹组织为带有摘要、时间戳和原始证据链接的结构化层级文件系统（如目录/文件结构）。通过递归技能精炼（Recursive Skill Refinement）迭代优化：对比未结构化历史（H）和结构化记忆（H'）的成功/失败轨迹，生成外源性（信息丢失导致失败）和内源性（结构化记忆改善推理）反馈，积累可重用的记忆管理技能库。
  2. **检索模块（Retrieval Agent, M_r）**：通过Bash工具（ls, cd, grep, cat, select, done）导航层级工作空间，主动遍历目录结构，选择最小但充分的上下文。使用**基于证据的重叠奖励（Jaccard系数）**对轻量级检索策略进行强化学习（GRPO）优化，直接优化检索质量，独立于下游推理。
- **关键技术细节**：
  - 记忆工作空间Ft：由结构化文件和目录组成，通过记忆转换算子TF更新。
  - 检索策略π(a_t | o_t, F_t, q) = M_r(C_t | F_t, q) * M_θ(a_t | o_t, C_t, q; P_main)，检索和主智能体分离。
  - 技能演化：通过对比分析，自动生成外源性技能（防止信息丢失）和内源性技能（利用结构化记忆优势），迭代更新管理提示。
  - RL优化：使用GRPO，奖励函数J(C_t, E) = |C_t ∩ E| / |C_t ∪ E|，鼓励精确且紧凑的上下文。

## 6. 主要结论与发现

- HORMA在**所有三个基准**上均取得最佳任务性能（ALFWorld大窗口73.9%成功率，LoCoMo 51.6 L-J，LongMemEval 55.9 L-J），同时**token用量极低**（LoCoMo仅用基线3.07%~22.17%，LongMemEval 1.24%~16.19%）。
- **记忆构建与检索解耦**显著改善信用分配：记忆管理技能可通过对比分析自动积累，RL可仅优化检索而不影响组织质量。
- **层级导航检索优于扁平相似性检索**：在时间敏感任务中，HORMA的非推理错误比embedding检索减少明显。
- **轻量级RL检索器有效泛化**：仅用LoCoMo训练的Qwen 3.5 4B GRPO检索器在LongMemEval上达到58.0% L-J，超越Claude Sonnet 4.5检索器（55.9%），且检索调用更少。
- **高容量记忆管理骨干是必要的**：小模型（Qwen 3.5 4B）即使配合强检索器也无法弥补结构缺陷，证明记忆构建需要强语义推理能力。

## 7. 优点

- **创新性**：首次将记忆构建与检索显式解耦并分别使用不同优化策略（技能演化 vs. RL），解决信用分配问题。
- **实用性**：基于文件系统的层级工作空间可解释、可追踪、可扩展，支持任意复杂度的经验组织。
- **高效性**：检索代理使用Bash工具导航，避免全量相似性搜索，在极低token预算下达到甚至超越无限制基线性能。
- **泛化性**：RL检索器在对话领域训练后零样本转移到交互任务（ALFWorld）和多会话任务（LongMemEval），展现跨域泛化能力。
- **实验完整性**：多维度评估（成功率、L-J、F1、token用量、步数、错误归因），消融详尽，对比方法全面。

## 8. 不足与局限

- **实验覆盖有限**：仅涵盖三类基准，未在更广泛的智能体应用（如WebAgent、游戏、物理机器人）中验证；LoCoMo训练集仅7场对话，规模较小。
- **记忆管理依赖强模型**：当前实现将Claude Sonnet 4.5作为默认管理骨干，对未来研究如何用轻量模型实现等效管理仍属开放问题（表7示小模型性能差距大）。
- **RL训练数据受限**：检索器仅在LoCoMo训练集上训练，未见其他领域数据；尽管展示零样本泛化，但LongMemEval的对话集与LoCoMo仍有一定相似性，可能高估真实泛化能力。
- **外源性技能发现依赖对比分析**：需要同时运行基线（全历史）和HORMA两种设置以生成反馈，增加了系统复杂度。
- **未讨论长链多步交互中的灾难性遗忘**：记忆管理器持续累积技能，但未明确验证技能库是否会因无限增长而退化或冲突。
- **实际部署成本**：虽token用量极低，但需要同时运行管理器和检索两个智能体，额外API调用和延迟可能增加端到端时间，尤其在高频场景下。
