## 摘要
医疗智能体系统日益被期望支持交互式临床决策，而不仅仅是静态的问答。在此类场景中，有效的智能体必须能够复用跨不断演变病例的先前经验，然而现有的记忆机制通常保留原始的历史痕迹，这些痕迹冗余、有噪声且难以管理。更重要的是，它们很少区分哪些记忆对未来推理真正有用。这限制了它们为长时程临床推理积累紧凑且可靠经验的能力。为弥补这一差距，我们提出SkeMex，一种部署后自我进化框架，通过基于技能的记忆改进医疗智能体，而无需更新模型权重。SkeMex将信息丰富的交互轨迹蒸馏为编码可复用程序性知识的结构化技能，并将其组织成一个跨通用、任务特定和动作级别经验的多分支仓库。为了决定应该复用和保留哪些记忆，SkeMex根据环境反馈估计上下文相关的效用，并利用它来指导价值感知的检索和仓库治理。一个闭环的“读-写-评估-治理”生命周期通过写入新技能、更新效用、促进有用记忆和移除有害条目来进一步支持持续进化。跨不同临床任务的实验表明，SkeMex在离线与在线设置中均持续优于代表性的基于记忆的智能体。它还能跨模型主干泛化并支持可迁移的技能记忆。所有数据和代码将公开发布。

## Abstract
Medical agent systems are increasingly expected to support interactive clinical decision making rather than only static question answering. In such settings, effective agents must reuse prior experience across evolving cases, yet existing memory mechanisms often retain raw historical traces that are redundant, noisy, and difficult to govern. More importantly, they rarely distinguish which memories are truly useful for future reasoning. This limits their ability to accumulate compact and reliable experience for long-horizon clinical reasoning. To close this gap, we propose SkeMex, a post-deployment self-evolution framework that improves medical agents through a skill-based memory without updating model weights. SkeMex distills informative interaction trajectories into structured skills that encode reusable procedural knowledge, and organizes them into a multi-branch repository spanning general, task-specific, and action-level experience. To determine which memories should be reused and retained, SkeMex estimates context-dependent utility from environment feedback and uses it to guide value-aware retrieval and repository governance. A closed-loop ``Read--Write--Assess--Govern" lifecycle further supports continual evolution by writing new skills, updating utilities, promoting useful memories, and removing harmful entries. Experiments across diverse clinical tasks show that SkeMex consistently outperforms representative memory-based agents in both offline and online settings. It also generalizes across model backbones and supports transferable skill memory. All data and code will be released publicly.

#### 2. 方法论：核心思想、关键技术细节与流程

    论文提出 **SkeMex** 框架，其核心是一个**闭环的“读-写-评估-治理”自我进化生命週期**。

*   **核心思想**：将医疗智能体的交互轨迹，通过无参数化的强化学习过程，蒸馏为结构化的、可复用的“技能”，并存储在外部技能库中。技能的有效性由环境反馈明确估计，并用于指导检索和库的管理，从而**在不更新主模型权重的情况下实现持续改进**。

*   **关键技术细节**：
    1.  **问题形式化（M-MDP）**：将问题建模为一个基于记忆的马尔可夫决策过程 (Memory-based Markov Decision Process, M-MDP)，其中智能体的策略 **π** 不仅依赖于当前状态，还依赖于可演化的外部记忆库（技能库）。
    2.  **多分支技能库（Multi-Branch Skill Repository）**：技能被组织成三个抽象级别的分支，避免不同粒度的知识相互干扰：
        *   **通用技能（General）**：跨所有任务的通用推理策略。
        *   **任务级技能（Task-Level）**：针对特定临床任务类别（如鉴别诊断）的模式。
        *   **动作级技能（Action-Level）**：关于使用特定工具（如医疗检索）的操作知识。
    3.  **价值感知的技能检索（Value-Aware Retrieval）**：在每个病例开始时一次性检索。检索评分综合了三种信号：
        *   **语义相似性**：本查询与技能的相关度。
        *   **上下文效用**：该技能在类似临床场景中的历史有效性。
        *   **记忆强度**：基于艾宾浩斯遗忘曲线的时效性因子，优先选择最近被强化的技能。
    4.  **轨迹到技能的蒸馏（Trajectory-to-Skill Distillation）**：通过一个**门控轨迹缓冲器**筛选出信息量丰富的轨迹（如含有多步推理或有价值的失败案例）。然后通过一个**两遍蒸馏引擎**（分析遍 + 变异遍）提取出可复用的模式，并生成新技能或更新现有技能。
    5.  **效用驱动的技能估值（Utility-driven Skill Valuation）**：使用**窗口级别（window-level）的估值**，通过计算该技能带来的**相对优势**（Advantage = 轨迹奖励 - 基线奖励）来评估其效用。公平地为成功或失败归因，避免噪音干扰。
    6.  **闭环治理（Governance）**：定期对技能库进行维护，包括合并冗余技能、弃用低效用技能、提升持续有效的技能为“成熟”状态，并限制各分支的容量，以保持库的紧凑和可靠。

*   **公式与算法流程（文字说明）**：
    *   **核心流程**：`M(w+1) = G(V(W(M(w), B(w))))`。其中 `M(w)` 是当前技能库，`B(w)` 是当前窗口采集的轨迹。
        *   **W**：写入运算符，将轨迹转化为新/更新后的技能。
        *   **V**：估值运算符，根据结果更新技能的效用值。
        *   **G**：治理运算符，对库进行维护。
    *   算法从初始技能库 `M(0)` 开始，对每个任务:
        1.  **读取**：根据任务类别检索高价值技能并注入智能体上下文。
        2.  **执行**：智能体（使用LLM主干）与环境交互，生成轨迹 τ。
        3.  **写入**（窗口结束后）：将轨迹 τ 存入缓冲器 B(w)。窗口填满后，**W** 将缓冲器中的轨迹蒸馏为新技能，并通过**V** 更新效用。
        4.  **治理**（每N个窗口后）：**G** 执行合并、弃用等操作。
        5.  **循环**：清空缓冲器，进入下一个学习窗口。

1.  **性能显著提升**：SkeMex在离线和在线设置中，**在所有基准上持续一致地超越ReAct和所有代表性记忆基线**，性能提升巨大。例如，在DeepSeek-V3.2上，离线设置下的平均准确率从ReAct的48.20%提升至56.08%。
2.  **强大的泛化能力**：SkeMex展现出强大的跨模型主干（如Qwen3.6-Plus、Claude Sonnet-4.6）和跨任务设置（从训练任务到未见过的任务）的泛化能力。这表明其提炼出的“技能”是**跨模型的、可复用的程序性知识**，而非依赖于特定模型的模式。
3.  **稳定的在线学习**：在流式任务序列中，SkeMex能够稳定地提升性能（从76.39%到78.56%），而许多基线方法在记忆更新后性能**出现倒退**，表明其价值感知的检索和治理机制能够有效避免负迁移和记忆污染。
4.  **消融验证了设计有效性**：所有核心组件（门控缓冲器、价值感知检索、闭环治理、多分支结构）都对最终性能有显著贡献，移除任一模块都会导致性能大幅下降。

#### 7. 优点

*   **创新的方法论**：提出了一个优雅且完备的“读-写-评估-治理”闭环生命周期，将强化学习的“奖励信号”与技能库的演化精巧地结合起来，形成了高效的自我进化系统。
*   **计算高效**：无需更新模型权重，避免了昂贵的训练开销和灾难性遗忘问题。智能体本身运行在轻量级硬件上（如CPU），而大模型通过API调用，部署成本较低。
*   **实验严谨且全面**：实验设计非常系统和深入，不仅证明了有效性，更深入探究了方法的机理（消融）、鲁棒性（敏感性）和泛化性（跨模型、跨任务），体现了极高的科研严谨性。
*   **良好的可解释性与可控性**：“技能”是一种比原始轨迹更有解释性的记忆形式。开发者可以查看、修改、添加或删除技能，对智能体的行为有更强的控制力。

#### 8. 不足与局限

*   **实验环境的局限性**：尽管基准测试多样，仍无法完全模拟真实临床环境的复杂性（如患者多样性、部门工作流程、伦理决策等），存在从模拟到现实的差距。
*   **额外的推理开销**：SkeMex在推理时增加了技能检索和更长的推理步骤，导致更高的API使用成本和更长的响应时间。作者也坦诚这是方法的一个代价。
*   **技能质量依赖蒸馏过程**：技能提炼的效果依赖于用于蒸馏的轨迹的质量。如果历史交互轨迹本身存在偏差或错误，提炼出的技能也可能是有害的。尽管有门控和治理机制，但这依然是一个潜在的隐患。
*   **未评估所有模型**：虽然跨模型泛化实验很出色，但作者承认由于实验成本，并未穷尽所有主流基础模型。其通用性需要在更广泛的模型上进行验证。
*   **未见明确讨论“技能遗忘”的负面后果**：治理机制通过弃用低效用技能来保证库的简洁。但如果一个有用的技能因为早期的一些失败而被过早地弃用，可能会导致系统“遗忘”掉一些重要的知识，论文未对此进行探讨。
