## 摘要
迭代检索-推理智能体近来在多模态长文档问答中展现出潜力。然而，大多数现有系统维护一个不断增长的单一上下文，混合了检索轨迹、观察结果和中间推理。随着交互的累积，关键证据变得分散和稀释，使得多跳推理变得嘈杂。我们提出MARDoc，一种内存感知细化智能体框架，将长文档问答解耦为三个专门的智能体：探索器用于多粒度多模态检索，精炼器用于将交互轨迹提炼为结构化的证据和推理记忆，反射器用于检查证据充分性并提供有针对性的反馈。在迭代过程中，智能体依赖于动态更新的结构化记忆，而非完整的累积交互历史。这种设计在保留答案关键事实及其逻辑依赖的同时，减少了上下文噪声。在MMLongBench-Doc和DocBench上的实验表明，MARDoc取得了强劲的结果，优于相同骨干网络的基线，证明了结构化记忆在智能体文档问答中的有效性。

## Abstract
Iterative retrieval-reasoning agents have recently shown promise for multimodal long-document question answering. However, most existing systems maintain a single growing context that mixes retrieval traces, observations, and intermediate reasoning. As interactions accumulate, key evidence becomes scattered and diluted, making multi-hop reasoning noisy. We propose MARDoc, a Memory-Aware Refinement Agent framework that decouples long-document QA into three specialized agents: an Explorer for multi-granularity multimodal retrieval, a Refiner for distilling interaction traces into structured evidence and reasoning memories, and a Reflector for checking evidence sufficiency and providing targeted feedback. Across iterations, the agents rely on a dynamically updated structured memory rather than a full accumulated interaction history. This design reduces context noise while preserving answer-critical facts and their logical dependencies. Experiments on MMLongBench-Doc and DocBench show that MARDoc achieves strong results, outperforming same-backbone baselines and demonstrating the effectiveness of structured memory for agentic document QA.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题**：多模态长文档问答中，信息以文本、布局、表格、图表等形式混合呈现，且支持证据往往分散在多页中，要求模型进行跨页面、跨模态的多跳推理。现有迭代检索-推理智能体（如DocAgent、DocDancer）采用“单体上下文流”范式，将所有交互历史（检索痕迹、观察、推理）拼接到一个不断增长的上下文中，导致关键证据被无关噪声稀释，有效推理空间被压缩，多跳推理质量下降。
- **意义**：亟需一种能够保留关键事实和逻辑依赖、同时抑制上下文膨胀的方法，以提高文档级问答的准确性和鲁棒性。

## 2. 方法论：核心思想与关键技术细节

- **整体框架**：提出 **Explore-Refine-Reflect** 循环，将任务解耦为三个专用智能体，通过动态更新的**结构化记忆**（Evidence Memory + Reasoning Memory）通信，完全替代传统累积对话历史。
- **文档处理**：使用 MinerU2.5 解析文档得到细粒度语义节点（保留布局），并用 Qwen3-VL 为图像、表格等生成描述性文本，构建统一索引的提纲。
- **Explorer（探索器）**：基于 ReAct 框架，输入查询、提纲、当前记忆和反射指令，调用多粒度工具集（search、get_section、get_paragraph、get_page_images、get_image、get_table_image、search_metadata）逐步检索证据并生成候选答案。
- **Refiner（精炼器）**：模拟人类专家压缩信息的过程，将 Exploror 的推理链和交互痕迹蒸馏为两部分：
  - **Evidence Memory**：记录与查询最相关的事实陈述及其来源（去除冗余）。
  - **Reasoning Memory**：提取清晰的推理路径，将证据节点连接成链，标注依赖关系。
  - 新记忆覆盖旧记忆，避免上下文无限增长。
- **Reflector（反射器）**：检查压缩后的结构化记忆，判断证据是否足以回答查询：
  - 若充分，直接输出最终答案。
  - 若不充分，生成针对性反馈指令（如缺失的具体数据、错误的方向），引导下一轮探索。
- **迭代**：最大迭代次数 K=3，每次探索至多 10 步工具调用。

## 6. 主要结论与发现

- MARDoc 在 MMLongBench-Doc 上以 Qwen3-30B 达到 57.1% ACC，与使用 Claude 3.5 Sonnet 的 DocAgent（57.3%）相当，且在 DocBench 上同样领先同骨干基线。
- 结构化记忆（证据记忆 + 推理记忆）比纯文本压缩方式在单跳、多跳和不可答问题上均表现更好，分别抑制幻觉和维护推理连贯性。
- 随着证据页面数增加，MARDoc 性能下降幅度小于 DocAgent，说明结构化记忆能有效保持多跳推理能力。
- Reflector 的指令在 K=3 时最优，过多迭代会导致冗余信息稀释；无指令时模型易误判为不可答。
- 细粒度文档解析（MinerU2.5）和多粒度工具集对性能提升贡献显著。

## 7. 优点

- **创新点**：提出结构化记忆替代累积上下文，直接从根源缓解上下文稀释问题，设计明确、可解释。
- **解耦设计**：将检索、精炼、反射分离，各司其职，组合灵活；精炼器模拟人类压缩信息过程，反射器实现自我纠错。
- **实验严谨**：消融实验全面（组件、记忆结构、指令、迭代次数、文档处理、计算成本），且在两个基准上验证一致性。
- **零微调即取得竞争力**：表明方法本身有效，不依赖特定训练数据或大规模调参。
- **可扩展性**：更强骨干（32B）上进一步提升性能，验证框架的可扩展性。

## 8. 不足与局限

- 所有智能体均基于提示工程构建，未进行任务特定微调；若能微调或将进一步提升性能。
