## 摘要
LLM代理的长期记忆不仅仅是适时检索正确的段落。当前的记忆系统将信念修正、因果耦合和跨领域抽象压缩到一个单一检索表面中，以追求表层回忆，因而在处理需要推理用户如何演变的隐性个性化任务时表现不佳。我们提出DCPM，它沿着认知能力层级重新组织代理记忆，从原始输入和原子事实开始，经过历时信念轨迹和身份，上升到领域图式、潜在意图和跨领域模式。该层级由继承双过程理论架构分离的两个过程驱动：一个同步的日间写入器（System1）记录信念修正为双向链接的取代链，以及一个异步的夜间引擎（System2）归纳图式和意图，并扫描跨领域冲突，将其抽象为更高级的核心图式。在LongMemEval、PersonaMem和PersonaMem-v2上，启用System2在基准测试奖励隐式跨会话推理的任务中贡献最大（在PersonaMem-v2上高达+5.20），而在跨度回忆任务上贡献最小，这与架构预测一致。

## Abstract
Long-term memory for an LLM agent is more than retrieving the right passage at the right time. Current memory systems collapse belief revision, causal coupling, and cross-domain abstraction into a single retrieval surface tuned for surface recall, and consequently struggle on implicit personalisation that requires reasoning over how a user has evolved. We propose DCPM, which reorganises agent memory along a cognitive capability hierarchy ascending from raw inputs and atomic facts, through diachronic belief trajectories and identity, to domain schemas, latent intentions and cross-domain patterns. The hierarchy is driven by two processes inheriting the architectural split of dual-process theory: a synchronous daytime writer (System1) that records belief revisions as doubly linked supersedes chains, and an asynchronous nighttime engine (System2) that induces schemas and intentions and sweeps for cross-domain collisions abstracted into higher-level core schemas. On LongMemEval, PersonaMem and PersonaMem-v2, enabling System2 contributes most where the benchmark rewards implicit cross-session inference (up to +5.20 on PersonaMem-v2) and least on span recall, matching the architectural prediction.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：当前LLM智能体的长期记忆系统被简化为纯粹的检索问题，将信念修正、因果耦合和跨领域抽象压缩到单一检索表面。这导致智能体无法处理需要推理用户行为演变的隐式个性化查询（例如，用户偏好为何改变、跨领域行为模式是什么）。
- **背景**：现有系统（如Mem0、Zep/Graphiti）主要停留在被动存储层面，缺乏对记忆认知能力的层次化组织。作者认为记忆不仅是存储，更是认知——需要追踪信念演化的轨迹、建立因果联系、归纳高阶模式。

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想
- 提出**DCPM（双过程认知记忆系统）**，基于双过程理论（Kahneman）将记忆处理分为**同步的System 1**（快速在线编码）和**异步的System 2**（缓慢离线抽象）。
- 沿着**认知能力层级**组织记忆：原始输入&原子事实 → 身份&历时取代链 → 领域图式 & 潜在意图 → 跨领域核心图式。

### 关键技术细节

**System 1（同步日间写入器）**
- 触发方式：由用户或应用显式调用 `add_memory` 请求（非每轮对话）。
- 步骤：
  1. **原始持久化**：将原始输入写入向量存储，确保零丢失。
  2. **提取**：使用提取LLM（`Me`）从当前轮次和最近历史窗口提取身份项（长期用户属性）和原子事实，附带类型、主题、显著性、时间戳。
  3. **调和**：使用调和LLM（`Mr`）决定对每个新项执行ADD（完全新增）、SUPERSEDE（矛盾/演进）、UPDATE（补充/扩展）操作。重复项丢弃。
  4. **批量更新与取代链**：对于SUPERSEDE项，添加双向指针（`new.SUPERSEDES = old`，`old.SUPERSEDED_BY = new`），形成双向链表；前任不删除。这是区别于原地更新系统的关键：允许读取时通过指针遍历完整演化弧，而不依赖嵌入相似度。

**System 2（异步夜间引擎）**
- 运行时机：空闲或夜间窗口，松弛延迟预算。
- 三个阶段：
  - **Phase 1 预处理（无LLM）**：事实筛选（尚未被图节点引用的事实），两阶段DBSCAN聚类（第一阶段ε1=0.35，第二阶段ε2=0.25，min_samples=3），寻找最近邻图节点。
  - **Phase 2 LLM智能体归纳**：对每个聚类调用归纳智能体`Ma`，拥有四个工具：CREATE_SCHEMA（创建领域内行为规律节点）、CREATE_INTENTION（创建潜在关注点节点）、ADD_EVIDENCE（将聚类事实ID附加到现有图节点）、ADD_EDGE（在节点间写结构边）。图逐步增量演化。
  - **Phase 3 跨领域扫描器**：
    1. 行为抽象：对每个图式，LLM抽象出简短行为描述，编码到行为-认知空间`E_beh`；语义嵌入用`sentence-bert`得到`E_sem`。
    2. 碰撞扫描：枚举跨领域图式对，若`cos(E_beh)>θ_beh`且`cos(E_sem)<θ_sem`（θ_beh=0.72，θ_sem=0.40），则标记为碰撞。用并查集聚类。
    3. 核心图式归纳：对每个碰撞簇，调用核心图式LLM `Mc`，归纳出更高级的核心图式，写回图并链接到所有成员图式。

**读取路径**：查询嵌入通过向量相似度命中事实/身份存储，遍历任何附加的取代链，然后在图G中查找`evidence_vdb_ref`边包含匹配事实ID的图式、意图、核心图式节点。**全程无LLM调用**，延迟由向量搜索主导。

**复杂度**：System1写代价O(N log N)；System2 Phase1 O(N)，Phase2 O(|C|) LLM调用，Phase3 O(D ̄s) LLM调用 + O((D ̄s)²) 向量比较（实际D≤20，̄s≤30，可接受）。读复杂度O(log N + k̄)，k̄=2.4。

## 6. 主要结论与发现

1. **双过程架构预测成立**：System 2在隐式跨会话推理（PersonaMem-v2）上贡献最大（+5.20对kimi-2.5），在简单跨度召回（LongMemEval）上贡献很小（+0.33），在中等难度（PersonaMem）上贡献居中（+2.41）。此不对称模式验证了双过程理论中System 2负责高级模式提取的假设。
2. **核心图式占比极小但贡献巨大**：跨域核心图式仅占所有记忆节点的1.3%，但在消融实验中贡献约4.1个点。说明少量高阶认知抽象能显著提升隐式推理性能。
3. **取代链机制至关重要**：消融实验显示，即使关闭System 2，保留取代链的System 1仍比完全移除取代链的系统高2.9个点。在LongMemEval知识更新子集上，正确回答中有78%触及取代指针，错误回答中仅31%，验证了历时轨迹对信念恢复的正面作用。
4. **DCPM full超过长上下文基线**：在PersonaMem-v2（kimi-2.5）上，DCPM full达到59.30%，超过全历史基线的58.20%，表明结构化记忆可缓解长上下文中的“丢失在中间”效应。
5. **记忆节点分布合理**：事实节点占主导（42.8%），身份项36.7%，摘要9.0%，基础图式8.9%，意图和核心图式各1.3%。系统未大量产生无意义的高阶节点。

## 7. 优点：方法或实验设计上的亮点

### 方法亮点
- **认知能力层级**：首次将LLM智能体记忆按认知复杂度分层（事实→身份→图式→意图→核心图式），超越了单纯存储-检索的视角。
- **双过程架构**：将在线写入与离线抽象分离，白天快速记录、夜晚深度处理，符合认知科学理论且实用。
- **取代链**：用双向链表记录信念演化，避免原地更新丢失中间态，且读取时仅需指针遍历，无需额外LLM。
- **双空间碰撞检测**：在行为-认知空间和语义空间联合评估跨域图式相似性，能发现表面不同但行为模式相同的图式，归纳为核心图式。
- **读路径无LLM**：保证推理延迟与向量搜索相当，可实际部署。

### 实验亮点
- **诊断性基准选择**：三个基准分别聚焦不同认知缺口（历时连续性、显式回忆、隐式推理），使结果直接对应架构设计。
- **消融实验设计**：按认知层级逐级移除组件，清晰分离三个贡献（取代链≈2.9，图式/意图≈1.1，跨域碰撞≈4.1）。
- **粒度分析**：提供节点类型分布、取代链统计、问题类型准确率，支撑理论解释。
- **定性案例**：展示健身偏好取代链和跨域碰撞的具体例子，直观说明系统行为。

## 8. 不足与局限
