## 摘要
解决通用任务的机器人需要能够将指令与过去的经验联系起来，因为人类在给出任务时可能会提及显著的过去事件（例如，“带我去昨天发生化学品泄漏的地方”）。由于记忆限制使得存储所有过去事件不可行，长期机器人记忆必须具有选择性，理想情况下只保留那些对未来任务有高实用性的事件。然而，对于通用机器人而言，未来的任务通常不是先验给定的。为了选择具有通用用途的记忆，我们提出贝叶斯惊喜作为记忆形成的门控机制。我们提出了一种方法，在V-JEPA-2提供的语义丰富且与部署无关的潜在空间中计算惊喜。使用我们的门控情景记忆来增强基于4D场景图的机器人空间记忆，我们在机器人问答任务中比现有最先进基准一致提高了性能，在时间、空间和二进制问题上优于之前的机器人记忆方法≥12%，并在事件分割任务中以无监督因果方法超越了监督和非因果方法的性能。

## Abstract
Robots solving generalist tasks need to be able to ground instructions in their past experience, since humans may refer to notable past events when giving a task (e.g., ``Take me to where the chemical spill happened yesterday''). Since memory limits make storing all past events infeasible, long-term robot memory must be selective, ideally retaining only those episodes with high utility for future tasks. However, future tasks are not typically given a priori for generalist robots. To select generically useful memories, we propose Bayesian surprise as a gating mechanism for memory formation. We present an approach to compute surprise in a semantically rich deployment-agnostic latent space provided by V-JEPA-2. Using our gated episodic memory to augment 4D scene graph-based spatial memory, we show a consistent improvement over state-of-the-art benchmarks in robot question answering, outperforming prior robot memory methods by $\geq12\%$ for temporal, spatial, and binary questions, and surpassing the performance of supervised and non-causal methods with an unsupervised causal method in event segmentation tasks.

## 2. 方法论
### 2.1 核心思想
- 利用**贝叶斯惊喜**（KL散度 between 观测前后预测分布）筛选值得记忆的帧，仅存储高惊喜事件以节省资源。

### 2.2 关键技术细节
- **嵌入提取**：对因果滑动窗口（M=64帧）应用V-JEPA-2编码器，将输出池化为单一特征向量 \(z_t \in \mathbb{R}^{1024}\)。

  \(s(t) = \frac{1}{D} \sum_{d=1}^D \frac{|z_t[d] - \mu_W[t,d]|}{\sigma_W[t,d]}\)  
  并证明在高斯假设下等价于逐点惊奇（surprisal）加上与观测无关的常数项。
- **阈值门控**：使用中位数绝对偏差（MAD）设定鲁棒阈值 \(\tau = \text{med}(s) + \gamma \cdot \frac{1}{\Phi^{-1}(0.75)} \cdot \text{MAD}(s)\)，并执行非极大抑制去重，仅保留局部峰值。

## 6. 优点
- **认知启发的强理论基础**：将认知科学中的贝叶斯惊喜用于机器人记忆，具可解释性。
- **无监督、在线、部署无关**：无需任务先验或训练，V-JEPA-2潜在空间泛化到不同环境。
- **高效存储**：仅存储约1.7%的帧，显著降低长期记忆负担。
- **系统集成友好**：可即插即用增强现有4D场景图记忆（DAAAM），并在问答和事件分割任务中均取超越SOTA的结果。
- **鲁棒阈值设计**：使用MAD和L1损失抑制高维特征重尾分布干扰，稳定触发。

## 7. 不足与局限
- **预测模型简单**：滑动窗口对角高斯模型表达能力有限，未利用V-JEPA-2-AC等因果预测架构，可能漏掉部分非惊喜但重要事件。
- **领域泛化不足**：在TAPOS（奥运体育视频）上性能远低于监督方法和部分离线方法，说明在线惊喜对于语义边界（如“跑→跳”）检测力较弱，且受限于领域偏差。
- **未考虑习惯化**：重复出现但意外的主体仍会持续触发存储，缺乏驯化机制导致冗余。
- **检索粒度粗**：仅用文本-图像嵌入和单帧最大相似度，无法捕捉事件时序演变；未来可探索文本-视频嵌入。
- **依赖特定预训练模型**：V-JEPA-2虽通用，但其训练数据和计算资源未公开，可能影响可复现性。
- **评测范围有限**：未在室内、多机器人或操作任务中验证，且OC-NaVQA基准可能隐含引用真实世界分布偏差（野外数据，但非标准化环境）。
