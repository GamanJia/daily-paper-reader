## 摘要
现代大语言模型（LLM）代理能够使用外部工具帮助用户解决复杂任务。然而，对于需要从长期历史事件或代理-环境交互中学习的问题，LLM代理必须使用记忆机制来存储和检索经验。尽管对话代理存在复杂的记忆系统，但很少有研究实证检验如何通过过去用户-代理对话提升代理的工具使用能力。我们提出MemToolAgent，一种通过记忆管理改善工具使用的框架。我们的方法包含一个记忆提取模块，将过去经验处理为结构化记忆条目；以及一个检索模块，动态选择存储的记忆条目子集。这使得无需微调LLM即可生成更个性化、更准确且符合用户偏好与反馈的响应。总之，本研究主要有三个贡献：（1）一种统一的记忆条目格式，无需微调LLM即可提升通用与个性化工具使用；（2）一种基于反思的记忆提取，利用环境和用户反馈将错误执行转化为批判性记忆进行存储；（3）一种基于记忆相似度分布选择使用多少过去经验的检索模块。在WorkBench、NESTFUL和PEToolBench基准上，MemToolAgent相比强基线分别取得了29%、80%和17%的相对提升。

## Abstract
Modern large language model (LLM) agents can use external tools to help users solve complex tasks. However, for problems that require learning from long-term historical events or from previous agent-environment interactions, LLM agents are required to use memory mechanisms to store and retrieve experiences. While sophisticated memory systems exist for dialogue agents, few studies have empirically examined how to improve agents' tool-using capabilities through past user-agent conversations. We propose MemToolAgent, a framework that improves tool use through memory management. Our approach contains a memory extraction module that processes past experiences into structured memory entries, and a retrieval module that dynamically selects a subset of the stored memory entries. This enables more personalized and accurate responses aligned with user preferences and feedback without requiring LLM fine-tuning. In summary, this work has three main contributions: (1) a unified memory entry format that improves both general-purpose and personalized tool use without LLM fine-tuning, (2) a reflection-based memory extraction that uses environment and user feedback to distill wrong executions into critiques to store, and (3) a retrieval module that chooses how many past experiences to use based on the memory similarity distribution. MemToolAgent achieves 29%, 80%, and 17% relative improvements compared to strong baselines on the WorkBench, NESTFUL, and PEToolBench benchmarks, respectively.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：通过构建统一的记忆条目格式存储过去经验（包括用户查询、工具调用序列、用户反馈、反思/批判），利用检索增强推理，并基于环境与用户反馈驱动记忆的增量更新。
- **关键技术细节**：
    1. **统一记忆条目格式**：每个记忆条目表示为四元组 `m = (q, a, f, r)`：
        - `q`：用户查询
        - `a`：工具调用序列
        - `f ∈ {0,1}`：二进制用户反馈（成功/失败）
        - `r`：当`f=0`时由记忆提取模块生成的反思/批判（否则为∅）
    2. **动态“n” Top-n 嵌入检索（Dynamic "n" Retrieval）**：
        - 计算测试查询与所有记忆条目嵌入的余弦相似度，降序排列。
        - 使用滑动窗口估计算法计算相似度序列的一阶导数。
        - 利用 `scipy.signal.find_peaks` 找到导数峰值（即相似度骤降点），选取第指定峰值对应的位置作为检索条目数 `n`。
        - 相比固定Top-k和Adaptive-k，该方法对噪声相似度曲线更鲁棒，能自动适应不同查询的最优上下文量。
    3. **记忆提取模块**：
        - 当用户反馈为失败时，调用LLM（称为E）对当前查询、工具集、代理动作、环境反馈、用户反馈及检索到的相似记忆进行反思，生成结构化批判。
        - 批判被存储而非原始跟踪，避免代理在解决当前任务时同时分析复杂历史轨迹。
        - 对个性化任务，记忆提取模块还提取高级用户偏好（如“用户偏好API_X下的工具”）。

### 6. 论文的主要结论与发现

1. **统一记忆格式+动态检索+反思提取**三个组件协同，在通用和个性化工具使用任务上均显著超越基线：
    - WorkBench总体准确率从57.56%提升至85.06%（+48%相对），其中Analytics从18.52%提升至86.11%。
    - NESTFUL完全序列匹配从15.6%提升至30.4%（+95%相对），胜率从51.2%提升至70.2%。
    - PEToolBench工具准确率从0.509（原始方法）提升至0.820，相比A-MEM/Mem0相对提升17%。
2. **反思/批判优于原始轨迹**：直接提供失败轨迹会降低代理效率，通过独立模块蒸馏出结构化批判能显著提升学习效果。
3. **动态检索优于固定Top-k**：自适应确定检索数量，避免不足或冗余，在WorkBench和NESTFUL上均一致优于固定k值。
4. **合成查询可缓解冷启动问题**：在无真实历史数据时，基于工具描述生成的合成查询也能带来性能提升（除复杂多域任务外）。
5. **输出Token更少**：相比扩展思考和ReAct，MemToolAgent输出Token更少，降低成本与延迟。

### 7. 优点

- **方法简洁通用**：统一记忆格式（q, a, f, r）适用于不同场景，无需任务特定适配。
- **无需LLM微调**：完全基于检索和提示工程，便于部署和持续更新。
- **动态检索机制创新**：基于导数峰值的动态n选择，解决了固定Top-k的适应性不足问题，且对噪声曲线鲁棒。
- **反思蒸馏有效**：将复杂轨迹浓缩为批判，减轻了代理上下文负担，使失败经验更易利用。
- **实验覆盖较全面**：涵盖两个通用基准和一个个性化基准，消融实验系统，并测试了不同骨干模型（Claude 3.5/3.7/4 Sonnet）。
- **对实际部署友好**：输出Token更少意味着更低成本和更快响应。

### 8. 不足与局限

- **冷启动问题**：初始无记忆时性能下降，虽提出合成查询缓解，但复杂多域任务效果有限。
