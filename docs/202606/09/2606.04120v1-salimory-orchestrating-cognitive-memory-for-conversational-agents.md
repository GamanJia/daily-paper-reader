## 摘要
作为终身伴侣的对话代理必须在所有交互中保持持久记忆。然而，简单通过原始检索扩展上下文窗口会降低推理质量，而通过标准强化学习训练记忆代理则会在多阶段流程中造成严重的信用分配瓶颈。为解决此问题，我们引入了SALIMORY，一个训练单一语言模型来管理认知结构化的记忆——涵盖用户事实、偏好和工作记忆的框架。通过引入分层阶段式过程奖励和奖励分解对比细化，SALIMORY为不同的记忆操作（选择性过滤、整合和线索驱动回忆）提供端到端的孤立监督。SALIMORY将记忆归因故障减少了三分之一，端到端准确率比最先进模型高出10%以上，并且良好个性化率翻倍以上。

## Abstract
Conversational agents that serve as lifelong companions must maintain persistent memory across all interactions. However, simply expanding context windows with raw retrieval degrades reasoning quality, while training memory agents via standard reinforcement learning creates a severe credit assignment bottleneck in a multi-stage pipeline. To solve this, we introduce SALIMORY, a framework that trains a single language model to manage a cognitively-structured memory-spanning user facts, preferences, and working memory. By introducing a hierarchical stage-wise process reward and reward-decomposed contrastive refinement, SALIMORY provides isolated supervision for distinct memory operations (selective filtering, consolidation, and cue-driven recall) end-to-end. SALIMORY cuts memory-attributed failures by one-third, outperforms the state-of-the-art by over 10% in end-to-end accuracy, and more than doubles the Good Personalization rate.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 将记忆分为三个互补存储：**事实库**（客观可验证）、**偏好库**（主观品味）、**工作记忆**（近期细节）。训练一个统一策略模型 πθ，通过不同指令提示扮演三个角色：*Saliency Filter*（选择性注意）、*Memory Booster*（整合与更新）、*Memory Utilizer*（线索驱动回忆并合成查询适应概要）。
- 采用强化学习（GRPO）优化，但引入**分层阶段式过程奖励**和**奖励分解对比细化**，为每个记忆角色提供孤立的监督信号，解决信用分配问题。

### 关键技术细节
1. **分层阶段式过程奖励**：
   - **R1：响应质量（乘法门控）**：准确率α×（1+λp·p），确保个人化仅在正确答案上有价值。
   - **R2：记忆质量（不对称惩罚）**：γ=事实性×（1−模糊性），奖励γ，惩罚(1−γ)，且惩罚权重λ_pen>λ_bon，鼓励保守写入（宁缺毋滥）。
   - **R3：利用与过滤质量**：μ评估合成概要的相关性，κ评估过滤器的二元决策（召回加权调和平均）。
   - 总奖励L_GRPO = R1+R2+R3。

2. **奖励分解对比细化（L_Cont）**：
   - **Booster对比对**：基于R2得分选取胜者/败者，用差距权重ΔR2缩放对比损失。
   - **Utilizer对比对**：基于μ得分选取，但仅当两个rollout的记忆库Jaccard相似度>τ_sim时形成对比对，以隔离利用器的真实合成能力。
   - 总损失L_total = 1/N Σ L_GRPO(ξ) + L_Cont，选择性梯度路由：GRPO更新所有（含滤波），L_Cont仅更新booster和utilizer。

3. **算法流程**（离线+在线）：
   - **离线阶段**：处理整个对话session，滤波→整合适配（异步更新三个存储）。
   - **运行时阶段**：用户查询到来，utilizer合成查询相关概要，冻结生成器π_gen产生最终响应。

## 7. 优点

- **认知启发的记忆架构**：模仿人类记忆系统，分离事实、偏好和工作记忆，允许差异化处理，避免混淆。
- **端到端优化记忆管理**：训练单一模型执行所有记忆角色，而不是依赖多个分离模块或静态提示。
- **新颖的RL训练范式**：分层阶段过程奖励+奖励分解对比细化，解决多阶段信用分配问题，确保每个角色只接受应得的梯度。
- **新基准与评估协议**：提出LoCoMo-P13n和三层个人化法官，更细致评估记忆使用质量，发现Underuse和Bad个人化等隐性失败模式。
