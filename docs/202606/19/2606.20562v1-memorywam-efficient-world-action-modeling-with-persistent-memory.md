## 摘要
现实世界中鲁棒的机器人操作不仅需要理解当前观察，还需要记忆和动力学建模。世界动作模型（WAM）通过联合建模视觉预见和基于当前与历史观察的动作，具备了这些能力，成为机器人操作的一个有前景的范式。然而，现有的WAM面临一个根本性的权衡：具有高效推理的方法通常仅以最近观察的有界窗口为条件，因此在非马尔可夫环境中表现不佳；而保留长历史的方法则会产生时间和空间成本，且随序列长度大幅增长。为了解决这一挑战，我们提出了MemoryWAM，一种具有高效持久记忆的世界动作模型。MemoryWAM采用混合记忆设计，结合了最近帧、事件边界锚定帧和总结长程历史的紧凑要点标记。定制的注意力机制能够检索详细的短期上下文和压缩的长期上下文，支持依赖记忆的决策，同时减少推理延迟和GPU内存使用。在仿真和现实世界中的长时域、依赖记忆的操作任务中，MemoryWAM优于强大的视觉-语言-动作（VLA）和WAM基线，同时保持了良好的计算效率。

## Abstract
Robust robotic manipulation in the real world requires not only an understanding of the current observation, but also memory and dynamics modeling. World action models (WAMs) possess these capabilities by jointly modeling visual foresight and actions conditioned on both current and historical observations, making them a promising paradigm for robotic manipulation. However, existing WAMs face a fundamental trade-off: methods with efficient inference typically condition only on a bounded window of recent observations and therefore struggle in non-Markovian environments, whereas methods that preserve long histories incur time and space costs that grow substantially with sequence length. To address this challenge, we introduce MemoryWAM, a world action model with efficient persistent memory. MemoryWAM uses a hybrid memory design that combines recent frames, event-boundary anchor frames, and compact gist tokens that summarize long-range history. A tailored attention mechanism enables retrieval of both detailed short-term context and compressed long-term context, supporting memory-dependent decision-making with reduced inference latency and GPU memory usage. Across long-horizon, memory-dependent manipulation tasks in both simulation and the real world, MemoryWAM outperforms strong vision-language-action (VLA) and WAM baselines while maintaining favorable computational efficiency.

## 2. 论文提出的方法论

### 核心思想
- 采用**混合记忆架构**，结合三种互补的上下文：
  - **短期记忆**（滑动窗口）：保留最近帧的高保真局部上下文，用于即时控制。
  - **事件边界记忆**（锚帧）：保留任务开始时的完整视觉令牌（如初始场景），因为初始状态常蕴含关键信息且可能被遮挡。
  - **要点记忆**（Gist Tokens）：为每个历史帧维护少量可学习要点令牌（M=8），压缩长程历史，减少缓存大小（压缩比d=L/M=15，L=120视频令牌）。
- 基于预训练视频扩散模型（Wan2.2-TI2V-5B）和动作扩散模型，采用**MoT架构**，视频分支提取动态特征并维护记忆，动作分支去噪预测动作。
- **推理时视频预测被禁用**（仅在训练时提供动力学监督），避免昂贵的视频生成，提升效率。

### 关键技术细节
- **注意力掩码**：视频帧和动作令牌只关注：短期窗口帧（完整令牌）、锚帧（完整令牌）、所有历史帧对应的要点令牌（压缩）。非锚、非近期的帧被直接驱逐，仅保留其要点令牌。
- **复杂度**：全历史KV缓存大小O(NL) → 混合内存O(NM)=O(NL/d)，注意力成本与缓存大小线性相关，从而将时间/空间复杂度从O(N)降至O(N/d)。
- **训练**：使用流匹配（Flow Matching），1000步，视频和动作分支联合训练；使用混合噪声增强（clean latent与高斯噪声线性混合），防止过拟合。
- **推理**：维护每层的混合KV缓存，每次执行16步动作块后更新观察，重新编码生成新的潜在帧，动作条用50步（仿真）或10步（真实）去噪。

## 3. 实验设计
- **仿真数据集**：RMBench（长时域、记忆依赖的双臂操作基准），包含9个任务（Observe and Pick Up, Rearrange Blocks, Put Back Block, Swap Blocks, Swap T, Battery Try, Blocks Ranking Try, Cover Blocks, Press Button），涵盖不同记忆复杂度。
- **真实世界任务**：
  - Shell Game：识别方块被遮盖后交换杯子，找到正确杯子。
  - Look and Press：观察桌面数字，根据数字按压左右按钮对应次数，最后按后方按钮完成。
- **对比方法**：
  - VLA基线：π0.5（直接观测→动作，有界窗口）。
  - WAM基线：FastWAM（高效WAM，有界窗口）、LingBot-VA（全历史KV缓存WAM）。

- **评价指标**：任务成功率（100次滚动）、推理延迟、GPU内存。

## 6. 论文的主要结论与发现
- MemoryWAM在仿真RMBench上平均成功率**83.0%**，优于π0.5（10.4%）、FastWAM（5.9%）和LingBot-VA（78.2%），**提升约4.8个百分点**。
- 在真实世界任务中，MemoryWAM达到Shell Game 18/20、Look and Press 15/20，显著优于π0.5（5/20, 0/20）和LingBot-VA（13/20, 14/20）。
- **效率优势**：混合记忆相比全注意力，在长轨迹（1600帧）时推理延迟和GPU内存显著更低；同时优于RNN和TTT方法。
- **消融表明**：要点令牌（长程历史）最关键（Press Button上从87%降至5%）；锚帧和滑动窗口分别提供事件边界和短期高保真信息，移除均导致性能下降。
- **全注意力不一定最优**：保留所有历史令牌引入冗余，导致Cover Blocks上96% vs Ours 98%，Press Button相同87%（但Ours效率高）。

## 7. 优点
- **方法设计亮点**：
  - 受人类记忆认知启发，设计**三层混合记忆**（短期、事件边界、要点摘要），实现高效长程记忆。
  - **压缩比15倍**（L=120令牌→M=8要点令牌），大幅降低缓存和注意力成本。
  - 利用预训练视频扩散模型的动力学知识，训练时通过视频预测提供监督，推理时**无需视频生成**，保持高效。
  - **定制的注意力掩码**确保训练和推理对齐，避免teacher-forcing过拟合。
- **实验设计亮点**：
  - 在专为记忆任务设计的**RMBench**基准上进行系统评估，涵盖9种任务。
  - 与多种记忆机制（全注意力、TTT、RNN）对比，展示延迟/内存/性能的全方位权衡。
  - 消融实验细致分解每个组件的贡献，结论扎实。
  - 真实世界验证了方法的泛化性和实时性（10Hz控制）。
