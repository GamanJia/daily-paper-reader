## 摘要
设备端语言模型智能体通过积累检索内存中的经验而非更新权重来改进。该内存是硬边界且暴露的：它消耗RAM和能量，通过窄上行链路到达对等节点，并因可被智能体读取的内容写入而成为攻击面。现有系统各自覆盖了该问题的一部分：智能体内存无预算增长，设备端方法仅凭成功保留条目，投毒主要作为攻击而非内存治理问题被研究。我们提出\sys{}，一个按字节计算的单一净值分数，用于治理智能体的经验内存生命周期。核心思想是让预算作为策展者：每个条目按字节计为价值减去危害，因此同一尺度决定保留、共享和信任什么。\sys{}做出三个决策：(1) \textbf{保留}在RAM和能量预算下驱逐低价值字节；(2) \textbf{共享}仅当某个见解的价值超过其上行链路成本时发送；(3) \textbf{信任}根据来源对等节点条目进行门控。在语言模型智能体任务漂移基准测试以及一个包含两个机械臂节点和一个集线器的真实异构Jetson测试台上，\sys{}将内存减少2.7倍，上行链路减少2.4倍，将注入成功率从0.75降至0，并提高了受投毒或过时内存破坏案例的准确性。按净值策展同时减少了占用、能量、上行链路和注入成功率，且不降低准确性。在该设置中，按净值遗忘改进了智能体而非削弱它。

## Abstract
On-device language-model agents improve by accumulating experience in retrieved memory rather than by updating weights. This memory is hard-bounded and exposed: it consumes RAM and energy, reaches peers through a thin uplink, and becomes an attack surface because it is writable by what the agent reads. Existing systems each cover one part of this problem: agentic memories grow without a budget, on-device methods keep entries by success alone, and poisoning is studied mainly as an attack rather than as a memory-governance problem. We propose \sys{}, a single net-value-per-byte score that governs an agent's experience-memory lifecycle. The main idea is to let the budget act as the curator: each entry is scored as value minus harm, per byte, so one ruler decides what to keep, share, and trust. \sys{} makes three decisions: (1) \textbf{KEEP} evicts low-value bytes under the RAM and energy budget; (2) \textbf{SHARE} sends an insight only when its value exceeds its uplink cost; and (3) \textbf{TRUST} gates a peer entry by provenance. On language-model-agent task-drift benchmarks and a real heterogeneous Jetson testbed with two robot-arm nodes and a hub, \sys{} reduces memory by $2.7\times$ and uplink by $2.4\times$, drives injection success from 0.75 to zero, and raises accuracy on cases corrupted by poison or stale memory. Curating by net value reduces footprint, energy, uplink, and injection success together without reducing accuracy. In this setting, forgetting by net value improves the agent rather than weakening it.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：设备端（on-device）语言模型智能体（如手机、机器人上的LLM）通过在外部经验内存中积累检索到的经验来持续改进，而不是更新模型权重。这种内存是**硬边界**（受RAM和能量限制）、**暴露**（可被智能体读取的任何内容写入）且**脆弱**（通过窄上行链路分享给对等节点时增加攻击面）。
- **三大关键问题**：
  - **Q1（KEEP）**：在固定的RAM和能量预算下，哪些经验值得保留？现有方法仅按成功或新近性保留，会保留过特定或过时的条目，甚至带来负价值。
  - **Q2（TRUST）**：由于内存可被智能体读取的任何内容写入，如何防止注入攻击？纯价值驱动会保留看似有用的毒化条目。
  - **Q3（SHARE）**：在窄上行链路下，哪些提炼后的见解值得发送给对等节点？现有系统分别处理这三个决策，缺乏统一机制。
- **核心挑战**：能否用一个单一分数同时管理保留、共享和信任这三个决策，从而在降低资源消耗的同时提升智能体性能？
- **论文主张**：通过**按净价值遗忘**（forget by net value）可以改进智能体，而非削弱它。

## 2. 提出的方法论：核心思想、关键技术细节

- **核心思想**：让预算本身成为策展者——每个内存条目按**每字节净价值**（net value per byte）评分，该分数由**价值减去危害**（value − harm）构成，除以字节数。同一分数用于三个决策：
  - **KEEP**：按净价值降序贪心填充驻留集，直到RAM预算耗尽。
  - **SHARE**：只有当一个见解的净价值超过上行链路成本时才发送（同时考虑接收方的工作草图）。
  - **TRUST**：只有净价值超过信任阈值的对等条目才被接纳。

- **净价值密度分数**（核心公式）：
  \[
  \rho(m) = \frac{\hat{V}(m) - \lambda \hat{H}(m)}{b(m)}
  \]
  - \(\hat{V}(m)\)：预计未来价值，由三因素乘积组成：检索倾向性（基于滑动查询草图）、帮助度（无标签条件下的边际效用）、抽象增益（原始轨迹字节数/存储字节数）。
  - \(\hat{H}(m)\)：危害，包含两项：**负迁移风险**（基于特定性和马氏距离）和**来源风险**（基于条目来源、自我强化次数和指令相似性的逻辑回归门控）。
  - \(b(m)\)：条目字节占用。
  - \(\lambda\)：价值与危害的权衡参数（默认取1，实验显示安全且近优）。

- **算法流程**（Algorithm 1）：
  1. 计算每个条目的\(\rho\)。
  2. **KEEP**：按\(\rho\)降序排序，贪心添加入驻留集，超出预算时先尝试蒸馏（提高密度），蒸馏后仍超出则停止。
  3. **SHARE**：在驻留集中按\(\rho\)降序选择，仅当净价值大于上行链路预算且非冗余时加入共享集。
  4. **TRUST**：对于每个对等条目，仅当\(\rho > \theta\)时加入接纳集。

- **能量管理**：额外使用虚拟队列（drift-plus-penalty）确保时间平均能耗在预算内，不影响分数统一性。

## 6. 主要结论与发现

1. **统一分数可同时优化四个轴**：内存占用降低 2.7 倍（287→107 KB），上行链路降低 2.4 倍（1068→454 B/轮），注入 ASR 从 0.75 降至 0，任务准确率从 0.528 提升至 0.605，受害者子集准确率从 0.294 提升至 0.420（Qwen2.5-3B）。
2. **遗忘有害条目不会降低能力**：因为模型权重冻结，丢失过时或毒化条目反而修复了能力。
3. **纯价值驱动不足**：无来源项时 ASR 仍为 0.75；来源项是关闭攻击的唯一原因。
4. **预算 Pareto 前沿**：准确率在内存预算降到 107 KB、上行链路预算降到 454 B 之前保持不变，低于膝盖后开始下降。
5. **真实硬件验证**：在 Jetson 测试台上，能量、内存、上行链路分别降至 keep-all 的 0.38–0.64，跨代理毒性保持在 0.02–0.03。
6. **组件消融**：每个项负责不同轴：抽象增益提升准确率，来源项确保安全性，每字节归一化控制内存，危害项提升准确率和安全性。
7. **多 backbone 鲁棒性**：在三个 backbone（3B、7B、Phi-3.5）上效果一致。
8. **λ 参数安全范围宽**：λ=1 附近同时保证高准确率和零 ASR。

## 7. 优点

- **统一治理框架**：首次用一个分数同时管理保留、共享和信任，消除多个独立模块的手动调参。
- **真实硬件验证**：在异构 Jetson 测试台上测量实际能耗、内存和上行链路，结果可信。

## 8. 不足与局限

- **来源风险依赖于固定先验向量**：虽然文中称为“先验权重”，但若攻击者能够伪造自我强化轨迹或模仿来源特征（如“伪造来源”实验中所见），ASR 仍可升至 0.30，说明防范高级自适应攻击的能力有限。
