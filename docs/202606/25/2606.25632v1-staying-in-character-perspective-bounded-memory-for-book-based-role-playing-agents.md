## 摘要
近期基于大语言模型（LLM）的角色扮演系统通过从小说中提取角色、场景和关系来构建角色代理。然而，长叙事角色扮演存在两个缺陷：事实越界——共享检索或参数记忆使角色使用其视角之外的事实；风格单调——角色描述将角色扁平化为固定声音。为解决这些问题，我们提出REVERIEMEM，一种面向书籍角色代理的三层记忆架构。情景层存储第一人称场景记忆；语义层存储带可见性标记的事实；个性层存储依赖情境的语言和行为模式。为评估，我们构建了KBF-QA，一个涵盖八部小说的4386个问题的基准测试，用于检验知识边界。REVERIEMEM相比于最强先前方法，将知识边界保真度提升了34.6个百分点。在BOOKWORLD的五维成对叙事协议中，REVERIEMEM实现了约79%的胜率，表明视角边界记忆同时提升了边界保真度和基于角色的叙事生成。

## Abstract
Recent LLM role-playing systems build character agents from novels by extracting characters, scenes, and relations. Yet long-narrative role-playing suffers from two failures: Factual Overreach, where shared retrieval or parametric memory lets a character use facts outside its perspective, and Stylistic Monotony, where profile descriptions flatten a character into a fixed voice. To address these failures, we propose REVERIEMEM, a three-layer memory architecture for book-based character agents. The episodic layer stores first-person scene memories; the semantic layer stores visibility-tagged facts; and the personality layer stores situation-dependent speech and behaviour patterns. For evaluation, we construct KBF-QA, a 4,386-question benchmark over eight novels for testing knowledge boundaries. REVERIEMEM improves Knowledge Boundary Fidelity by 34.6 percentage points over the strongest prior method. On BOOKWORLD's five-dimension pairwise narrative protocol, REVERIEMEM achieves a ~ 79% win rate, suggesting that perspective-bounded memory improves both boundary fidelity and character-grounded narrative generation.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：基于互补学习系统（CLS）、自传体记忆系统和叙事身份理论，提出 **REVERIEMEM**——一种视角边界的三层记忆架构。在推理时，所有检索都受限于角色所能见到的事实子集，且表达模式由情境匹配的人格模式决定。

- **关键技术细节**：
  - **三层记忆架构**：
    1. **情景层（Episodic Layer）**：对每个焦点角色，存储每个场景的第一人称回顾摘要（角色做了什么、感受到什么、观察到什么）。作为后续检索的锚定框架。
    2. **语义层（Semantic Layer）**：存储结构化 SPOCV 五元组（主语-谓语-宾语-原因-可见集）。每个事实附带可见性集 V⊆C，表示哪些角色能知晓该事实。可见性通过四种途径分配：直接经验、观察、组织共享、常识。推理时检索仅限 Fc = {f ∈ F : c ∈ V(f)}。
    3. **个性层（Personality Layer）**：对每个角色聚类出 K 个行为模式（如“雷斯垂德对福尔摩斯的谨慎尊重”），每个模式包含描述和典型节选。同时记录角色情绪转换序列（情绪、强度、触发原因）。推理时通过情绪门控选择匹配的行为模式。

- **推理流程**（分三个阶段）：
  1. **Source-to-Memory（离线构建）**：将小说分割成场景；对每个场景生成第一人称摘要（情景层）；抽取实体和关系形成 SPOCV 知识图谱（语义层）；提取对话并标注情绪，聚类形成行为模式（个性层）。
  2. **CLS 记忆协作推理（CLS Memory Collaborative Reasoning）**：
     - **场景回忆（ANCHOR）**：根据查询 q 从情景层检索 c 的第一人称场景摘要 Sc。
     - **场景引导的细节重建**：使用 SELF-PROBE 生成子查询，循环从语义层可见子集 Fc 中检索事实，直到足够回答或达到最大轮数 N。每次检索仅限 Fc。
  3. **融合注入（Fusion Injection）**：并行运行个性轨道，通过情绪门控决定是否切换行为模式；最终使用记忆融合提示，将 Sc、检索到的事实 M(τ) 和选定的模式 m* 整合后生成回答。

- **算法流程**（文字说明）：
  1. ANCHOR：从情景层检索场景记忆 Sc。
  2. SELF-PROBE 生成初始子查询 P(1)。
  3. 循环 t=1..N：
     - VIS-RETRIEVE：从 Fc 检索事实，扩充事实池 M(t)。
     - SUFFICIENT：判断 (Sc, M(t)) 是否足以回答；若满足或 t=N 则退出。
     - 否则 SELF-PROBE 生成新的子查询。
  4. 退出时 τ = t。
  5. 并行个性轨道：用 EMOTIONAL-GATE 检测情绪事件，若触发则用 EMOTIONAL-TRANSITION 和 PATTERN 选择新模式 m*；否则保持先前模式。
  6. MEMORY-FUSION：用 (Sc, M(τ), m*) 生成回答。

- REVERIEMEM 在 KBF-QA 上达到 **KBF=73.3**，比最强基线 BOOKWORLD（38.7）提升 **34.6 个百分点**，召回与拒答同时提升。
