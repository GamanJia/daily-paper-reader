## 摘要
用于具身导航的视觉-语言模型（VLM）依赖于从不断增长的轨迹历史中选择固定数量的帧。随着回合的延长，这种选择逐渐变得稀疏，然而先前的研究表明，当帧数从8扩展到64时，准确性并未提升，这表明瓶颈不在于帧的数量，而在于表征本身。稀疏的帧选择无法捕捉长程推理所需的结构化行为信号：转向模式、累积位移和路径拓扑。我们提出了BIT-Nav（面向导航的类脑轨迹记忆），这是一种通过紧凑学习的轨迹记忆来增强冻结VLM导航管道的框架。受海马体路径整合（空间经验被压缩为结构化情景痕迹而非作为原始感官重放存储）的启发，BIT-Nav通过一个多正例InfoNCE对比目标，在共享相同行为意图的轨迹前缀上训练一个作用于动作和相对姿态序列的双向门控循环单元（Bi-GRU）编码器。得到的嵌入通过轻量级MLP投影到VLM令牌空间，并在每个决策步骤注入单个记忆令牌，从而以恒定的令牌成本（与回合长度无关）使模型基于结构化运动历史进行条件处理。

## Abstract
Vision-Language Models (VLMs) for embodied navigation rely on selecting a fixed number of frames from a growing trajectory history. As episodes extend, this selection grows increasingly sparse, yet prior work shows no accuracy gain when scaling from 8 to 64 frames, suggesting the bottleneck is not frame quantity but the representation itself. Sparse frame selection cannot capture the structured behavioral signal that long-horizon reasoning requires: turning patterns, cumulative displacement, and path topology.   We introduce BIT-Nav (Brain-Inspired Trajectory Memory for Navigation), a framework that augments frozen VLM navigation pipelines with a compact learned trajectory memory. Motivated by hippocampal path integration, where spatial experience is compressed into structured episodic traces rather than stored as raw sensory replay, BIT-Nav trains a Bi-GRU encoder over action and relative pose sequences via a multi-positive InfoNCE contrastive objective on trajectory prefixes sharing the same behavioral intent. The resulting embedding is projected into the VLM token space via a lightweight MLP and injected as a single memory token at each decision step, conditioning the model on structured motion history at constant token cost regardless of episode length

## 1. 核心问题与整体含义

**研究动机：**
- 现有视觉-语言模型（VLM）导航系统（如NaVILA）依赖从轨迹历史中均匀采样固定数量的过去图像帧（例如8帧或64帧），作为VLM的上下文输入。
- 随着导航回合（episode）变长，固定窗口的帧采样变得稀疏，丢失中间运动结构（转向模式、累积位移、路径拓扑），导致长程推理能力不足。
- 已有消融实验表明，将历史帧从8帧扩展到64帧并未提升导航精度，说明瓶颈不是帧数量，而是表征形式——视觉帧历史只能提供间接的运动信息，无法让VLM直接访问结构化的运动记忆。

**核心含义：**
作者将轨迹历史视为一种独立的“模态”，受海马体路径整合（hippocampal path integration）启发——大脑将空间经验压缩为结构化情景痕迹而非原始感官重放——提出BIT-Nav，用紧凑的、可学习的轨迹记忆增强VLM，使其在恒定token成本下获得结构化运动历史，从而支持长程推理。

## 2. 方法论：核心思想、关键技术细节

**核心思想：**
训练一个Bi-GRU轨迹编码器（BITE），将动作和相对位姿序列通过对比学习压缩为固定维度的嵌入，再通过轻量投影器将其注入VLM的token空间，作为单个记忆token在每个决策步骤提供结构化运动历史。

**关键技术细节：**

1. **运动特征工程（7维特征）**  
   将离散动作序列转换为7维向量：`[cx, cy, sinθ, cosθ, Δθ, is_forward, is_turn]`，包含累计位置、绝对朝向、朝向增量、动作类型指示，使编码器能区分局部相似但全局不同的轨迹模式。

2. **对比学习数据构建**  
   从R2R/RxR提取3600个起始-目标对（start-goal pairs），每对包含10条几何等价但路径不同的增强轨迹，共36000条轨迹。同一组的轨迹共享相同起点和终点，但步长、转向序列可能不同。

3. **Bi-GRU轨迹编码器（BITE）**  
   - 两层双向GRU，隐藏维度dh=256（每方向），输出512维每步隐藏状态。
   - 使用**掩码均值池化**（masked mean pooling）聚合整个序列为512维向量，而非仅用最后状态。
   - 通过投影头（512→256→128）并L2归一化得到128维嵌入。

4. **多正例InfoNCE对比目标**  
   - 每个小批量包含6个组（每个组10条轨迹），共60条轨迹。
   - 每个锚点有9个正例（同组其他轨迹）和50个负例（其他组轨迹）。
   - 损失函数对所有正例平均计算，迫使编码器压缩整个起始-目标等价类到一个紧凑邻域，捕获“行为意图”的全局结构。

5. **与VLM（Qwen3-VL-8B）对齐**  
   - 冻结Bi-GRU编码器和Qwen3-VL-8B，只训练一个两层MLP投影器（4.46M参数），将128维嵌入映射到4096维VLM token空间。
   - 在每个决策步骤，将轨迹记忆token `etraj` 预置到LLM输入序列：`[etraj, evisual, eframes, einstr]`。
   - 无论轨迹多长，只增加1个token，不随历史增长。

## 6. 主要结论与发现

1. **轨迹作为导航模态是可行的**：仅通过运动信号（无视觉）训练的Bi-GRU编码器能学习到可检索的、区分性的轨迹嵌入。
2. **恒定token成本**：BITE在每个决策步骤只消耗1个token（无论轨迹多长），而文本历史基线在124步时消耗903个token，BITE仅为41个（4.5%）。
3. **结构化推理能力**：BITE+Qwen在累积朝向估计（Q1）上保持0.83准确率，两个基线均崩溃至0.07；在动作频率推理（Q2）上匹配文本历史基线。
4. **涌现指令定位**：无需监督，模型能根据轨迹记忆推断已完成的子指令和剩余步骤（定性案例显示正确识别“已向左转、继续前进”等状态）。
5. **优于固定帧历史**：因为帧历史无法捕获结构化运动模式，而BITE显式编码了转向、位移、路径拓扑。

## 7. 优点

- **脑启发设计**：类比海马体路径整合，具有坚实的认知科学基础。
- **高效率**：仅增加1个token/步，不随轨迹线性增长，适合资源受限的嵌入式部署。
- **冻结VLM**：无需微调大模型，只训练极小投影器，兼容任意VLM的token空间。
- **自监督对比学习**：无需人工标注，利用数据增强构建正负样本，可扩展。
- **与现有VLM架构正交**：可即插即用，丰富上下文而不改动模型内部。
- **涌现能力**：没有显式监督，却能推断指令进度（instruction localization），展现可解释性。

## 8. 不足与局限

- **缺乏标准benchmark评估**：本文未在VLN基准（R2R val-unseen、RxR等）上报告成功率、SPL、导航误差等指标，仅用合成查询评估，结果虽好但难以直接对比主流方法。
- **验证场景有限**：定量评估在随机生成的离散轨迹上（基于R2R统计参数），而非真实连续导航或模拟器动态执行；定性评估仅3个例子，样本量小。
- **依赖离散动作空间**：假设前行步长0.25m、转向15°，无法直接泛化到连续控制机器人（如轮式或四足），需要额外适配。
- **投影器训练依赖对齐数据**：需要配对的轨迹嵌入与VLM响应，可能存在domain gap。
- **未分析对短轨迹的影响**：实验覆盖15-125步，但未区分短、中、长轨迹的具体表现，表中显示平均准确率较稳定，但非全部子区间都显著。
- **可扩展性问题**：虽然token数量恒定，但Bi-GRU仍需处理逐渐增长的序列（编码到当前步），长序列可能存在遗忘或计算开销，论文未讨论长段序列（>200步）的性能。
