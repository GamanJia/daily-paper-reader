## 摘要
检索增强生成（RAG）使代理能够访问积累的知识，但缺乏时间模型。当一个事实发生变化（例如，函数重命名或API重构）时，RAG会同时检索到过时和当前的值，且嵌入相似度几乎相同。代理要么放弃回答，要么提供已被取代的事实。我们表明这是一个结构性问题：在一个校准数据集上，余弦相似度区分矛盾事实与重复事实的AUROC仅为0.59（接近随机），因为矛盾事实与原始事实的嵌入相似度往往比改写后的重复事实更高。我们提出了MemStrata，一种保持时间有效性的检索记忆。它像RAG一样存储事实，保留静态召回能力，但当某个事实的值被矛盾时，一种确定性的（主语，关系，宾语）取代规则会在一个双时间账本中淘汰过时值——无需相似度阈值，无需调用LLM。在本地使用7B模型进行的六个基准测试中，MemStrata在静态知识上与RAG持平，在演化知识上的准确率达到0.95-1.00（而RAG仅为0.20-0.47）。核心结果是过时事实错误率：当需要回答时，RAG有15-40%的时间提供已被取代的值；MemStrata将其降至约0%，这是RAG无法避免的失败类别。MemStrata在检索延迟（约2.1秒）方面优于基于LLM重排序的基线（约16-18秒）。我们发布了测试框架、数据集以及一种用于知识演化下记忆的无标记评估协议。

## Abstract
Retrieval-augmented generation (RAG) gives agents access to accumulated knowledge, but has no model of time. When a fact changes (e.g., a function is renamed or API restructured), RAG retrieves both the stale and current value with near-identical embedding similarity. The agent then either abstains or serves the superseded fact. We show this is a structural problem: on a calibrated dataset, cosine similarity distinguishes a contradicted fact from a duplicated one with AUROC 0.59 (near chance), as contradictions are often more embedding-similar to the original than rephrased duplicates.   We present MemStrata, a retrieval memory maintaining temporal validity. It stores facts like RAG, preserving static recall, but when a fact's value is contradicted, a deterministic (subject, relation, object) supersession rule retires the stale value in a bi-temporal ledger - with no similarity threshold and no LLM call. Across six benchmarks run locally with a 7B model, MemStrata ties RAG on static knowledge and reaches 0.95-1.00 accuracy on evolving knowledge (where RAG reaches 0.20-0.47). The central result is the stale-fact-error rate: when required to answer, RAG serves superseded values 15-40% of the time; MemStrata drives this to ~0%, a failure class RAG cannot avoid. MemStrata achieves this at retrieval latency (~2.1s) versus ~16-18s for LLM-reranking baselines. We release the harness, datasets, and a marker-free evaluation protocol for memory under knowledge evolution.

### 1. 论文的核心问题与整体含义（研究动机和背景）

*   **核心问题**：检索增强生成（RAG）作为主流记忆机制，缺乏**时间模型**。当知识演化（如函数重命名、配置值变更、API重构）时，新旧事实在嵌入空间中几乎相同，RAG无法判断哪个是当前的，导致代理频繁给出**过时事实（stale-fact）** 错误。
*   **整体含义**：这是一个**结构性缺陷**，而非调参问题。作者通过实验证明，余弦相似度无法区分“矛盾（新版本）”与“重复（相同事实）”，矛盾事实的嵌入相似度甚至高于重复事实。因此，任何基于相似度的解决方案从根本上不可行。
*   **背景**：AI代理（如编程助手）需要跨会话积累知识并持续更新。RAG在处理**静态知识**（如项目文档）时表现良好，但在**演化知识**（如代码库迭代）场景下会出现严重的过时事实错误。

### 2. 论文提出的方法论：核心思想、关键技术细节

*   **核心思想**：使用**确定性取代规则（deterministic supersession rule）** 代替相似度判断。基于（主语，关系，对象）三元组，当新事实与已存储事实共享相同（主语，关系）但对象不同时，自动将旧事实标记为“被取代”，并记录在双时账本中。
*   **关键技术细节**：
    *   **写入路径**：
        1.  **精确重复短路**：通过文本哈希直接丢弃完全重复。
        2.  **确定性断言路径**：将输入句子解析为三元组，若存在相同（主语，关系）但对象不同的活跃断言，则**关闭旧事实的有效期**（设置`valid_to`），并打开新事实，并链接`superseded_by`。无冲突则作为新事实存储。
        3.  **文本门控回退**：对于无法提取三元组的自由文本，使用惊喜门（surprise gate）基于相似度+LLM判断处理，但仅丢弃精确重复，保留其他非矛盾事实。
    *   **双时账本**：事实不会被删除，而是被退役（retire），保留有效时间区间（valid_from, valid_to）和被取代链接，支持将来的“截至某个时间点”查询。
    *   **读取路径**：对查询嵌入后，检索活跃事实（排除被取代行），并按原始句子打包提供给模型。**无需LLM参与读路径**，延迟仅为嵌入层时间（约2.1秒）。
    *   **设计原则**：“先保留，后取代”（retain, then supersede），即在静态知识上像RAG一样保留所有非矛盾事实，仅在矛盾时进行取代，避免压缩导致静态召回下降。

### 6. 论文的主要结论与发现

*   **核心结论**：RAG在演化知识上存在结构性过时事实错误（15-40%），而MemStrata通过确定性取代规则将其降至**约0%**，同时保持静态知识上的等高召回和极低延迟（~2.1秒 vs LLM基线的~16-18秒）。
*   **关键发现**：
    *   **余弦相似度无法区分矛盾与重复**（AUROC 0.59，最大精度0.67），矛盾事实的相似度甚至高于重复事实。
    *   **LLM验证无法解决随时间题**（无时间信号），且代价8倍。
    *   **无标记基准是必要**，否则基线会读取文本标记，并非真正衡量时间追踪能力。
    *   **有损压缩（为追求边界增长率而合并非矛盾事实）** 会严重损害静态召回（domain从0.86降至0.62，locomo从0.30降至0.13）。
    *   **完整保留但无取代**会同时降低准确率并增加幻觉（因为模型面对并存的新旧版本无法区分）。

### 7. 优点：方法或实验设计上的亮点

*   **方法亮点**：
    *   **结构性解决方案**：不依赖相似度或LLM，而是利用三元组键的确定性逻辑，从根本上避免RAG无法避免的错误。
    *   **双时账本设计**：事实被退役而非删除，支持未来时间点查询（虽然未评估）。
    *   **无标记基准设计**：首次提出并强制实施无文本标记的演化基准，防止评估污染，为后续研究设立标准。
    *   **延迟极低**：读路径无LLM调用，与朴素RAG同量级（~2.1秒），而其他基线（LLM重排序/验证）高达8倍延迟。
*   **实验设计亮点**：
    *   **消融实验完整**：有损/完整保留/无取代三个方向相互印证，准确隔离了成功率来源（确定性取代）。
    *   **强制回答实验**：揭示了RAG在允许弃权时隐藏的过时错误，真实暴露其结构性缺陷。
    *   **余弦校准实验**：用98个标注样本直接证伪了基于相似度解决过时的可能性。

### 8. 不足与局限

*   **实验覆盖与偏差风险**：
    *   **结构化单值基准**：演化基准均为单模板，每个事实只有一个可变值（如一个函数名或配置值）。三元组提取器在此场景准确率~97%；但面对**复杂的自然语言矛盾**（多值句子、自由文本），提取率降至~44%，导致未能报告该结果（作者坦诚这对当前方法是一个边界）。
    *   **基准规模小**：每类仅20-50个场景，不足以代表真实世界的复杂性，作者承认这是为了隔离机制，需要后续扩展到大规模纵向数据。
    *   **仅使用7B模型**：实验结果可能随模型规模变化；但作者明确选择本地优先，且temperature=0确保确定性。
*   **应用限制**：
    *   **依赖提取质量**：在非结构化、多值或模糊的自然语言中，三元组提取是瓶颈，而非取代机制本身。

    *   **未评估真实时间戳与时间点查询**：双时账本已支持，但未在实验中展示。
