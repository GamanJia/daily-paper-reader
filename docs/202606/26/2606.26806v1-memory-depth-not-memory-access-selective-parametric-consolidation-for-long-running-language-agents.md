## 摘要
长时间运行的语言代理需要的不仅仅是记忆访问。检索系统可以在查询时获取过去的事实，但它们无法决定哪些经验应在工作上下文卸载后继续塑造行为。我们将这一独立问题视为记忆深度：写入小型参数存储中的持久目标条件倾向。我们引入了循环漂移协议，这是一个受控的压力测试，其中检索索引保持不变，而工作上下文被卸载，目标条件行为必须在长循环干扰下持续。我们评估了EVAF，一种基于惊喜和效价的LoRA巩固机制。在GPT-2和TinyLlama上，检索在浅层事实回忆（短事实准确率0.956-0.973）上最强，而EVAF在目标持久性和卸载后恢复（0.812-0.904）上最强，每200个事件仅需2-3次参数写入。机制控制表明，选择性巩固可分解为两个可控维度：选择和驱动。匹配的随机门控将选择与稀疏写入区分开来；跨GPT-2、TinyLlama和Mistral-7B的固定内循环控制表明，内循环写入强度依赖于模型；Mistral-7B的匹配门控反转揭示了在失准驱动下的非对称选择-驱动耦合。公开的Memora事件流作为外部诊断工具，暴露了过期记忆失效这一未解决的边界。在此探测中，选择性参数巩固提供了与检索访问相区别且互补的记忆深度。

## Abstract
Long-running language agents need more than memory access. Retrieval systems can fetch past facts at query time, but they do not decide which experiences should continue to shape behavior after the working context is unloaded. We study this separate problem as memory depth: durable goal-conditioned tendencies written into a small parametric store. We introduce the loop-drift protocol, a controlled stress test in which the retrieval index remains intact while working context is unloaded and goal-conditioned behavior must persist under long-loop interference. We evaluate EVAF, a surprise- and valence-gated LoRA consolidation mechanism. Across GPT-2 and TinyLlama, retrieval is strongest on shallow factual recall (short-fact accuracy 0.956--0.973), while EVAF is strongest on goal persistence and post-unload recovery (0.812--0.904) with only 2--3 parametric writes per 200 events. Mechanism controls show that selective consolidation factorizes into two controllable dimensions: selection and actuation. Matched random gates isolate selection beyond sparse writing; fixed-inner controls across GPT-2, TinyLlama, and Mistral-7B show that inner-loop write strength is model-dependent; and a Mistral-7B matched-gate inversion reveals asymmetric selection-actuation coupling under miscalibrated actuation. Public Memora event streams serve as an external diagnostic, exposing stale-memory invalidation as an unresolved boundary. Within this probe, selective parametric consolidation supplies memory depth distinct from and complementary to retrieval access.

### 2. 方法论：核心思想、关键技术细节
- **核心思想**：选择性参数巩固——只将行为相关的事件写入一个小的参数化存储（LoRA适配器），而非对所有事件进行持续更新。巩固过程需同时控制**事件选择**（哪些事件应被写入）和**驱动强度**（写入行为对模型参数的影响程度）。
- **关键技术细节**：
  - **EVAF选择门**：每个事件 \(x_t\)，计算惊喜得分 \(s_t\)（基于标记负对数似然）和效价得分 \(v_t\)（基于嵌入相似度与用户持久目标的相似性）。准入分数 \(g_t = \sigma(k_s (s_t - \tau_s)) \cdot \sigma(k_v (v_t - \tau_v))\)，若 \(g_t > \tau_w\) 则事件进入写入缓冲区。
  - **LoRA更新**：当缓冲区满时，对缓冲区数据进行重放式更新，并结合L2锚定（\(\lambda(\theta - \theta_0)\)）防止漂移。
  - **驱动控制**：通过调整内循环的梯度步骤数（固定-1、固定-2、固定-3）来独立控制驱动强度，与选择门解耦。
  - **路由策略（Routed EVAF+RAG）**：将事实查询路由到RAG，目标/偏好查询路由到EVAF，测试互补性。
- **算法流程**（文字说明）：
  1. 对每个事件，计算惊喜和效价，通过门控判断是否写入缓冲区。
  2. 缓冲区满时，利用缓冲区数据+以前巩固事件的回放更新LoRA适配器，同时施加L2锚定。
  3. 循环处理整个事件流，记录每次写入触发。

### 6. 主要结论与发现
- **深度翻转**：检索在短事实回忆上最强（准确率0.956~0.973）；EVAF在目标持久性和卸载后恢复上最强（0.812~0.904），每200事件仅2~3次写入。Naive-LoRA写入多但效果不如EVAF。
- **选择和驱动是可分离的控制维度**：固定内循环驱动强度的控制证明了这点；Mistral-7B上错误校准的驱动会导致EVAF退化，而随机门反而更好，揭示了选择-驱动的不对称耦合。
- **互补性**：路由EVAF+RAG可在保持短事实准确率的同时提升目标层性能，支持记忆访问与深度互补的观点。
- **边界发现**：Memora诊断中EVAF对过期记忆无效（p=0.57），该问题需采用有效性门控或再巩固而非反训练。

### 7. 优点
- **问题定义清晰**：首次明确区分“记忆访问”与“记忆深度”，并设计了针对性的循环漂移协议。
- **机制分解精细**：通过匹配随机门和固定内循环控制，将巩固机制分解为选择、驱动两个独立维度，并揭示了它们之间的非对称反馈。
- **跨模型验证**：在GPT-2、TinyLlama、Mistral-7B三个不同规模模型上验证，分析了模型依赖性。
- **边界诊断诚实**：主动使用Memora暴露方法在不擅长任务（过期记忆）上的不足，不回避局限。

### 8. 不足与局限
