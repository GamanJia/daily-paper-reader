## 摘要
随着大型语言模型智能体在长期交互和不断演变的任务场景中运行，长期记忆变得越来越重要。最近的记忆系统使过去的经验更加持久、紧凑和可检索，但仅靠检索并不能确保记忆为当前查询提供有效证据。当经验被压缩成可重用的片段时，来自不同情境的记忆如果涉及重复出现的实体或用户状态，可能显得同样相关。我们将这种失败称为上下文崩塌：记忆失去了判断其是否为当前查询提供有效证据所需的周围上下文。为解决这个问题，我们提出了面向智能体记忆的上下文重建（RaMem），一个将检索到的记忆片段转化为上下文可验证证据的框架。RaMem通过四个协调阶段运作：(i) 证据锚定将每条记忆定位在其原始事件条件中，特别是事件时间、提及时间、会话跨度及参与者；(ii) 回忆条件推导从查询中推导出所需的证据条件；(iii) 有效性感知检索利用这些条件优先选择上下文兼容的记忆，同时保留内容相关的候选项作为备用证据；(iv) 上下文保留合成将选定记忆的结构化上下文保留给生成器。在长期记忆基准上的实验表明，RaMem在多个强记忆基线上持续提升性能，在多个骨干网络上平均F1值提升超过10%。

## Abstract
Long-term memory has become increasingly important for LLM agents that operate across extended interactions and evolving task contexts. Recent memory systems have made past experiences more persistent, compact, and retrievable, but retrieval alone does not ensure that a memory provides valid evidence for the current query. When experiences are compressed into reusable fragments, memories from different situations may appear equally relevant if they involve recurring entities or user states. We refer to this failure as context collapse: memories lose the surrounding context needed to judge whether they provide valid evidence for the current query. To address this problem, we propose Contextual Reinstatement for Agentic Memory (RaMem), a framework that turns retrieved memory fragments into contextually verifiable evidence. RaMem operates through four coordinated stages: (i) evidence anchoring grounds each memory in its original episodic conditions, especially event time, mention time, session span, and participants; (ii) recall condition induction derives the evidence conditions implied by the query; (iii) validity-aware retrieval uses these conditions to prioritize context-compatible memories while retaining content-relevant candidates as fallback evidence; and (iv) context-preserved synthesis keeps the selected memories' structured context available to the generator. Experiments on long-term memory benchmarks show that RaMem consistently improves performance over strong memory baselines, with average F1 gains of more than 10% across several backbones.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：论文识别并定义了LLM智能体长期记忆中的一个关键失败模式——**上下文坍塌 (Context Collapse)**。当过去的经验被压缩成可复用的记忆片段后，来自不同情境的记忆，如果包含相似的实体（如人物、地点）或主题，可能会在语义上看起来同样相关。然而，只有其中一部分记忆是当前查询的有效证据。这种“看似相关但证据无效”的现象，本质上是**上下文信息的丢失**，导致智能体无法区分记忆来源于哪个特定场景。

- **整体含义**：当前许多长期记忆系统主要关注信息的“可用性”，即如何存储、压缩和高效检索。但论文指出，**可用性不等于可靠性**。一个有效的长期记忆系统，不仅需要让信息变得可访问，还必须确保检索到的信息在**当前的查询上下文**中是有效的。这要求记忆必须保留足够多的“情境信息”（如发生时间、参与人、所属会话等），以便智能体进行证据验证。

### 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

- **核心思想**：提出 **上下文重建 (Contextual Reinstatement)** 框架 **RaMem**。其核心在于将记忆片段转化为**上下文可验证的证据**，而不是仅仅作为上下文无关的文本块。它通过恢复记忆被编码时的情景条件，来确保检索结果的证据有效性。

- **关键技术细节与流程（四阶段）**：
    1.  **情景记忆锚定 (Episodic Memory Anchoring)**:
        *   在存储记忆时，为每条记忆 `m_i` 附加一个**情景上下文场 (episodic context field)** `e_i`。
        *   `e_i` 包含：事件发生时间(τ_event)、提及时间(τ_mention)、所属会话跨度(τ_session)、参与者(p_i)、地点(ℓ_i)、实体(u_i)和主题(z_i)。
        *   这一步确保了记忆不是孤立的文本，而是与具体情景绑定的“证据单元”。
    2.  **回忆条件归纳 (Recall Condition Induction)**:
        *   在处理查询 `q` 时，将其分解为两个部分：**信息需求 (information need)** `r_q` 和**上下文回忆框架 (contextual recall frame)** `c_q`。
        *   `c_q` 描述了有效证据应满足的条件，例如查询推断出的时间范围(τ̂_q)、对话方(p̂_q)等。例如，对于查询“Sarah在3月底的会议后做了什么决定？”，信息需求是“Sarah的决定”，回忆框架是“涉及Sarah、发生在3月底的会议之后”。
        *   这一步将查询本身也情景化，明确了“什么样的记忆才是有效的”。
    3.  **有效性感知检索 (Validity-Aware Memory Retrieval)**:
        *   这是选择性应用上下文的关键步骤。系统不会盲目应用回忆框架，而是当框架中的条件可以被**可靠地推断**时才激活。否则，退回到纯内容检索。
        *   **选择性激活**：当回忆框架可靠时，RaMem会构建一个**上下文兼容候选列表 (context-compatible candidate list)** `C_ctx(q)`。例如，通过检查记忆的会话跨度(τ_session)是否与查询的时间范围(τ̂_q)有重叠。
        *   **有序融合**：最终候选列表 `C_q` 以 `C_ctx(q)` 优先，内容检索结果 `C_content(q)` 作为备用证据，通过“去重优先”策略合并。这直接解决了上下文坍塌问题：优先选择“既相关又符合上下文”的记忆，而非仅基于语义相似度。
    4.  **上下文保留合成 (Context-Preserved Evidence Synthesis)**:
        *   在将选择的记忆传给生成器时，**不会将其还原为纯文本**。每条记忆都以其完整的形式呈现，包括其情景上下文场（会话、时间、参与者等）。
        *   这使得生成器不仅能看到“发生的事实”，还能看到“发生在什么情景下”，从而做出更明智、更可靠的回答。

- **算法流程总结**：存储时（阶段一：锚定上下文） -> 查询时（阶段二：解析查询上下文） -> 检索时（阶段三：选择性匹配并排序上下文） -> 生成时（阶段四：传递完整上下文给LLM）。
