## 摘要
记忆系统对于个性化大型语言模型（LLM）至关重要。然而，这些系统中的现有检索方法主要依赖语义相似性，可能遗漏语义重叠有限但在逻辑上至关重要的记忆。当前的基准测试在评估这一问题上仍显不足。为弥补这一空白，我们构建了IMLogic，这是首个针对长对话场景中隐式逻辑记忆检索的高质量基准。受这一挑战启发，我们引入了根记忆（root memory），这是一种结构化的、保留决策的表示形式，能从长期用户历史中提炼出可重用的个性化逻辑。接着，我们提出了RootMem，一个即插即用框架，首先将原始历史蒸馏为结构化的根记忆，然后使用基于LLM的路由器激活逻辑相关的记忆，从而用个性化决策逻辑补充语义检索。大量实验表明，RootMem显著优于最强的检索基线，并持续提升现有记忆代理的准确性。我们的基准测试和代码将在https://anonymous.4open.science/r/IMLogic-DBB3上开源。

## Abstract
Memory systems are essential for personalized Large Language Models (LLMs). However, existing retrieval methods in these systems primarily rely on semantic similarity, potentially missing logically critical memories with limited semantic overlap. Current benchmarks remain inadequate for evaluating this problem. To address this gap, we construct IMLogic, the first high-quality benchmark targeting implicit logical memory retrieval in long-dialogue scenarios. Motivated by this challenge, we introduce root memory, a structured, decision-preserving representation that distills reusable personalized logic from long-term user histories. We then propose RootMem, a plug-and-play framework that first distills raw histories into structured root memories and then uses an LLM-based router to activate logically relevant ones, complementing semantic retrieval with personalized decision logic. Extensive experiments demonstrate that RootMem significantly outperforms the strongest retrieval baselines and consistently boosts the accuracy of existing memory agents. Our benchmark and codes will be available at https://anonymous.4open.science/r/IMLogic-DBB3.

### 2. 论文提出的方法论：核心思想、关键技术细节

*   **核心思想：**
    *   **提出“根记忆”（Root Memory）概念**：一种结构化的、保留决策逻辑的记忆表示，从用户长期历史中蒸馏出可重用的个性化逻辑，而不仅仅存储事实信息。
    *   **提出RootMem框架**：一个即插即用的框架，用于构建和利用根记忆，以增强传统的语义检索。
*   **关键技术细节：**
    1.  **根记忆单元构建**：将原始历史记忆蒸馏成结构化的根记忆单元 `Ui = ⟨Ri, Ei⟩`。
        *   `Ri` (执行规则)：定义了单元的激活条件和响应引导逻辑，例如“当查询涉及工作室环境时，必须考虑宠物的安全和存在”。
        *   `Ei` (个性化逻辑证据)：提供支持该规则的用户特定事实和约束，例如“用户经常在工作室工作”、“用户的猫经常在工作室陪伴他”。
        *   **构建过程**：一个离线阶段。系统周期性处理新记忆批次 `Mt`，并使用LLM提取器 `ΦC` 动态创建、更新或合并根记忆单元，过程中会更新其证据 `Ei` 或优化规则 `Ri`。
    2.  **根记忆路由**：
        *   在线推理阶段，一个LLM路由器 `ΦR` 评估当前用户查询 `q` 与每个根记忆单元的执行规则 `Ri`，通过布尔决策来决定是否激活该单元（`ΦR(q, Ri)` ∈ {0, 1}）。
        *   激活的根记忆单元提供其 `[Ri, Ei]` 块，与标准语义检索得到的记忆条目 `Msem` 拼接，形成逻辑增强的上下文 `C`，作为LLM作答的输入。
*   **算法流程（文字说明）**：
    *   **离线阶段（记忆构建）**：
        1.  获取新的用户历史记忆批 `Mt`。
        2.  调用LLM `ΦC`，结合现有根记忆库 `U(t-1)` 和新记忆批 `Mt`，更新/生成根记忆单元，形成新库 `U(t)`。
    *   **在线阶段（响应生成）**：
        1.  接收用户查询 `q`。
        2.  执行标准语义检索，得到语义记忆集 `Msem`。
        3.  调用LLM路由器 `ΦR`，对每个根记忆单元判断是否与 `q` 逻辑相关，得到激活单元集 `Uact`。
        4.  拼接 `{Uact的 [Ri, Ei] 块}` 和 `Msem`，形成最终上下文 `C`。
        5.  将上下文 `C` 与查询 `q` 一同送入LLM生成响应。

1.  **IMLogic基准揭示了现有记忆系统的普遍短板**：无论是词法、语义还是复杂的图检索/混合系统，在处理“语义-逻辑冲突”的隐式逻辑检索任务时都表现不佳（最佳基线EverMemOS准确率仅43.50%）。
2.  **RootMem框架显著提升了隐式逻辑记忆检索性能**：
    *   **记忆级**：RootMem在多项选择测试中达到**55.23%**的准确率，相对最强基线（Query Reconstruction + Reranker）提升了**27.23%**。
    *   **对话级**：将RootMem集成到现有强系统中（如EverMemOS, LightMem, MemOS），平均带来了**26.36%**的相对准确率提升，所有系统的准确率都超过了50%。
    *   **错误分析**：性能提升主要来源于对“逻辑缺失”错误的修正，尤其是大幅减少了**泛化陷阱（Generic Trap）**错误（平均降低20.06%），表明RootMem成功帮助系统捕获了被忽略的逻辑约束。
3.  **根记忆的结构化设计是有效的**：消融实验表明，Router、Execution Rules和Personalized Evidence这三个组件都对最终性能有显著贡献，缺一不可。
4.  **RootMem具有良好的泛化能力**：在多种LLM骨干网络（GPT, Qwen, GLM）和开放生成任务中均取得了稳定且显著的性能提升。
