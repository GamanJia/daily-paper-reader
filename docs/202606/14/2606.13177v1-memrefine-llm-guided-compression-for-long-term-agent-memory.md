## 摘要
大型语言模型（LLM）智能体越来越需要能够在长期交互中运行，其中必须保留并回忆过去对话中的信息以支持未来任务。然而，随着交互的积累，记忆存储无限增长，并填满了冗余条目，这些条目增加了存储成本，并通过挤掉最有用的证据来降低检索质量。此外，这在具有严格内存预算的资源受限平台上尤其受限，促使我们提出带存储预算的记忆管理任务，即在不超出固定预算的前提下，保留对未来交互有用的信息，同时对已构建的记忆存储进行管理。为此，我们提出了MemRefine，一个基于LLM引导的框架。由于表面相似性不能很好地反映事实价值，该框架仅使用相似性来提出候选对，而将删除、合并和保留的决策推迟给基于事实内容的LLM评判者，迭代直到满足预算。在多个记忆框架和长期对话基准测试中，MemRefine在满足目标预算的同时保持了下游性能，并在严格预算下优于基于规则的基线方法。

## Abstract
Large language model (LLM) agents are increasingly expected to operate over long-term interactions, where information from past dialogues must be preserved and recalled to support future tasks. However, as interactions accumulate, the memory store grows without bound and fills with redundant entries that inflate storage cost and degrade retrieval by crowding out the most useful evidence. Furthermore, this is especially limiting on resource-constrained platforms with hard memory budgets, motivating us to formulate storage-budgeted memory management, the task of keeping an already constructed memory store within a fixed budget while preserving information useful for future interactions. To this end, we then propose MemRefine, an LLM-guided framework that, since surface similarity poorly reflects factual value, uses similarity only to propose candidate pairs and defers delete, merge, and preserve decisions to an LLM judge based on factual content, iterating until the budget is met. Across multiple memory frameworks and long-term conversation benchmarks, MemRefine consistently meets target budgets while preserving downstream performance and outperforming rule-based baselines under tight budgets.

- **新任务**：定义**带存储预算的记忆管理**（Storage-Budgeted Memory Management）——在固定存储预算下，对已构建的记忆存储进行压缩，保留对未来查询有用的信息。
- **现有方法不足**：会话级摘要、推理时上下文压缩、基于图结构剪枝等方法均不能直接针对“已构建的存储”在事实内容层面进行压缩。
- **整体含义**：提出一种**后构建记忆压缩**（Post-Construction Memory Compression）思路，将压缩作为独立模块插入记忆构建与检索之间，不修改宿主流程。

## 2. 方法论：MemRefine
### 核心思想
- 表面相似性（如 cosine similarity）可用于**提议**候选对，但不足以决定动作（因为高相似可能对应冗余、互补或不同事实）。
- 将决策权交给 **LLM 评判者**（Judge），基于**事实内容**（而非表面措辞）决定对候选内存条目执行 **删除**（DELETE）、**合并**（MERGE）或**保留**（PRESERVE）操作。
- 迭代进行，直到内存大小满足预算或无可压缩的对。

### 关键技术细节
- **候选对选择**：每次选择当前内存中最相似且未评判的对（基于 embedding 余弦相似度）。
- **LLM 评判**：Judge 接收两个条目的内容，输出结构化决策（action, target, merge_instruction）。
- **操作执行**：
  - DELETE：移除指定目标，若存在图链接则剪枝。
  - MERGE：调用另一个 LLM（Merge模型），按指令合成新条目，继承原链接并重新计算 embedding。
  - PRESERVE：记录该对已评判，避免重复。
- **终止条件**：内存大小 ≤ 预算 * 原始大小，或所有相似对都已被评判为 PRESERVE。
- **查询无关性**：压缩不依赖未来查询，直接优化最坏情况下的下游效用（形式化为 max-min 问题）。

### 算法流程（文字描述）
1. 输入原始内存 M0 和预算比例 ρ，初始化压缩后内存 M' = M0，空集合 S 记录已判为 PRESERVE 的对。
2. 当 M' 大小 > 预算 B 时：
   - 从 M' 中选出最相似且不在 S 中的对 (u, v)。
   - 若无候选则跳出。
   - 调用 Judge 获取决策。
   - 根据 action 执行相应修改（删除/合并/保留并加入 S）。
3. 返回压缩后的 M'。

## 6. 主要结论与发现
1. **MemRefine 可在中等压缩下（如 70%~50%）保持与原始存储相当的下游性能**，在更严格预算下性能平滑下降而非崩溃。
2. **LLM Judge 是核心**：规则基线在宽松预算下接近，但在严预算（30%）时大幅落后，表明仅靠相似性或图中心性不足以区分事实价值。
3. **压缩收益取决于宿主框架**：A-MEM 风格图记忆含有更多可去除冗余；Mem0 因已在构建阶段过滤合并，保留空间较小。
4. **问题类型影响**：单跳/时序类在压缩后有时性能提升（去噪效果）；开放/反事实类更敏感。
5. **模型能力正相关**：更强的 Judge 模型（GPT-5-mini）在严预算下优于较小模型（Qwen3-8B）。
6. **压缩性能随对话长度增长仍保持平滑**，表明可实用部署。
