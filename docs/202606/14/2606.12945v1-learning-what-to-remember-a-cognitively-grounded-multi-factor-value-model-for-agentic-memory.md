## 摘要
长时间运行的LLM代理积累的交互历史远大于任何上下文窗口，这迫使一个持续存在的决策：在固定的记忆预算下，什么应该深度编码，什么应该遗忘，以及什么应该检索。生产系统通过语义相似性或最近性来回答——这两种方式对于遗忘决策而言都是错误的规范，因为遗忘决策是在未来查询未知的整合时刻做出的。我们提出了一种多因素记忆价值函数V(m)=∑_i w_i f_i(m)，该函数基于认知心理学的七个可解释因素（情绪强度、目标相关性、价值一致性、自我/用户相关性、任务效用、可靠性和使用历史），其权重通过梯度自由优化器从下游目标中学习，并且其单一标量统一控制编码深度、遗忘风险和检索排名。我们提出了一个方法论观点：在LongMemEval上，针对保留的评估问题对目标相关性进行评分，将黄金证据保留率饱和至约0.98——这衡量的是检索，而非遗忘。在现实盲态下，学习到的多因素价值在479个可用案例中保留了0.770±0.011的黄金证据，而均匀权重为0.657，最佳单因素为0.518，最近性为0.368；每个配对差距的95%自举置信区间均高于零，且基于相同因素的神经网络与线性模型持平。学习到的权重是可解释的——可靠性、情绪强度和自我/用户相关性占主导地位，而查询时的目标相似性在遗忘决策中被正确降低权重。一个带有植入混淆因素的控制合成任务证实，学习器能够恢复分离性权重（保留率1.00），而均匀权重则失败（0.62）。该基础是开源的；所有实验均在单个CPU上运行，无需API调用。

## Abstract
Long-running LLM agents accumulate interaction histories far larger than any context window, forcing a standing decision: what to encode deeply, what to forget, and what to retrieve under a fixed memory budget. Production systems answer with semantic similarity or recency -- both mis-specified for the forgetting decision, which is made at consolidation time before the future query is known. We propose a multi-factor memory value function V(m)=\sum_i w_i f_i(m) over seven interpretable factors (emotional intensity, goal relevance, value alignment, self/user relevance, task utility, reliability, and usage history) drawn from cognitive psychology, whose weights are learned from a downstream objective by a gradient-free optimiser, and whose single scalar uniformly controls encoding depth, forget risk, and retrieval rank. We make a methodological point: on LongMemEval, scoring goal relevance against the held-out evaluation question saturates gold-evidence retention at \approx 0.98 -- this measures retrieval, not forgetting. In the realistic blind regime, a learned multi-factor value retains 0.770 \pm 0.011 of gold evidence across 479 usable cases, versus 0.657 for uniform weights, 0.518 for the best single factor, and 0.368 for recency; every paired gap's 95% bootstrap CI is above zero, and a neural network over the same factors ties the linear model. The learned weights are interpretable -- reliability, emotional intensity, and self/user relevance dominate, while query-time goal similarity is correctly down-weighted for the forgetting decision. A controlled synthetic task with planted confounds confirms the learner recovers a separating weighting (1.00 retention) where uniform weighting fails (0.62). The substrate is open-source; all experiments run on a single CPU with no API calls.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：长时间运行的 LLM 代理（agent）会积累远超上下文窗口的交互历史，必须持续做出“记忆三选一”的决策：哪些内容应该深度编码、哪些应该遗忘、哪些应该在检索时优先返回。现有生产系统依赖两个单因素策略——语义相似性（与当前查询）或**近期性（recency）**——但这两者在遗忘场景下均存在根本性错误设定：**遗忘决策是在整合（consolidation）时刻做出的，而此时未来的查询是未知的**。相似性策略在遗忘时无法使用未来查询，近期性策略虽然查询无关，却会因偏爱近期低价值内容而丢弃“旧但重要”的事实（如用户过敏信息、项目约束）。人类记忆并非单因素驱动，而是由多个认知因素（价值导向记忆、加工深度、情绪调制、自适应遗忘等）共同决定信息的存留。

- **整体含义**：本文借鉴认知心理学，提出一种**多因素记忆价值模型**，用一个标量统一控制编码深度、遗忘风险和检索排序，且权重通过下游目标从数据中学习，而非手工设定。同时揭露了一个方法论陷阱：在查询定义的黄金证据保留率上测试“遗忘”会混淆检索与遗忘，真正的遗忘评估必须在**盲态（blind）** 下进行（即聚合时看不到未来查询）。

## 2. 论文提出的方法论

### 2.1 核心思想

定义一个记忆价值函数 \( V(m) = \sum_i w_i f_i(m) \)，其中 \( f_i(m) \) 是七个人类记忆决定因素的可计算度量，权重 \( w_i \) 通过无梯度优化器从下游目标（本工作中为黄金证据保留率；一般可替换为任务 QA 正确率）学习。\( V(m) \) 作为单一标量同时控制三个操作：编码深度、遗忘风险和检索排名。

### 2.2 七个可解释因素

| 因素 | 定义（无 API 形式） | 实验中是否激活 |
|------|----------------|----------------|
| 情绪强度 (emotional intensity) | 从词汇/结构提取器获得的情绪显著性 | 激活 |
| 目标相关性 (goal relevance) | \( \frac{1}{2}(1 + \cos(e_m, e_{\text{goal}})) \) | 激活 |
| 自我/用户相关性 (self/user relevance) | \( \frac{1}{2}(1 + \cos(e_m, \mu_{\text{user}})) \) | 激活 |
| 可靠性 (reliability) | 启发式来源可靠性（用户陈述>模型陈述） | 激活 |
| 价值一致性 (value alignment) | 与价值档案（SOUL）的匹配度 | 未激活（设为0） |
| 任务效用 (task utility) | 任务成功的边际贡献（LLM 判断） | 未激活（设为0） |
| 使用历史 (usage history) | \( r/(1+r) \)，r=检索次数 | 未激活（设为0） |

其中 \( e_m \) 是记忆文本的句嵌入（使用 all-MiniLM-L6-v2, 384 维），\( \mu_{\text{user}} \) 是用户所有陈述的运行质心（查询无关的“该用户特性”锚点），\( e_{\text{goal}} \) 是代理活跃目标的嵌入。

### 2.3 一个标量，三个操作

- **编码深度**：将归一化价值 \( \bar{V}(m) \in [0,1] \) 映射到四个层级（浅层/语义/图式/元），阈值 {0.20, 0.45, 0.70}，更高价值分配更深编码。
- **遗忘**：遗忘分数 = \( (\Delta t)^{0.7} \cdot \frac{1}{1+r} \cdot \frac{1}{1+\beta V(m)} \)，其中 \( \Delta t \) 是天数，\( r \) 是检索次数。高价值 \( V(m) \) 乘性抵抗遗忘。
- **检索**：查询时，同一价值 \( V(m) \) 与查询特定相似性一起贡献检索排序（实验为了隔离存储/丢弃决策，直接按 \( V(m) \) 排序）。

### 2.4 学习权重（无梯度优化）

由于编码-遗忘-检索-回答流水线不可微（离散决策+外部回答器），使用随机爬山算法（Algorithm 1，类似轻量 CMA-ES）最大化下游目标 \( R(w) \)（本文为黄金证据保留率）。初始化权重全 1，每轮随机扰动每个维度，如果新权重提高目标则接受，并退火步长。

- **合成控制场景**：每个案例含 4 个金证据（旧但具真正信号：高目标相关性、任务效用、可靠性）和 16 个干扰项（新且植入混淆：高价值一致性、高自我相关性、高情绪噪声）。训练 60 案例，测试 60 案例。

## 7. 优点

1. **认知科学 grounding**：七个因素均有坚实的认知心理学基础（价值导向记忆、加工深度、情绪巩固、自适应记忆等），使模型具备理论合理性。
2. **单一标量统一三个操作**：避免分别调参，编码深度、遗忘抵抗、检索排名共享同一个价值，简化系统设计。
3. **学习权重而非手工设定**：权重通过梯度自由优化从下游目标自动学习，无需领域专家手动调整，且可适应不同工作负载特性。
4. **可解释性**：线性模型权重直接指示哪些因素对任务重要，可作为部署的审计工具。
5. **揭示方法论陷阱**：明确指出 Oracle vs. Blind 的区别，并验证了 Oracle 下多因素无优势，而盲态下优势显著；对后续记忆评估工作有重要指导意义（必须使用聚合时可用的信息）。
6. **极轻量计算**：单 CPU、无 API 调用，所有实验完全本地运行，开源可复现，非常适合研究社区使用。

## 8. 不足与局限

1. **保留率是下游准确率的代理**：当前目标为黄金证据保留率，而非最终 QA 正确率。高保留率是必要条件但不充分——通常还需检索和回答。作者明确声明留待未来加入 API 回答器。
2. **三个因素未激活**：价值一致性、任务效用、使用历史在无 API 环境中设为 0。这使得盲态实验仅用 4 个因素，可能低估完整七因素的表现（也可能因噪声而高估，但更可能是保守估计）。特别是任务效用是最直接的预期效用信号，其缺失限制了潜力。
3. **单一数据集和模态**：仅测试了 LongMemEval-S（英文多会话聊天）。其他智能体工作负载（工具使用、编程、网页导航）具有不同的金标准结构，可能偏好不同因素。未验证泛化性。
4. **盲态目标锚的选择**：使用会话用户陈述质心作为聚合时目标锚，可能不是最优选择（如明确任务描述、运行目标栈可能提供更多信号）。作者承认该选择非最优，但强调“regime distinction”本身重要。
5. **线性模型和简单优化器**：虽然实验表明在当前设置下线性可加且非线性消融持平，但若因素间存在强交互（例如情绪只对自我相关项重要），线性模型可能不足。优化器为随机爬山，未与 CMA-ES、贝叶斯优化等更强大方法对比。
6. **未评估检索最终质量**：实验仅执行了按价值排序并保留 top 30%，未实现完整的前端检索（包括查询相似性混合），也未运行实际回答。这使得结果局限于“什么幸存遗忘”，而非完整的记忆系统端到端性能。
7. **无跨代理/多任务**：合成实验单一，真实场景仅一个，未展示在不同类型代理（如编程助手、个人助理）上的表现。
