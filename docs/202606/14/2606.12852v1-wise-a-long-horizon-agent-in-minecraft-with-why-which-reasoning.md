## 摘要
通过采用基于大语言模型增强的分层方法，在Minecraft等环境中开发通用具身智能体取得了快速进展。尽管前景广阔，但由于重复的执行失败，低级控制器常常成为性能瓶颈。我们认为一个关键限制不仅是缺乏情景记忆，还在于将“什么-哪里-何时”记忆与“哪个-为什么”推理相分离。为解决这一问题，我们提出了WISE（Which-Why Informed Semantic Explorer），一个长周期智能体框架，其增强的低级控制器配备了一个因果事件图，该图通过显式的因果结构将观察与任务相关性联系起来，从而扩充情景记忆。与依赖特征相似性进行检索的先前工作（如MrSteve）不同，WISE能够在视角变化下实现稳健的回忆，并通过因果推理支持机会性的任务重排序。基于这一记忆，我们提出一个机会性任务调度器，当检测到因果相关的机会时，动态重新优先排序子任务。我们还为WISE配备了多尺度渐进探索策略，为下游推理提供空间上全面的观察。实验表明，WISE在长周期稀疏任务上大大提高了任务成功率和效率，尤其是在需要自适应决策的场景中。

## Abstract
Rapid advances have been made in developing general-purpose embodied agent in environments like Minecraft through the adoption of LLM-augmented hierarchical approaches. Despite their promise, low-level controllers often become performance bottlenecks due to repeated execution failures. We argue that a key limitation is not only the lack of episodic memory, but also the decoupling of \textit{what-where-when} memory from \textit{which-why} reasoning. To address this, we propose \textbf{WISE} (Which-Why Informed Semantic Explorer), a long-horizon agent framework with an enhanced low-level controller equipped with a Causal Event Graph that augments episodic memory with explicit causal structure linking observations to task relevance. Unlike prior work such as MrSteve, which relies on feature similarity for retrieval, WISE enables robust recall under viewpoint changes and supports opportunistic task reordering through causal reasoning. Building on this memory, we propose an Opportunistic Task Scheduler that dynamically re-prioritizes subtasks when causally relevant opportunities are detected. We further equip WISE with a multi-scale progressive exploration strategy to provide spatially comprehensive observations for downstream reasoning. Experiments show that WISE largely improves task success and efficiency on long-horizon sparse tasks, particularly in settings requiring adaptive decision-making.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
WISE是一个**闭环架构**，将探索、记忆与规划统一：探索获取观察 → 记忆将观察转化为因果知识 → 规划利用知识做出自适应决策。

### 关键技术细节

1. **Causal Event Graph（因果事件图）**
   - **短期几何记忆**：类似MrSteve的PEM，使用MineCLIP编码视频帧，通过DP-Means聚类形成事件簇，按余弦相似度检索。回答“where”和“when”。
   - **VLM驱动的因果图构建**：在短期记忆之上，利用GPT-4o分析关键帧（通过混合聚类+熵基策略提取），提取实体（如牛、树木），并添加因果边（如cow → CAN_OBTAIN → beef）及共现关系（CO_OCCURS_WITH）。将原始观察转化为结构化语义知识。
   - **两级检索**：短期层按视觉相似性检索；语义层查询因果图，通过因果边找到与任务相关的实体及其位置。最终得分为视觉相似度与因果匹配的加权和（公式1：Score = λ·sim + (1-λ)·CausalMatch）。这提供了视角变化下的鲁棒回忆。

2. **Opportunistic Task Scheduler（机会主义任务调度器）**
   - 动态重排序待办子任务，基于当前观察和因果图记忆。
   - 优先级公式（公式2）：Priority = w_u·Urgency + w_r·CausalRel + w_n·[1 - NavCost]，其中**CausalRel是核心**，当观察到与某子任务因果相关的实体时，该子任务优先级大幅上升。
   - 示例：任务序列“找水→砍树→获得牛肉”，途中遇到牛，立即重排序为“获得牛肉→找水→砍树”，避免后续回头路。

3. **Multi-Scale Progressive Exploration（多尺度渐进探索）**
   - **全局层级**：基于四叉树（quadtree）划分区域，按探索效用得分（深度奖励与距离惩罚）选择宏观区域。
   - **区域层级**：在选定区域内提取前沿点（frontier），按覆盖率、信息新奇度和导航成本评分。
   - **局部完成层级**：基于维诺图（Voronoi decomposition）识别残留未探索区域，填补空隙。
   - 三者形成粗到细的探索框架，保证覆盖效率和完整性。

## 6. 主要结论与发现

- **探索效率**：WISE在384×384模拟地图上20,000步内覆盖率达98%，而MrSteve仅83%；在真实小图上10,000步内覆盖率97%对67%（MrSteve）。多尺度策略显著优于计数基方法。
- **ABA稀疏任务**：WISE成功率达62%，平均完成5,981步，相比MrSteve（32%, 8,123步）提升30个点、缩短26%时间。返回定位步数从4,253步降至2,341步，归因于因果记忆的视角不变性。
- **ABC自适应任务**：WISE成功率达77%，平均4,620步，相比MrSteve（33%, 8,040步）提升44个点、缩短42.5%时间。调度器使得机会性任务重排序成为可能。
- **消融实验**：去掉因果图导致性能下降最多（-46点），接近MrSteve，表明语义记忆是基石；去掉多尺度探索次之（-32点）；去掉调度器再次（-15点）。三者协同效果远超单独改进之和。

## 7. 优点

1. **创新性地将因果推理融入低级控制**：通过VLM构建因果事件图，使记忆不只是存储“看到什么”，而是理解“为什么重要”，实现视角不变下的鲁棒检索。
2. **机会主义调度器设计巧妙**：将低级控制器从固定序列执行变为动态自适应决策，显著提升长周期效率。
3. **多尺度渐进探索策略**：结合全局效率、前沿边界意识和局部完整性，在稀疏环境中高效覆盖，为后续推理提供丰富观察。
4. **闭环架构统一探索-记忆-规划**：三个模块相互增强，而非孤立运行。
5. **实验设计严谨**：对比公平（排除API特权方法），消融实验充分，在模拟和真实环境中均验证了鲁棒性。
6. **低成本异步VLM调用**：推理异步进行，不阻塞在线控制，API成本估算合理。

## 8. 不足与局限

1. **依赖外部大模型**：因果图构建依赖GPT-4o，API调用带来成本（约$0.48/回合）和隐私/延迟问题，论文提出未来需探索轻量替代方案。
2. **仅针对Minecraft环境**：方法虽具有一定通用性，但实验仅在Minecraft上进行，未在其他具身环境（如Habitat、Gibson）验证，泛化性存疑。
3. **实验覆盖范围有限**：ABC-Sparse任务中资源C的出现位置固定（步骤500且距离30块内），未测试更随机的出现时机或更复杂的机会类型；任务种类单一（仅涉及资源收集）。
4. **计算资源较充足**：使用4块RTX 4080，但未报告训练或运行总时长，难以评估实际效率。
