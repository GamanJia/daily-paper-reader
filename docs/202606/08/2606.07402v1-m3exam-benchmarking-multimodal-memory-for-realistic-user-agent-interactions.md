## 摘要
语言智能体越来越多地部署在累积多模态信息的环境中，然而现有基准测试假设人机交互形式，视觉内容稀疏且内容直白，既不能评估对真实多模态文件交互的推理能力，也不能评估对隐藏用户信息的解读能力。因此，我们提出M$^3$Exam，这是一个以查询为中心的多模态对话记忆基准测试，基于真实的用户-智能体交互，具有跨模态基础推理和隐式信息推理的多维评估。对多模态大语言模型和记忆系统的基准测试揭示了跨模态基础推理、跨会话推理以及累积多模态上下文的效率成本方面的持续差距。我们进一步提出M$^3$Proctor，一种多模态记忆方法，可检测查询模态偏差，仅按需消费原始视觉资源，将准确率提升13%，同时将索引构建时间和检索令牌数量削减超过70%。

## Abstract
Language agents are increasingly deployed over accumulating multimodal information, yet existing benchmarks assume a human-human form with sparse visuals and straightforward content, evaluating neither reasoning over authentic multimodal file interaction nor the interpretation of concealed user information. We therefore introduce M$^3$Exam, a query-centric multimodal conversational memory benchmark built on realistic user-agent interaction, with multi-dimensional evaluation spanning cross-modal grounding and implicit information inference. Benchmarking MLLMs and memory systems reveals persistent gaps in cross-modal grounding, cross session reasoning, and the efficiency cost of accumulating multimodal context. We further propose M$^3$Proctor, a multimodal memory method that detects query modality bias and consumes raw visual sources only on demand, improving accuracy by 13% while cutting index-construction time and retrieved tokens by over 70%.

## 2. 方法论

### 2.1 M³Exam基准构建

- **核心思想**：构建一个以查询为中心的多模态对话记忆基准，覆盖真实场景中的多会话、多模态交互，并设计八种问题类型，重点评估记忆、推理和解读三个维度的能力。
- **关键技术细节**：
  - 每个实例由三元组（人物画像P、核心事件C、多模态文件池F）合成。
  - **时间线生成**：LLM根据P和C生成N个核心事件（含描述、查询、时间戳、关键词），并混入M个干扰旁枝事件，通过自检和人工抽查确保质量。
  - **多轮对话合成**：通过事件滑动窗口逐步生成对话，每个回合包含用户查询和助手回复，并附上累计的多模态文件。对话被分割成多个会话，每个会话末尾保留关键摘要以模拟跨会话记忆。
  - **问题库合成**：采样上下文窗口，由LLM生成8种问题类型：单会话检索、文件管理、事实判断（记忆）；多会话分析、多模态推理、时间推理（推理）；隐式推理、主题推理（解读）。每个问题配有序号答案列表（从精确到粗略）和支持事实的轮次。
- **数据规模**：239个多会话对话，15个人物场景，3,025轮交互，1,799个多模态工件，5,150个评估问题。

### 2.2 M³Proctor方法

- **核心思想**：检测查询的模态偏差，仅当必要时才消费原始视觉资源，从而提升准确率并降低计算成本。
- **关键技术细节**：
  - **索引构建**：将图像和文档转换为文本替代物（图像生成标题、图表生成数字转录、文档生成摘要），并附加模态标签（图像、文档、图表）。每个会话附加紧凑的会话摘要块。
  - **模态感知推断**：
    - **偏差检测**：用一次LLM调用判断查询是否需要特定模态（二进制向量），并缓存。
    - **偏差重排序**：在语义相似度基础上，对候选块根据查询模态偏差和块模态标签进行加权调整，提升来自相关模态的块排名。
    - **成本感知级联**：首先仅用文本替代物回答；若置信度检查认为不可靠或模态偏差未满足，则级联到原始视觉源。级联决策由融合了检索块中模态占比、检测到的偏差和表面词汇线索的分数触发。
- **效果**：在M³Exam上，准确率提升13%，检索令牌减少超70%，索引构建时间减少80%。

## 6. 主要结论与发现

- **M³Exam仍远未被解决**：最强前沿MLLM（GLM-5.1）Overall Score仅0.549；记忆系统在7B骨干上总体得分0.35-0.48。
- **瓶颈在于跨模态推理和隐式意图**：单会话回忆表现较好，但多模态推理和隐式推理大幅下滑；基础MLLM在这些能力上接近崩溃（如TH/F1=0.064，II/F1=0.052）。
- **M³Proctor达到记忆系统最佳**：Overall Score 0.484，超越之前最优MIRIX（0.456），且在多模态推理（LLM-J 0.606）、隐式推理（0.652）和文件管理（EM 0.569）上领先。即使使用7B骨干，也优于部分MLLM（如Claude-Opus-4.6、GPT-5.4）在同等设置下的表现。
- **级联机制高效**：级联仅在视觉类型问题上高频触发（FM 68%、MR 51%），对文本类型触发极少（≤15%），且激活级联后可提升FM 0.116、MR 0.092准确率。M³Proctor的令牌消耗（4,591/查询）处于纯文本系统水平，远低于多模态系统（如NGM 26,988、MemVerse 26,988）。
- **多模态信息至关重要**：全上下文设置下，模型表现下降（因检索和上下文压力），表明外部记忆系统不可或缺。

## 7. 优点

- **基准设计全面**：首次联合评估真实多模态交互中的记忆、推理和解读三个维度，覆盖8种问题类型，尤其包括隐式推理和主题推理。
- **数据质量高**：严格的质量控制（自检、人工抽查），确保问题答案仅基于提供的上下文，避免幻觉。
- **方法创新**：M³Proctor提出模态偏差检测和成本感知级联，按需消费原始视觉源，在提升准确率的同时大幅降低计算成本，概念清晰且实用。
- **实验客观公平**：对比方法覆盖广泛（前沿闭源模型、开源记忆系统、文本/模态系统），使用统一骨干（Qwen-2.5-VL-7B），并验证了骨干替换的鲁棒性。
- **评估指标丰富**：结合精确匹配、F1、BLEU-1和LLM-as-a-Judge，既有词汇级也有语义级评分，并验证了LLM Judge与人类评估的高度一致性。

## 8. 不足与局限

- **任务形式有限**：当前基准主要聚焦于单轮QA（基于累积历史），真实交互通常涉及长期多轮对话、演化意图和迭代记忆更新，暂未覆盖。
- **M³Proctor的解读能力有限**：在解读定向问题（如隐式推理）上仍表现不佳（总体0.651，但相比其他方法有提升），更精细的隐式用户状态建模和深度上下文解读仍是未来方向。
- **数据完全合成**：所有对话和人物均为LLM生成，可能缺乏真实用户交互的微妙性和噪声分布，存在与现实场景的偏差风险。
- **实验覆盖不足**：未在不同检索器（如ColBERT、SPLADE）或不同模态编码器下测试M³Proctor的泛化性；未与更细粒度的模态路由方法（如训练一个分类器来预测模态需求）对比。
- **算力成本未透明**：未报告完整实验的GPU小时数，不利于复现和成本评估。
- **单骨干依赖**：主要实验基于Qwen-2.5-VL-7B，虽验证了替代骨干（含更强的闭源模型），但7B本身是较小模型，可能低估更大模型上的表现上限。但论文也报告了MLLM oracle结果作为上限参考。
