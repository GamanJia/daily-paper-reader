## 摘要
长上下文任务要求LLM从大量上下文中识别并保留与答案相关的信息。分块记忆智能体通过顺序读取文档块、更新紧凑记忆并从累积记忆中生成最终答案来解决这一问题。然而，现有的基于强化学习的分块智能体要么依赖稀疏的最终答案奖励，要么对记忆和检索动作使用词法中间奖励。这些信号监督任务成功或局部重叠，但并未直接评估最终记忆是否支持真实答案。我们提出InfoMem，一种用于训练分块记忆智能体的奖励机制，该机制使用答案条件信息评估最终记忆效用。InfoMem衡量最终记忆增加了模型对真实答案的每token对数似然程度。为了稳定强化学习优化，InfoMem仅在成功轨迹上施加此信号，并在奖励组合前对其进行归一化。在相同的GRPO框架和训练预算下，InfoMem提升了长上下文记忆智能体相对于可比记忆智能体强化学习基线的性能。分析表明，有效的最终记忆奖励应作用于成功轨迹，在奖励组合前进行归一化，并且应基于答案而非查询进行条件设置。我们的代码可在https://github.com/GenSouKa1/InfoMem获取。

## Abstract
Long-context tasks require LLMs to identify and preserve answer-relevant information from large contexts. Chunk-wise memory agents address this issue by sequentially reading document chunks, updating a compact memory, and generating the final answer from the accumulated memory. However, existing RL-based chunk-wise agents either rely on sparse final-answer rewards or use lexical intermediate rewards for memory and retrieval actions. These signals supervise task success or local overlap, but do not directly evaluate whether the final memory supports the ground-truth answer. We propose InfoMem, a reward mechanism for training chunk-wise memory agents that evaluates final-memory utility using answer-conditioned information. InfoMem measures how much the final memory increases the model's per-token log-likelihood of the ground-truth answer. To stabilize RL optimization, InfoMem applies this signal only to successful trajectories and normalizes it before reward composition. Under the same GRPO framework and training budget, InfoMem improves long-context memory-agent performance over comparable memory-agent RL baselines. Analyses show that effective final-memory rewards should operate on successful trajectories, be normalized before reward composition, and be conditioned on the answer rather than the query. Our code is available at https://github.com/GenSouKa1/InfoMem.

# 论文总结：InfoMem: 基于答案条件信息增益的长上下文记忆智能体训练

## 1. 核心问题与整体含义（研究动机和背景）

长上下文理解是大型语言模型（LLM）的关键能力，应用包括长文档问答、语料级证据聚合等。现有方法中，**分块记忆智能体（chunk-wise memory agent）** 是一种有效范式：模型顺序读取文档块，更新紧凑记忆，并从累积记忆中生成最终答案。然而，现有基于强化学习（RL）的分块智能体在训练时存在关键缺陷：
- **稀疏最终答案奖励**：仅监督答案正确性，无法区分不同记忆在成功轨迹中的质量差异（例如同样正确但记忆冗余/偏离）。
- **词法中间奖励**（如ReMemR1）：基于词汇重叠，无法捕捉语义上对最终答案的支持。

**核心问题**：如何设计一种可扩展、直接的奖励信号，监督最终记忆对真实答案的支持程度？**InfoMem** 从信息论视角出发，提出基于**答案条件信息增益**的奖励机制，直接衡量最终记忆对正确答案对数似然的提升。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **信息论视角**：有用的最终记忆应减少关于真实答案的不确定性。理想情况下可用条件互信息 I(M; Y|X) 衡量，但难以估计。
- **点式代理**：使用单样本点式代理——**答案条件信息增益**，比较有/无最终记忆时模型对真实答案的 teacher-forcing 平均每token对数似然。

### 2.2 奖励定义
给定查询 x、最终记忆 M、真实答案 y*，信息增益奖励：
\[
r_{\text{gain}}(x, M, y^*) = \frac{1}{|y^*|} \log P_\theta(y^*|x, M) - \frac{1}{|y^*|} \log P_\theta(y^*|x, \emptyset)
\]
其中 \(\emptyset\) 表示空记忆。第一项衡量条件于最终记忆下的答案似然，第二项为无记忆基线。

### 2.3 关键技术细节
- **仅作用于成功轨迹**：只对最终答案正确的轨迹（\(R_{\text{outcome}}=1\)）施加信息增益奖励。失败轨迹仅使用稀疏结果奖励。这避免了失败轨迹中记忆质量与错误答案生成之间的混淆。
- **归一化**：在组合奖励前，对成功轨迹中的信息增益值进行**组内标准化**（减去均值除以标准差），以控制跨prompt的尺度不平衡。
- **最终奖励组合**：
  \[
  R_i = 
  \begin{cases}
  R_{\text{outcome},i} + \beta \tilde{r}_i, & i \in \mathcal{S} \\
  R_{\text{outcome},i}, & i \notin \mathcal{S}
  \end{cases}
  \]
  其中 \(\mathcal{S}\) 为成功轨迹集合，\(\tilde{r}_i\) 为归一化后的信息增益，\(\beta\) 控制强度。
- **训练算法**：使用 GRPO（Group Relative Policy Optimization），奖励仅改变每个 rollout 的标量奖励，轨迹级优势传播到所有生成token（包括记忆更新和最终答案）。

## 6. 主要结论与发现

1. **InfoMem 显著优于现有方法**：在4个长上下文基准上，InfoMem在相同训练预算下超过Outcome-only GRPO和ReMemR1，且避免了Outcome-only GRPO在某些任务上的退化。
2. **有效最终记忆奖励的三条设计原则**：
   - 应**仅作用于成功轨迹**（positive memory shaping），失败轨迹的信号不可靠。
   - **必须在奖励组合前归一化**，以平衡跨prompt的尺度差异。
   - 必须**基于真实答案而非查询**，否则模型会学会记忆查询而非支持性证据。
3. **答案条件信息增益是直接且稳定的记忆效用信号**：合成诊断实验显示，rgain相比嵌入相似性和注意力得分具有更高的MRR和信噪比。

## 7. 优点

- **方法创新性**：从信息论角度提出直接衡量最终记忆对答案支持度的奖励，解决了稀疏结果奖励和词法中间奖励的不足。
- **设计简洁且有效**：仅需在GRPO框架中替换奖励函数，不改变算法结构，易于集成。
- **消融实验深入**：系统验证了监督侧、归一化、条件对象三个关键因素，提供了清晰的指导原则。
- **诊断实验设计巧妙**：通过合成幻觉证据，直观展示了rgain的区分能力，并对比了多种常见文本表示（嵌入、注意力）的信噪比。
- **实验公平性**：严格控制训练预算、数据、模型，并对ReMemR1保留其原始框架以保持一致性，分析诚实透明。

## 8. 不足与局限

- **算力和规模有限**：训练仅512例、1.5B模型；未在更大模型（如7B/70B）或更大训练集上验证，可扩展性未知。
- **仅针对分块记忆智能体**：不适用于检索增强系统或全上下文单遍模型。记忆机制本身可能限制模型直接从长上下文中提取稀疏信息的能力（例如MRCR-8needle得分普遍低）。
- **奖励仅基于最终记忆和最终答案**：GRPO将轨迹级优势传播到所有token，但未对中间记忆状态提供直接监督；未来可扩展为过程级监督。
- **潜在风险**：
  - 若真实答案错误或源文档有偏见，模型可能学会强化误导性证据。
  - 可能过度优化记忆以高度关联预期答案，忽略原始上下文中的重要限定条件。
  - 在高风险领域（法律、医疗、金融）中，压缩记忆不应替代源文档验证。
- **评估依赖LLM评判**：尽管人类校准了部分样本，但大规模使用可能引入评判偏差。
