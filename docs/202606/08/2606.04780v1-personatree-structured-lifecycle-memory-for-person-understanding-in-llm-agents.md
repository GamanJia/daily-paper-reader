## 摘要
持久化LLM智能体需要记忆表示，使得在长期交互中人物理解的形成过程明确化。现有的智能体记忆方法强调信息保留与检索，但对如何将累积的交互证据抽象为人物理解描述有限。我们将这一过程视为图式形成，即情境证据被抽象为可复用的模式与稳定的人物层面断言。我们引入PersonaTree，一种结构化生命周期记忆框架，通过三级人物树实现该观点，并具有从证据到断言的显式支持路径。PersonaTree通过保守写入、置信度引导整合以及查询条件路径检索来维护树结构，仅返回每次查询所需的证据深度。在六个涉及人物理解与持久化记忆基准测试中，结合三种回答主干，PersonaTree在18个紧凑分数中有12个排名第一，并在16个设置中达到前两名。消融实验表明，层次结构改善了KnowMe上的抽象人物理解，而支持路径检索在可比上下文预算下提升了RealPref的对齐度。

## Abstract
Persistent LLM agents require memory representations that make the formation of person understanding explicit across long term interaction. Existing agent memory methods emphasize information retention and retrieval, yet give limited account of how accumulated interaction evidence is abstracted into person understanding. We view this process as schema formation, where situated evidence is abstracted into reusable patterns and stable person level claims. We introduce PersonaTree, a structured lifecycle memory framework that realizes this view as a three level persona tree with explicit support paths from evidence to claims. PersonaTree maintains the tree through conservative writing, confidence guided consolidation, and query conditioned path retrieval, returning only the evidence depth required by each query. Across six person understanding and persistent memory benchmarks with three answer backbones, PersonaTree ranks first in 12 of 18 compact scores and reaches the top two in 16 settings. Ablations show that hierarchy improves abstract person understanding on KnowMe, while support path retrieval improves RealPref alignment under a comparable context budget.

## 2. 方法论：核心思想、关键技术细节、算法流程
### 核心思想
- 将长期交互历史**结构化为三级人物树**（Persona Tree）：叶子节点（Leaf）存储带时间戳的交互事件证据；中间节点（Mid）捕捉重复的行为模式或状态；根节点（Root）表示稳定的人物层面声明（如价值观、原则、硬边界）。
- 通过**支持边**（support edges）将低层证据连接到高层抽象，确保每一个用户层面的声明都能追溯到具体的观察。

### 关键技术细节
- **在线证据插入（Online Evidence Insertion）**：新交互进入时，先提取为叶子节点，进行模式兼容性检查（schema compatibility），再结合嵌入相似度和证据验证器（evidence validator）计算匹配分数 \( s_{\text{match}} \)，选择最佳中间节点附着。匹配分数公式：
  \[
  s_{\text{match}}(l,m) = 1[\kappa(a_l, a_m)=1] \cdot (\alpha \cos(z_l, z_m) + \beta \psi(l,m))
  \]
  其中 \(\kappa\) 是模式兼容性谓词，\(\psi\) 是验证器输出的证据支持/冲突分数（-1到1）。
- **置信度更新（Confidence Update）**：在对数几率空间进行更新，包含时间衰减和证据权重：
  \[
  L_t = (L_{t-1} - L_{\text{base}})e^{-\lambda \Delta t} + L_{\text{base}} + \omega_E, \quad c_t = \sigma(L_t)
  \]
  支持证据增加置信度，冲突证据降低置信度，长期无新证据则向基线衰减。
- **离线整合（Offline Consolidation）**：定期处理孤立的叶子（orphan leaves），聚类形成新的中间节点；当中间节点满足置信度、支持数量和时间覆盖要求时，可提升为根节点；同时剪枝陈旧或低置信度的节点，保持树结构紧凑。
- **查询条件路径检索（Query-Conditioned Path Retrieval）**：首先通过路由模型预测查询需要的抽象层级（Leaf/Mid/Root）和属性约束；然后从根/中间/叶子的支持路径中选择合适的渲染深度（d=0/1/2）；最后在token预算内通过选择函数选出最优上下文：
  \[
  C^\star = \arg\max_{C \subseteq G_q} \sum_{x \in C} \left[ r(q,x) - \lambda_b \text{tok}(x) \right]
  \]
  平衡了相关性、可靠性、所需深度与token成本。
