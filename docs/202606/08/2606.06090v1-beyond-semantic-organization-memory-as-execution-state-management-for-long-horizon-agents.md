## 摘要
基于LLM的智能体越来越多地处理具有相互依赖决策的长周期任务，其中每个动作都会重塑未来的约束条件，中间错误可能级联放大。现有的RAG和智能体记忆系统按语义相似性组织历史记录，在决策时检索内容相关的条目。我们认为这种设计与执行状态依赖关系不匹配：它会分割决策轨迹，混合有效和错误的轨迹，阻碍连贯的状态重建和错误隔离。我们提出MAGE（记忆作为智能体引导的探索），这是一种主动执行状态管理器，将交互存储在层次状态树中。智能体从活跃的根到当前路径推导其状态，结合子目标摘要、最近轨迹和先前分支的提示。四个耦合操作维护这棵树：Grow记录新轨迹，Compress总结已完成的子目标，Maintain验证摘要，Revise恢复目标边界并在新分支上继续执行。这种设计限制了上下文增长，同时保持状态完整性并将有缺陷的片段与活跃路径隔离。在MemoryArena上的实验表明，MAGE将平均任务成功率提高了7.8-20.4个百分点，同时将token消耗减少了55.1%。

## Abstract
LLM-based agents increasingly tackle long-horizon tasks with interdependent decisions, where each action reshapes future constraints and intermediate errors can cascade. Existing RAG and agent memory systems organize histories by semantic similarity, retrieving content-relevant entries at decision time. We argue that this design mismatches execution-state dependencies: it fragments decision trajectories and mixes valid and erroneous traces, hindering coherent state reconstruction and error isolation. We propose MAGE (Memory as Agent-Guided Exploration), an active execution-state manager that stores interactions in a hierarchical state tree. The agent derives its state from the active root-to-current path, combining subgoal summaries, recent traces, and hints from prior branches. Four coupled operations maintain the tree: Grow records new traces, Compress summarizes completed subgoals, Maintain validates summaries, and Revise restores a target boundary and resumes on a new branch. This design bounds context growth while preserving state integrity and isolating flawed segments from the active path. Experiments on MemoryArena show that MAGE improves the average task success rate by 7.8--20.4 pp over baselines, while reducing token consumption by 55.1%.

- **研究动机**：随着LLM智能体在长期任务（数百步）中执行具有相互依赖的决策，每一步动作会改变未来约束，中间错误可能级联放大。现有RAG和智能体记忆系统（如HippoRAG2、Mem0、MemoryOS等）普遍采用**语义相似性**来组织和检索历史信息，导致两个关键问题：
  - **状态碎片化**：决策轨迹被语义片段打散，无法保持完整的执行状态链，智能体基于不完整信息做出错误动作。
  - **错误隔离困难**：相似性检索会混合有效和错误的轨迹，无法追溯到错误源头，导致错误传播和积累。
- **整体含义**：论文指出，对于长周期、具有状态依赖的任务，记忆系统应从“被动语义存储”转向“主动执行状态管理”，以保持状态完整性和错误隔离能力。

## 2. 方法论：核心思想、技术细节与算法流程

### 核心思想
- **MAGE（Memory as Agent-Guided Exploration）**：将智能体的交互历史组织为**两层层次状态树**，智能体的当前执行状态由树中活跃的根到当前路径完整决定，而非从语义相似条目中组装。
- **仿脑机制**：受认知科学启发——前额叶皮层分层组织子目标并压缩完成片段；前扣带回检测子目标边界的错误；执行控制选择性回溯修复受影响分支。

### 关键技术细节
- **层次状态树结构**：
  - **底层（Raw Layer）**：记录每一步的动作-观察对（action-observation），保持细粒度状态。
  - **顶层（Summary Layer）**：将完成的底层段压缩为子目标摘要节点，同时保留决策边界。
- **执行状态S**由三部分构成：
  - **C（压缩状态）**：顶层摘要节点沿根到当前路径。
  - **R（原始状态）**：最近未压缩的底层节点（精细上下文）。
  - **H（执行提示）**：已探索分支的子节点和诊断反馈。

### 四个耦合操作（算法流程）
| 操作 | 触发时机 | 功能 |
|------|----------|------|
| **Grow** | 每一步动作后 | 将新动作-观察对追加到底层。若已有相同内容子节点则合并，避免重复；否则创建新节点并更新H（暴露兄弟分支）。 |
| **Compress** | 子目标完成或原始状态R超长阈值 | 将底层段（从上一次压缩边界到当前）压缩为顶层摘要节点，保留边界信息。清空R，将摘要添加到C。 |
| **Maintain** | 紧接Compress之后 | 用LLM验证刚压缩的子树及其摘要是否正确（检查信息缺失、任务未满足、依赖破坏）。若失败，记录诊断反馈到节点note，返回FAIL信号（含目标步id）。 |
| **Revise** | Maintain失败或智能体主动检测错误 | 沿树回退到目标边界（通常是子目标边界），恢复C和R到该点，注入诊断反馈到H，从该点开始新分支执行。隔离错误片段，保留有效进度。 |
