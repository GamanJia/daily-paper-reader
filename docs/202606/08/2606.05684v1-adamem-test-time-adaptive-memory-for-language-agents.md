## 摘要
语言体面临的核心挑战是如何利用过往经验适应动态的测试时环境。尽管近期研究展示了体记忆机制的潜力，但多数系统将检索局限于情节起始阶段，导致在长时任务展开时不得不依赖日益失准的静态指导。为解决这一僵化问题，我们提出自适应记忆体（AdaMEM）——一种面向体测试时自适应的新颖框架。在不更新模型参数的前提下，AdaMEM通过混合记忆架构调整体行为：离线收集的原始经历构成长期轨迹记忆，同时在线生成动态短期策略记忆以指导决策。该机制可在不同推理时计算量水平下权衡标记效率与适应性。实验表明，AdaMEM显著优于静态记忆基线，在ALFWorld上相对提升达13%，在WebShop上提升11%，且在HotpotQA的体搜索任务中保持领先性能。为进一步增强自适应能力，我们提出STEP-MFT（步骤级记忆微调技术），通过训练策略从检索经历中合成高质量策略，从而带来额外性能提升。本工作建立了体记忆的新缩放维度，支持真实环境中部署后的持续推理与自我进化。代码见https://github.com/yunx-z/AdaMEM。

## Abstract
A central challenge for language agents is utilizing past experience to adapt to dynamic test-time conditions. While recent work demonstrates the promise of agentic memory mechanisms, most systems restrict retrieval to episode initiation. Consequently, agents are forced to rely on static guidance that becomes increasingly misaligned as long-horizon tasks unfold. To address this rigidity, we propose the Adaptive Memory Agent (AdaMEM), a novel framework for agent test-time adaptation. Without updating model parameters online, AdaMEM adapts agent behavior via a hybrid memory architecture: it maintains a long-term trajectory memory of raw experiences collected offline while generating dynamic short-term strategy memory on-the-fly to guide decision-making. This mechanism enables the trade-off between token efficiency and adaptability across varying inference-time compute levels. Empirically, AdaMEM significantly outperforms static memory baselines, achieving relative gains of up to 13% on ALFWorld and 11% on WebShop, with consistent leading performance extending to agentic search on HotpotQA. To further enhance this adaptation, we develop STEP-MFT, a Step-wise Memory Fine-Tuning technique that trains the policy to synthesize high-quality strategies from retrieved experiences, yielding additional performance gains. Our work establishes a new scaling dimension for agentic memory, supporting continuous reasoning and self-evolution post-deployment in real-world environments. Our code is available at https://github.com/yunx-z/AdaMEM.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **混合记忆架构**：将记忆分解为**长期轨迹记忆（Long-Term Trajectory Memory）** 和**短期策略记忆（Short-Term Strategy Memory）**。
  - 长期记忆：离线收集的成功原始轨迹，通过状态嵌入索引，提供可检索的过往经验。
  - 短期记忆：在推理时在线生成，基于当前状态从长期记忆中检索相关经验后合成简洁的策略文本，直接指导下一步动作。
- **无需参数更新**：动态策略合成仅通过提示（prompt）实现，不修改模型参数。

### 关键技术细节
1. **长期轨迹记忆（M）**：
   - 从训练集中收集成功轨迹（r_T=1）。
   - 使用预训练嵌入模型 ϕ(·) 将每个步骤的状态 st 编码为键，对应值存储当前状态、动作和剩余成功轨迹。
   - 采用 HNSW 索引支持高效稠密检索（默认 top-1，k=1）。

2. **短期策略记忆（zt）**：
   - 在线合成，使用 LLM 生成 1-3 条简洁、可操作的策略条件项。
   - **两种推理模式**（算法 1 文字说明）：
     - **AdaMEM-HIGH**（高适应努力）：每一步都基于当前状态决定是否触发记忆检索和策略合成（d_mem = yes/no）。若触发，生成临时策略 zt 用于当前步，之后丢弃。最大化适应性，但 token 成本高。
     - **AdaMEM-LOW**（低适应努力）：策略 z_curr 作为持久状态变量，指导多步动作。每步决定是否刷新（d_refresh = yes/no）。仅在检测到状态与策略不匹配时刷新，平衡效率与适应性。

3. **STEP-MFT 微调技术**：
   - 目的：训练策略模型生成真正影响决策的高效用策略，避免生成冗余文本。
   - **数据收集**：使用 AdaMEM-HIGH 模式在训练集上执行推理，收集 (st, E_ret, zt, at, a'_t, r) 元组，其中 a'_t 是未使用策略的基线动作（仅采样不执行）。
   - **过程级过滤（Dual-filter）**：
     - 条件 1：轨迹最终成功（r=1）。
     - 条件 2：策略改变了动作（at ≠ a'_t），即动作变更过滤。
   - **理论证明**（命题 3.1）：动作变更是策略优势严格为正的必要条件。
   - **训练目标**：对过滤后的策略进行拒绝采样微调（RFT），使用标准交叉熵损失优化策略生成。
   - 微调后的单一模型同时承担策略合成和动作生成任务（低部署复杂度）。

## 6. 主要结论与发现

1. AdaMEM（特别是 **AdaMEM-LOW**）在训练无关设置下显著优于静态记忆基线：ALFWorld 未见划分相对增益 +11.4 点（绝对），WebShop +2.8 点，HotpotQA 领先。

3. **策略抽象是关键**：仅检索原始轨迹（无策略合成）性能下降 6 个点；没有长期记忆则策略生成为幻觉（下降 30.7 个点）。
4. **STEP-MFT 进一步提效**：过程级动作变更过滤优于结果过滤，在 ALFWorld 上较训练无关 AdaMEM-HIGH 提升 +5.3 点。
5. AdaMEM 实现了**推理成本与性能之间的可控权衡**，在效率-性能图上占据优越帕累托前沿。
6. 混合架构支持**跨模型记忆共享**（异策略实验），Gemma 使用 Qwen 构建的记忆仍获提升。

## 7. 优点

1. **创新性**：提出动态在线策略合成而非静态检索，解决记忆僵化问题。
2. **灵活性与可缩放**：通过两种推理模式平滑调节适应性与效率；随检索规模 k 增加性能单调提升（与 Synapse 退化形成对比）。
3. **理论支撑**：对动作变更作为必要条件的证明合理，引入过程级奖励概念。
4. **实验设计扎实**：覆盖训练无关与微调、同策略与异策略、消融、效率分析，报告标准差。
5. **实用导向**：单一微调模型同时处理策略与动作，降低部署复杂度；采用 LoRA 高效微调。
6. **可复现性**：开源代码，详细记录实现细节和提示模板。

## 8. 不足与局限

1. **策略惯性**：AdaMEM-LOW 依赖体自我评估触发刷新，当体高估当前策略时（如为失败解释为未完全探索），无法纠正，导致任务失败（附录 C.3 案例）。该问题未在 STEP-MFT 中直接处理。
2. **仅使用成功轨迹**：长期记忆仅存储成功轨迹，失败经历被排除。论文指出原因（体难以从失败中提取一致指导），但缺乏利用失败轨迹的机制，可能限制了策略多样性。
3. **实验覆盖不全面**：
   - 仅评估 4B/7B 模型，未在更大模型（13B/70B+）或不同系列（如 GPT-4）上验证。
   - 未包含难度更高的基准（如 SWE-bench、AgentBench 的游戏或代码任务）。
4. **微调依赖训练集轨迹质量**：若训练集成功轨迹稀少，记忆构建和数据收集可能受限。
5. **检索来源固定**：长程记忆在部署后不更新，无法利用测试时新获得的成功策略（仅基于预收集数据）。
6. **未评估灾难性遗忘或记忆污染风险**：当体连续在多任务上交互时，记忆内容可能与当前分布冲突。
