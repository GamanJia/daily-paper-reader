## 摘要
语言智能体的“记忆宫殿”系统将每个记忆锚定到世界坐标，基于几何能提供文本所不能的直觉。我们使这一直觉可测试，并报告三个结果。首先，将空间邻近性折叠到与最近性和重要性并列的线性混合中的记忆宫殿默认做法没有帮助，甚至可能有害：在一个预注册的回忆实验中，发布的混合未能通过其自身的冻结测试（平均Delta-Hit@5 -0.0375，Wilcoxon p=0.306），与位置盲基线持平，而几何主导的加权则显著胜出（+0.3208，p<10^-15）：当查询模式是空间性时，几何必须主导回忆。其次，记忆回忆和可见性必须分离：回忆在设计上对遮挡不敏感（你正确记得墙后的下一个房间），而可见性是对存储几何的感知谓词，当前系统从未计算过。一个从智能体已投射的视线射线重新指向的单行射线与体素数字微分分析器（DDA）提供了这一点：文本和实时视场锥体在849个墙后目标上均得分为0.000，而锥体加DDA达到0.982（精确McNemar p<10^-6）；坐标回忆分别解决了余弦空值无法解决的近乎重复位置（1.000 vs 0.533，n=150）。第三，在git提交的预注册下（SPMEM-OCC-LIVE-v1：八个脚本化世界，自动评分，96个墙后目标，误显1.000->0.000，合并精确McNemar p=2.5x10^-29），可见性谓词被实时确认，该运行发现并修复了一个真实的中继锚点缺陷。我们承认“遮挡需要几何”近乎同义反复；贡献在于测量和隔离，将空间记忆必须存储的内容与如何读取分开。这些试点为冻结的验证性研究（SPMEM-ZERO-REAL-PREREG-v1）提供动力；完整的由人类编写的多世界研究及盲评员留作未来工作。

## Abstract
Language-agent "memory palace" systems anchor each memory to a world coordinate, on the intuition that geometry adds something text cannot. We make that intuition testable and report three results. First, the memory-palace default of folding spatial proximity into a linear blend beside recency and importance does not help and can hurt: in a pre-registered recall experiment the shipped blend fails its own frozen test (mean Delta-Hit@5 -0.0375, Wilcoxon p=0.306), sitting at a position-blind baseline, while a geometry-led weighting wins decisively (+0.3208, p<10^-15): geometry must lead recall when the query regime is spatial. Second, memory recall and visibility must be separated: recall is occlusion-blind by design (you correctly remember the next room behind a wall), while visibility is a perception predicate over stored geometry that the live system never computed. A one-line ray-versus-voxel digital differential analyzer (DDA), re-pointed from the gaze ray the agent already casts, supplies it: text and the live FoV cone both score 0.000 on 849 behind-wall targets while cone-plus-DDA reaches 0.982 (exact McNemar p<10^-6); coordinate recall separately resolves near-duplicate locations a cosine null cannot (1.000 vs 0.533, n=150). Third, the visibility predicate is confirmed live under a git-committed pre-registration (SPMEM-OCC-LIVE-v1: eight scripted worlds, automated oracle scoring, 96 behind-wall targets, false-visible 1.000->0.000, pooled exact McNemar p=2.5x10^-29), a run that surfaced and fixed a real relay anchor defect. We concede that occlusion-needs-geometry is near-tautological; the contribution is the measurement and isolation, separating what spatial memory must store from how it is read. These pilots power a frozen confirmatory study (SPMEM-ZERO-REAL-PREREG-v1); the full human-authored multi-world study with blind raters remains future work.

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：锚定到世界坐标的“记忆宫殿”系统究竟是否真的需要几何信息，以及几何信息为纯文本语言智能体内存系统带来了什么独特价值，这是不可以被文本替代的？
- **背景**：现有语言智能体系统（如Generative Agents、MemGPT、Mem0等）大多采用基于文本相似度（如余弦相似度）的检索方法，无法处理需要几何信息的具体问题，比如：“目标物体是否被遮挡”、“该位置是否存在不同物体”等。作者指出，目前记忆系统的“默认混合排序”（接近度和重要性/时间相近性混合）并不成立。
- **整体含义**：作者主张，空间几何信息应单独存储并用于主导召回或作为验证谓词，而非作为排名加权的一小项。特别是**可见性判断（遮挡）** 是几何特有的、文本系统无法复现的核心功能。

## 2. 论文提出的方法论（核心思想、关键技术细节、算法流程）
- **核心思想**：
  - 区分**记忆召回（memory recall）** 与**可见性感知（visibility perception）**：召回用于获取信息，可见性用于判断是否可视，二者分开处理。
  - 将空间记忆使用至少分为两种形式：
    1. **空间作为排序项**：通过混合公式将几何邻近度与语义相似度、时效性、重要性等混合排序。
    2. **空间作为索引和验证**：先通过几何条件（如区域包含、视野锥、视线遮挡）筛选候选，再排序或验证谓词。
  - 关键主张：当查询场景具有空间性质时，**几何必须主导召回**，而不是作为稀释后的一个项。

- **关键技术细节**：
  - **DDA（数字差分分析器）**：一条单行射线遍历体素网络，判断从观测者到目标之间是否有固体阻挡，从而实现可见性谓词。所有几何运算都是利用系统中已有的“视线射线”机制重新指向目标实现，不引入额外数据结构或大开销。
  - **坐标作为锚点**：每个记忆存储其世界坐标中心，召回时通过3D欧几里得距离或视野位置进行筛选。

- **算法流程**（文字说明）：
  1. 存储：每条记忆记录对象世界坐标、观测者位置、视野方向、文字描述等。
  2. 召回：通过坐标距离或语义相似性初筛，返回候选。
  3. 感知查询：对已返回的记忆候选，从观测者当前坐标和方向，通过DDA扫描到目标坐标的直线上每个体素点，如果有任何固体体素阻挡，则判断目标不可见。
  4. 输出：可见性结果（是/否），不改变召唤排名。

## 6. 论文的主要结论与发现
1. **几何必须主导召回**：几何空间信号在大规模混合排序中“稀释”后会低于纯向量检索基线，而几何主导加权（几何靠近度高占主导）则显著优于纯文本和默认混合（+0.3208 Hit@5）。
2. **可见性（遮挡）是纯文本无法计算的基本功能**：文本、视野锥法都在遮挡检测上得分为0，而加上DDA的可见性谓词达到0.982。
3. **坐标召回解决重复位置问题**：在近重复定位中，坐标召回达到1.000，而纯余弦检索仅为0.533差（近乎机会水平）。
4. **记忆召回和可见性必须分开**：回忆可以（而且应该）返回被遮挡的记忆；可见性是独立检查中使用的谓词，这两个不能混为一谈。
5. **动作层增益来自“对象关联”，而非几何本身**：行为效率提升主要来源于将记忆绑定到操作对象（而非具体几何坐标），但几何在感知层不可替代。
6. **三种表示方法（存储坐标+ DDA/LLM推理/纯文本）对比**：DDA与LLM在文本坐标条件下效果相同，关键在“存储几何”，而非使用何种计算媒介。
7. **过去的“主题分区”研究被降级**：先前声称空间优势的研究实际上是在做文字级主题分区，根本未读取世界坐标，因此该例不应作为空间记忆实验的证据。

## 7. 优点
- **清晰的理论区分**：明确指出记忆、召回和感知应当分开处理，并提出“索引/验证”比“混合排序器”更强。
- **预先注册**：大量实验设计和结论已在git中冻结，增强了可信度和可复现性。
- **严格的上限和失败检验**：不仅证明空间有效，也通过“文本控制反转”实验证明其不是通用的改善，保证了实验的公平性。
- **实际系统验证**：不仅在仿真中运行，而且在真实部署的中继系统中运行（发现并修复了记忆锚点错误）。这体现了方法的实用性和鲁棒性。
- **揭露默认混合排序的弱点**：这是实际很少被量化的发现—默认多因子混合排序（记忆宫殿方法）可能比纯向量没意义甚至有害。

## 8. 不足与局限
- **实验场景有限**：很多工作是在脚本化的体素世界或控制场景中进行的，缺乏来自各种复杂真实世界的有机人工智能探索记录。
- **只使用单一种类模型**：所有实验均使用同一个单一嵌入模型（bge-small-en-v1.5），未对比其他大型嵌入模型（如text-embedding-3-large）。
- **缺乏人为标定**：所有近期实验的分数均由自动化脚本计算，尚未引入人类标定员进行质量标准评估（这是论文计划进行但尚未完成的下一步工作）。
- **遮挡动态性未解决**：实验假设世界几何是静态的；当世界构建变化时（如新增或移除障碍物），在召回时执行的可见性谓词可能不符合创建时实情；当前未实现“几何版本化”或重新验证机制。
- **运行方式过于定性**：尽管结果统计显著，但在执行时仍然需要DDA扫描查询，对较大场景而言可能存在性能隐患。
- **缺乏从头到尾比较**：作者并未与其他状态空间记忆系统（如3DSPMR、GSMem、RenderMem）在相同任务集合上进行完整端点对比评估，表明这只是隔离实验，而非排行榜战。
