## 摘要
在自主操作中，机器人可能需要基于不再可见的证据做出决策。我们研究“延迟证据”任务，其中早期线索在后续决策点之前消失，因此视觉上相似的观察可能需要不同的动作。在这些设置中，当前观察不足以作为控制的状态。我们提出了轨迹路由因果证据（TRACE），一种用于视觉运动模仿策略的记忆框架。TRACE将任务相关的视觉和机器人状态证据（如物体身份、目标选择或路线依赖状态）存储在固定大小的潜在记忆中，该记忆在长时间段内保持有界。TRACE不是通过原始时间或手动提供的任务标签来索引记忆，而是使用“路径签名”：执行机器人状态轨迹的紧凑、顺序敏感特征。这些签名不存储视觉线索本身；相反，它们提供轨迹条件化的键，用于写入和检索线索可见时存储的证据。当机器人后来遇到模糊的观察时，策略基于TRACE记忆来恢复缺失的上下文并选择正确的分支。TRACE通过轻量级适配器附加到策略上，而不改变策略主干、动作头或模仿目标。在具有视觉模糊分支点的真实世界长时域操作任务中，TRACE在分支选择和任务成功率上优于其他基线方法，包括短期历史和循环记忆。项目页面：https://jeong-zju.github.io/trace

## Abstract
Robots under autonomous operation may require decisions based on evidence that is no longer visible. We study \emph{delayed-evidence} tasks, where an early cue disappears before a later decision point, so visually similar observations can require different actions. In these settings, the current observation is not a sufficient state for control. We introduce TRAjectory-routed Causal Evidence (TRACE), a memory framework for visuomotor imitation policies. TRACE stores task-relevant visual and robot-state evidence, such as object identity, target choice, or route-dependent state, in a fixed-size latent memory that remains bounded over long episodes. Instead of indexing memory by raw time or manually provided task labels, TRACE uses \emph{path signatures}: compact, order-sensitive features of the executed robot-state trajectory. These signatures do not store the visual cue itself; rather, they provide trajectory-conditioned keys for writing and retrieving the evidence stored when the cue was visible. When the robot later reaches an ambiguous observation, the policy conditions on TRACE memory to recover the missing context and choose the correct branch. TRACE attaches through lightweight adapters to policies, without changing the policy backbone, action head, or imitation objective. Across real-world long-horizon manipulation tasks with visually ambiguous branch points, TRACE improves branch selection and task success over alternative baselines, including short-history and recurrent memory. ### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在机器人自主操作中，许多任务存在“延迟证据”现象：早期出现的视觉线索（如目标物体的身份、起始位置）在后续决策点之前消失，导致决策点处的观察在视觉上几乎相同（例如从不同起始位置出发后到达相似场景），但需要执行不同的动作。传统的视觉运动策略依赖当前观察或短时间窗口，隐含马尔可夫假设，无法区分这些历史分支，因此决策失败。
- **研究背景**：现有方法如循环策略、Transformer上下文窗口、通用记忆机制可以携带历史信息，但往往需要修改策略主干、依赖检索或学习到的隐藏状态，且容易覆盖或稀释与分支决策相关的关键证据。TRACE旨在提供一种固定预算、因果、在线更新的记忆模块，在不改变策略主干、动作头或模仿损失的前提下，为延迟证据任务提供缺失的历史上下文。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：TRACE将“记忆内容”与“记忆访问”分离。它使用**路径签名（path signatures）**——执行机器人状态轨迹的紧凑、顺序敏感的特征——作为键，在固定大小的潜在记忆槽中写入和读取任务相关的视觉和状态证据。路径签名不存储视觉线索本身，而是提供轨迹条件化的访问键，使得在决策点可以通过当前轨迹的签名检索到早期存储的线索。
- **关键技术细节**：
  - **路径签名计算**：对机器人状态轨迹（17-D proprioceptive state）进行分段线性插值，计算截断深度 p=3 的签名，得到维度 5,219 的特征向量。同时维护签名增量（delta signature）以捕捉局部运动变化。
  - **签名路由记忆更新**：每步将当前视觉-状态编码作为证据，通过路径签名和增量签名的嵌入形成轨迹键 `qt`，计算路由权重 `ω` 选择哪些记忆槽被激活。通过门控更新将证据写入被选中的槽，门控强度由路由权重调制。
  - **记忆读取**：利用当前证据和轨迹状态形成查询，通过注意力从更新后的记忆槽中读出上下文 `zmem`。
  - **策略适配器**：共享的TRACE更新器产生的记忆状态 `(M, zmem, gt, Δgt)` 通过轻量级适配器（对回归策略用记忆令牌拼接，对扩散策略用全局条件向量）注入基础策略，不改变原策略的训练目标。
  - **训练细节**：使用因果扫描（只使用当前及之前的信息），辅助损失（平衡、熵、一致性）防止槽坍缩或写入扩散；基础策略损失（如chunk L1或扩散去噪损失）保持不变。

- TRACE显著提升了延迟证据任务的分支选择和任务成功率：回归策略平均进度从25.50%提高到69.23%，扩散策略从25.00%提高到59.53%，优于最强的非TRACE基线π0.5（50.47%）。

- 与通用历史记忆（GRU、Transformer上下文、LRU、检索提示）相比，TRACE表现更好，尤其在需要保留早期起源线索的任务（Book、Laundry、Medicine）上优势明显。
- 消融和诊断实验证明：TRACE确实使用历史顺序信息而非仅依赖决策点观察；顺序反转会严重降低路线相似度和分支一致性，而顺序保持的变换（重采样、抖动等）则保持高值。

### 7. 优点：方法或实验设计上的亮点

- **创新性**：将路径签名作为记忆访问键，利用其顺序敏感性和时间参数化不变性，实现紧凑的轨迹条件化记忆路由，避免了学习动态地址可能带来的歧义。
- **模块化**：TRACE通过轻量级适配器附加到现有策略，不改变策略主干、动作头或训练目标，易于集成到多种策略家族（回归、扩散、未来其他架构）。
- **因果在线更新**：记忆更新只使用当前及之前信息，无需未来帧、线索标签或分支标签，训练与部署一致。
- **辅助损失设计**：平衡、熵、一致性损失有效防止了固定槽记忆的常见失败模式（槽坍缩、扩散写入、读写不匹配）。
- **实验诊断深入**：除了标准进度指标，还设计了历史变换诊断（路线相似度、分支一致性）来验证记忆是否真的在使用历史顺序信息，提供了对内部机制的洞察。
- **真实世界评估**：在5个具有挑战性的长时操作任务上进行物理部署评估，场景多样，包含延迟线索和视觉模糊。

### 8. 不足与局限

- **签名维度问题**：标准流式签名的维度随状态维和深度指数增长（ds=17, p=3时已达5,219维；p=4将达88,740维），导致学习投影、归一化和计算开销增加。论文指出这是主要局限，但未讨论使用log-signature（更具冗余消除）或更低维度投影的替代方案。

- **算力资源未明确**：缺乏训练所用GPU型号、数量及总训练时长的报告，影响了复现性和资源消耗评估。
