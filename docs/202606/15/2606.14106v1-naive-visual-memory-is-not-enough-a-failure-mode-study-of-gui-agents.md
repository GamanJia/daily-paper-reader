## 摘要
图形用户界面（GUI）智能体越来越多地被用于跨应用、网站和操作系统的复杂计算机任务自动化。为了提高其可靠性，近期工作引入了经验记忆，智能体检索先前的轨迹以指导类似状态下的决策。更近期的方法进一步将这一思想扩展到视觉记忆，通过存储和检索过去交互中的截图，为智能体提供比纯文本记忆更丰富的上下文信息。然而，视觉记忆在GUI智能体中的效果尚未得到充分理解：目前不清楚视觉记忆缓解了哪些失败，又加剧了哪些失败。为系统分析视觉记忆的效果，我们提出了一个四类GUI智能体失败的分类法（即认知失败、视觉状态误解、隐藏操作盲区和接地错误），这些失败对应于感知-推理-行动管线的不同阶段。我们发现，预置完整图像记忆对失败分布具有分化效应：它减少了状态级失败，但恶化了行动级失败，并增加了隐藏操作盲区和接地错误。受此发现启发，我们提出了行动接地视觉记忆（AGMem），一种面向GUI智能体的行动接地记忆框架。AGMem的核心思想是存储与成功行动或恢复紧密相关的局部GUI区域的图像裁剪，而非存储完整截图。在OSWorld上的实验表明，AGMem相比完整图像记忆将任务成功率提高了33.3%。这些结果表明，AGMem是GUI智能体中视觉记忆的一种有效表示。

## Abstract
Graphical User Interface (GUI) agents are increasingly used to automate complex computer tasks across applications, websites, and operating systems. To improve their reliability, recent work has introduced experiential memory, where agents retrieve prior trajectories to guide decision-making in similar states. More recent approaches further extend this idea to visual memory by storing and retrieving screenshots from past interactions, providing agents with richer contextual information than text-only memories. However, the effect of visual memory in GUI agents remains insufficiently understood: it is unclear which failures visual memory mitigates, or which failures it exacerbates. To systematically analyze the effect of visual memory, we introduce a taxonomy of four GUI agent failures (i.e., cognitive failure, visual state misunderstanding, hidden operation blindness, and grounding error) that map to distinct stages of the perception-reasoning-action pipeline. We find that prepending full-image memory has a divergent effect on the failure distribution: it reduces state-level failures but worsens action-level ones, and increases hidden operation blindness and grounding error. Motivated by this finding, we propose Action-Grounded Visual Memory (AGMem), an action-grounded memory framework for GUI agents. The core idea of AGMem is to store image crops that capture the local GUI region closely related to a successful action or a recovery, rather than storing full screenshots. Experiments on OSWorld show that AGMem improves task success rates by 33.3 % over full-image memory. These results demonstrate that AGMem is an effective representation for visual memory in GUI agents.

# 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

## 核心思想
- **记忆应关注动作相关的局部区域**，而非全屏截图。因为GUI中大部分像素对当前决策无关，全屏截图会引入任务无关线索，干扰模型对隐藏操作和精确坐标的判断。
- 构建**行动接地视觉记忆（AGMem）**：每个记忆条目存储一个紧密裁剪的图像区域，该区域与成功执行的动作（或恢复操作）直接相关。

## 关键技术细节

### 2.1 行动接地视觉记忆构建
- **自动裁剪算法**：给定步骤 \(t\) 的截图 \(o_t\) 和执行动作 \(a_t\) 后的截图 \(o_{t+1}\)，计算像素级差分，经形态学处理得到变化掩膜，再取最小包围盒并适配到UI容器（如窗口、面板）。
- **记忆结构**：每个记忆步骤 \(m_t = (s_j, a_t, C_t)\)，其中 \(s_j\) 是子任务标签，\(a_t\) 是动作，\(C_t\) 是行动相关裁剪。

### 2.2 恢复意识记忆检索（Recovery-Aware Retrieval）
- **两阶段检索**：
  - **轨迹级检索**：使用Sentence-BERT对当前子任务列表 \(s\) 与记忆库中的子任务标签进行相似度匹配，选择覆盖所有子任务的 \(k\) 条相关轨迹。
  - **步骤级检索**：对选定轨迹内的记忆步骤，用CLIP编码器联合文本（子任务标签）和图像（裁剪图），计算与当前状态（当前子任务 + 上一时刻裁剪图 \(C_{t-1}\)）的余弦相似度，返回Top-5步骤。
- **恢复记忆**：
  - 当**恢复状态检测器**（LLM-based）识别到错误时（通过检查近期截图和动作），将查询重定向到专门的**恢复记忆库**，该库存储了从错误状态恢复的正确步骤对（每个对标注失败模式），从而提供纠正范例。

### 2.3 整体流程
1. 将任务指令 \(I\) 分解为子任务列表 \(s = (s_1, \dots, s_p)\)。
2. 每一步，智能体自报当前子任务，并基于当前截图 \(o_t\) 和上一时刻裁剪 \(C_{t-1}\) 检索最相关的记忆步骤。
3. 若检测到错误状态，则禁用提议动作，并从恢复记忆库中检索纠正示例，重规划动作。
4. 执行动作后，自动构建新的记忆条目（裁剪图）并存入记忆库。

# 6. 论文的主要结论与发现

## 核心发现
1. **GUI智能体存在四种主要失败模式**：认知失败、视觉误读、隐藏操作盲区、接地错误，各自对应感知-推理-执行管线的不同阶段。
2. **全图像记忆具有分化效应**：
   - 减少状态级失败（认知失败：82.6%→75.0%；视觉误读：73.1%→69.6%）。
   - 加剧动作级失败（隐藏操作盲区：67.1%→78.8%；接地错误：27.5%→36.1%）。
3. **AGMem有效缓解副作用**：
   - 在OSWorld上，AGMem将任务成功率从20.4%（全图像记忆）提升至27.2%（相对提升33.3%）。
   - 所有四种失败模式均下降：视觉误读（-37.3pp）、隐藏操作盲区（-26.3pp）、接地错误（-13.6pp）、认知失败（-15.5pp）。→ 注：表2中AGMem视觉误读32.3%，相比全图像记忆69.6%下降37.3pp；隐藏操作盲区52.5% vs. 78.8%下降26.3pp。
4. **单纯裁剪不足**：仅做裁剪（+Crop）虽部分恢复，但仍不如AGMem，说明子任务对齐的检索和恢复记忆同样重要。
